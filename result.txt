817. 设计哈希映射

难度: Easy | 标签: Array Hash Table Linked List Design Hash Function

 题目描述

不使用任何内建的哈希表库设计一个哈希映射（HashMap）。

实现 MyHashMap 类：

	MyHashMap() 用空映射初始化对象
	void put(int key, int value) 向 HashMap 插入一个键值对 (key, value) 。如果 key 已经存在于映射中，则更新其对应的值 value 。
	int get(int key) 返回特定的 key 所映射的 value ；如果映射中不包含 key 的映射，返回 -1 。
	void remove(key) 如果映射中存在 key 的映射，则移除 key 和它所对应的 value 。

 

示例：

输入：
["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]
[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]
输出：
[null, null, null, 1, -1, null, 1, null, -1]

解释：
MyHashMap myHashMap = new MyHashMap();
myHashMap.put(1, 1); // myHashMap 现在为 [[1,1]]
myHashMap.put(2, 2); // myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(1);    // 返回 1 ，myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(3);    // 返回 -1（未找到），myHashMap 现在为 [[1,1], [2,2]]
myHashMap.put(2, 1); // myHashMap 现在为 [[1,1], [2,1]]（更新已有的值）
myHashMap.get(2);    // 返回 1 ，myHashMap 现在为 [[1,1], [2,1]]
myHashMap.remove(2); // 删除键为 2 的数据，myHashMap 现在为 [[1,1]]
myHashMap.get(2);    // 返回 -1（未找到），myHashMap 现在为 [[1,1]]

 

提示：

	0 <= key, value <= 106
	最多调用 104 次 put、get 和 remove 方法

---
 解题思路与复盘

1. 一句话直击本质：使用链地址法解决哈希冲突，通过链表存储同一哈希桶中的所有键值对。

2. 综合思路：
   - 链地址法：使用一个固定大小的数组作为哈希表，每个数组元素是一个链表的头节点，用于处理哈希冲突。对于每个操作（插入、查找、删除），首先计算键的哈希值以确定桶的位置，然后在该桶的链表中进行相应操作。
   - 开放寻址法（未在此代码集中出现）：另一种常见的解决哈希冲突的方法，通过线性探测、二次探测或双重哈希等策略在数组中寻找下一个可用位置。

3. 全量伪代码：
   plaintext
   类 ListNode:
       初始化方法(键=None, 值=None, 下一个=None):
           设置键, 值, 下一个节点

   类 MyHashMap:
       初始化方法:
           设置容量为10000
           创建一个大小为容量的数组，每个元素是一个空的链表节点

       方法 放入(键, 值):
           计算键的哈希值并取模得到索引
           获取对应索引的链表头节点
           遍历链表:
               如果找到相同键, 更新值并返回
           如果未找到, 在链表头插入新节点

       方法 获取(键):
           计算键的哈希值并取模得到索引
           获取对应索引的链表头节点
           遍历链表:
               如果找到相同键, 返回对应值
           如果未找到, 返回-1

       方法 移除(键):
           计算键的哈希值并取模得到索引
           获取对应索引的链表头节点
           遍历链表:
               如果找到相同键, 从链表中移除该节点
   

4. 复杂度：
   - 时间复杂度：在理想情况下（假设哈希函数均匀分布），插入、查找和删除操作的平均时间复杂度为 O(1)。在最坏情况下（所有键都映射到同一个桶），时间复杂度为 O(n)，其中 n 是插入的键值对数量。
   - 空间复杂度：空间复杂度为 O(n + k)，其中 n 是存储的键值对数量，k 是哈希表的容量（在此实现中为10000）。
