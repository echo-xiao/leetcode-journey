选择标签

已选项置顶 · 支持多选

没有匹配项，试试其他关键词。

目标设在扩展，不在 app

不是偏好，是架构定的：app 只申请 read 权限，写不了任何东西。会改变调度行为的设置，只能放在能写的那一端。Chrome 设目标，app 当记分牌。

范围可以交叉，不改变调度

公司、标签和题单通过可搜索的多选页选择，首页只保留已选项；超过两项折叠为 +N。同组取或、不同组取且。点完成应用选择，返回或 Esc 放弃本次修改，其他维度与时间保持不变。

为什么是 side panel 不是 popup

popup 点一下别处就关了（flomo 的扩展就是）。side panel 一直开着、跟着你换题自动更新，这才撑得住「做题全程它都在」。

为什么不注入 DOM

注入 DOM 要猜 LeetCode 的 HTML 结构，人家一改版就瞎。side panel 是浏览器给的独立区域，只从 GraphQL 读数据。LeetHub 被 fork 四次就是这么来的。

完成自动记录，不需要评分

队列中的题出现新的 AC 后，自动记录完成。阶梯复习按预设阶梯推进，轮次复习按整轮进度推进；手机阅读不记为完成。

为什么答案默认折叠

一打开就看见答案，间隔重复立刻失效。折叠不是为了省地方，是为了逼出一次真实的回忆尝试。

为什么分两层展开

伪代码和题解是不同深度的提示。记录你停在哪一层，比只记「看没看答案」信息量大得多。

降级态要明说，不能装没事

没网、token 过期、LeetCode 掉登录——标题栏的状态点变色，正文下方出一条可操作的琥珀条。数据进本地队列不会丢，但必须让人看见它还没推上去。

iOS首页是一个抽屉

和 flomo 手机版一样：平时你看到的是阅读页，点左上角 ☰，左侧导航展开，占 79% 屏宽，阅读页整体推向右侧， 右边露出带圆角的阅读页窄条。选一个分类，抽屉自动收回，屏幕上剩下那一类的题。

抽屉里是三个大数字、热力图、今天的进度，和 题单 / 标签 / 公司 / 时间 四个维度的 横向分类栏和对应列表。每行右边是 待复习 / 总数。全程没有卡片。

题意1004. 最大连续1的个数 III

给一个 0/1 数组和一个 k，最多可以把 k 个 0 翻成 1，问能得到的最长连续 1 有多长。

伪代码left = 0, zeros = 0 for right in range(n): while zeros > k: 收缩 left

题解关键是「不用真的翻转」——只要窗口里 0 的个数不超过 k 就合法。

第一次一直在想怎么「真的翻转」那 k 个 0，完全没意识到根本不需要翻转。

第二次重做还是先写成了 if，忘了窗口可能要连续收缩好几格。

我的代码def longestOnes(nums, k): left = zeros = ans = 0 for right, v in enumerate(nums): ...

卡片是点出来的，不是折叠的

下一张卡在点之前并不存在——这是 ChainCardView 原本的机制（opened as far as revealed）。所以屏幕上永远没有灰着的占位行。

第一层给题意，不给解法

知道问的是什么，但要自己想出怎么做——这才是复习的起点。题意是自己复述的一两句话：版权干净、离线可用，而且复述本身就是理解的检验。

题解就是 review.md

不存在单独的题解文件——原来的「复盘」写的本来就是「这题该怎么想、我当时怎么卡的」。界面上叫题解，文件名不动。里面 ==标记== 的橙色高亮是这份数据里最贵的部分。

热力图直连 LeetCode

绕过仓库，每次回到前台重新拉。断网时画上次的结果并标「数据截至 X 月 X 日」——不能画成空白，那会读成「没练习」。

没有评分按钮

手机上翻过的题不计入调度。这是换来「系统里只有一个调度器」的代价，是自愿付的。

数字是「待复习 / 总数」

不是进度条。绿色那个是现在等着你的，灰色那个是这一类一共有多少。沿用现有 HomeEntry 的 backlog / total。

分享三种卡片，留下三种积累

X 天内的成绩，用三个数字和热力图记下来；一道题想通了，分享题目、链接和自己的题解；一天结束，列出今天做过的题。三种图片统一使用 flomo 的深色卡片、字号、间距与低饱和绿色。

删除不再存在的界面

app 改成纯读之后失去理由的那些。视觉规范一个值都不动。

组件理由
SessionViewsession 是评分流程的容器。没有评分就没有 session，只有「翻到哪了」
GradeBar不再需要评分；扩展检测到 AC 后自动记录完成
SessionRunner / SessionBuilder同上
FSRS.swift / Grading调度只在扩展里跑一份：阶梯复习或轮次复习。app 只读到期日期排本地通知
SettingsView 的 session 长度app 唯一的那个旋钮，随 session 一起消失
Widget明确不做。放大器不是发动机——它放大已成立的习惯，造不出习惯。随时可补，零架构代价

HomeView 不是删，是改。 原来一行一个可以开 session 的 scope，现在变成抽屉：计数器 + 热力图 + 今天 + 四个维度的 # 列表。 点进某一行仍然是原封不动的串珠阅读体验。
