# 93. 复原 IP 地址 · 复盘

这是一个分割字符串的问题，分割点就是idx。五个部分，首先是**递归终止条件，**路径长度肯定不能超过4的，路径凑齐了4段数字，就停止继续切分，并且只有当用完字符串所有字符的时候（start = len(s)），才说ip合法，才能够存入结果表。然后**剪枝逻辑**，剩下的段数（4-len(path)），最少1位，最多3位，减少不必要的计算。然后是**横向切分循环**，如果切分的长度（start+size）比字符串总长还要长，直接结束循环。然后是**判断合法性**，排除不符合ip协议的数字，长度超过1位且以0开头，以及转换成整数之后>255，那么就是非法的。最后是**正常的回溯流程**。
