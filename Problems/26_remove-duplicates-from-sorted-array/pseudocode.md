# 26. 删除有序数组中的重复项 · 解题思路与伪代码

1. 一句话直击本质：使用双指针法遍历数组，逐步覆盖重复项以实现原地去重。

2. 综合思路：
   - 双指针法：使用两个指针（慢指针和快指针）遍历数组，慢指针指向去重后的数组末尾，快指针用于扫描整个数组。
   - 其他可能的思路（未在提供的代码中出现）：递归法、使用额外的数据结构（如集合）等，但这些方法通常不符合题目要求的原地修改和 $O(1)$ 空间复杂度。

3. 全量伪代码：
   ```
   定义函数 removeDuplicates(nums):
       初始化慢指针 slow 为 0
       遍历数组 nums，快指针 fast 从 0 到 len(nums) - 1:
           如果 nums[slow] 不等于 nums[fast]:
               将慢指针 slow 增加 1
               将 nums[slow] 赋值为 nums[fast]
       返回去重后数组的长度 slow + 1
   ```

4. 复杂度：
   - 时间复杂度：$O(n)$，其中 $n$ 是数组的长度，因为每个元素最多被访问两次。
   - 空间复杂度：$O(1)$，因为算法只使用了常数级别的额外空间。
