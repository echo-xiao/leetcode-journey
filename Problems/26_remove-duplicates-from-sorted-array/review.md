# 26. 删除有序数组中的重复项 · 复盘

看到这个题目的第一反应目前并不是快慢指针（which很有问题），但是因为已经 sorted 了，所以肯定是两个指针，但是可能没有反映出来为什么用快慢指针，因为没有想到快慢指针如何快速实现这个东西。快慢指针除检测是否有环，判断距离，还有一种方式就是array原地过滤和重建，若以如何看到array原地重组和构建，优先考虑快慢指针。快慢指针的核心不是交换，而是甄别和覆盖。这个里面慢指针用来施工，永远站在已经建成的、合格的新数组的最后一个元素上面，只有接到明确的指令才会移动，移动后立即接受一个新成员来扩大已经建好的array。而fast则是探路的，用来判断哪些是好东西，哪些是快东西，fast指针核心是做判断，没到一个新位置，就根据规则，判断是否是个好东西。好东西是fast发现的，符合保留条件的元素，好东西需要明确、主动的留下来，并且放在slow指针结果序列的末尾。发现了坏东西之后就直接跳过，被彻底忽略掉。所以这个里面更多的是覆盖，而不是交换。
