# 1073. 飞地的数量 · 要素

1. 节点与邻居：节点是网格里每个格子(r,c)，邻居是它上下左右四个格子，只有值为1的陆地格子之间才算连通。

2. 起点与终点：起点是所有位于第0行、最后一行、第0列、最后一列且值为1的边界陆地格子（多源）；没有终点，队列空了就结束，最后再扫全图数还剩多少个1就是答案。

3. visited 时机：格子一出队/一入队就直接把 grid[r][c] 改成 0 当作已访问标记，靠原地淹没代替额外 visited 数组，改过的格子不会再被当作陆地入队。

4. 是否分层：不用分层，这题只要把与边界相连的陆地全部淹掉，不关心走了几步，所以不需要记录层数。
