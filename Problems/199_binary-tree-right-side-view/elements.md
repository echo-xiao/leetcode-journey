# 199. 二叉树的右视图 · 要素

1. 函数定义：dfs(node, level)：node 是当前节点，level 是它所在的层号（根为0），函数本身不返回值，靠往外部 res 列表里追加值来记录每层第一个见到的节点。

2. base case：node 为空就直接 return，什么都不加；另外主函数里 root 为空直接返回空列表。

3. 单层主体：只看当前节点：如果 level == res.size()，说明这一层还没记过，就把 node.val 加进 res（因为先走右边，所以它就是该层最右），然后先递归右子节点、再递归左子节点，层号都 +1。

4. 代码位置：写在前序位置——必须进入子节点之前就判断并记录当前节点值，且顺序改成「右先左后」；BFS 写法则是每层出队完后取 vals 最后一个。
