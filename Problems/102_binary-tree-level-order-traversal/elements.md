# 102. 二叉树的层序遍历 · 要素

1. 函数定义：递归写法是 dfs(node, level)：node 是当前节点，level 是它所在层号（根为0），不返回值，靠往外部 res 里塞值来记录结果；迭代写法则只有主函数 levelOrder(root) 返回每层值的二维列表。

2. base case：node 为空就直接 return 什么也不做；另外主函数开头 root 为空时返回空列表 []。

3. 单层主体：看当前节点：如果 level 等于 res 的长度说明这层第一次到，先 append 一个空列表，然后把 node.val 放进 res[level]，再拿 level+1 去递归左右孩子。

4. 代码位置：写在前序位置——必须先把当前节点的值记进本层，再往下递归，这样同一层的值才是从左到右的顺序。
