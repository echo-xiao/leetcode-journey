# 2786. 找到最长的半重复子字符串 · 解题思路与伪代码

## 1. 一句话直击本质
用**滑动窗口**维护窗口内"相邻字符相等对"的数量，当该数量超过1时收缩左边界，从而找出最长的合法子串。

## 2. 综合思路
本题所有 AC 解法本质上都是**滑动窗口（双指针）**的思路，差异仅在于实现细节：

- **思路一：双指针 + 计数器（本题版本采用）**
  维护一个变量 `cnt` 记录窗口内出现"相邻两字符相同"的次数（即重复对个数）。每次右指针扩展时判断是否产生新的重复对，若窗口内重复对数超过 1，则收缩左指针直到重复对数 ≤ 1，过程中更新最大窗口长度。

- **思路二（常见变体，未在给出代码中但属于同类 AC 解法）**：
  预处理出所有"连续相同字符段"的分界点，把字符串分割成多个"块"，用双指针在块索引上滑动，保证窗口内相邻块之间因合并产生的重复对不超过 1 个，从而求最大窗口对应的字符长度。

两种思路复杂度相同，只是计数维度不同（字符位置 vs 块索引），核心都是单调双指针的滑动窗口。

## 3. 全量伪代码

```
函数 求最长半重复子串(s):
    left = 0
    cnt = 0          # 窗口内相邻相同字符对的个数
    maxlen = 0

    for right in [0, len(s)-1]:
        # 判断当前字符与前一个字符是否相同，若相同则重复对数加一
        if right > 0 and s[right] == s[right-1]:
            cnt += 1

        # 当窗口内重复对数超过1时，收缩左边界
        while cnt > 1:
            if s[left] == s[left+1]:
                cnt -= 1      # 移除左边界导致的一个重复对
            left += 1

        # 更新最大长度
        maxlen = max(maxlen, right - left + 1)

    return maxlen
```

## 4. 复杂度

- 时间复杂度：$O(n)$，其中 $n$ 为字符串长度，左右指针各遍历一次字符串，整体为线性双指针扫描。
- 空间复杂度：$O(1)$，只使用常数级别的额外变量（`left`, `cnt`, `maxlen`）。
