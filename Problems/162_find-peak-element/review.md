# 162. 寻找峰值 · 复盘

索引条件比较难理解和处理。==**1. 为什么是while left < right**==，而不是 left ≤ right，主要是==**防止死循环和越界保护**==，我们这个算法不是找到就返回，像找target一样，而是==**排除掉所有的不可能，剩下的那个就是答案**==，当left < right成立的时候，区间至少有两个元素，还能够继续且分，`但是当left == right时`，区间变成了一个点，所以不可能都派出，剩下的一个必定是峰值，此时循环结束，直接返回left即可，如果left≤right，`当left==right时还会进行循环`，执行right=mid，导致left和right永远相等，陷入死循环；==**两外一个原因就是防止mid+1越界**==，只要left<right，mid就永远不会去到right这个索引，它最大只能是倒数第二个元素，所以mid+1永远是安全的，绝对不会超出数组边界。2. ==**为什么是 mid 和 mid+1进行比较**==，因为如果和mid-1进行比较，会遇到两个问题，一个是越界报错，一个是死循环，主要是整数出发//2的偏向性，向下取整，所以导致mid偏左，所以总是向后面看 3. ==**下降阶段，right=mid**==，因为你在下坡，前面的位置比你脚下低，所以峰顶不可能在右边，但是mid可能就是峰顶 4. ==**同理上坡的阶段**==，既然前面比脚下高，所以mid绝对不是峰顶，峰顶一定再更加右边，大胆舍弃mid，选择mid+1.
