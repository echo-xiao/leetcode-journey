# 1737. 括号的最大嵌套深度 · 要素

1. 栈还是队列：用栈（后进先出），左括号压进去、右括号弹出最近那个，符合括号匹配的后进先出；其实只需要栈的大小，所以可以直接换成一个计数器。

2. 存什么：栈里存的就是左括号这个字符本身（占位用），真正有用的只是栈的高度，也就是当前嵌套层数；配对信息和下标都不需要，因为题目保证是有效的 VPS。

3. 进出时机：遇到 '(' 就入栈（或计数器 +1）并立刻用当前深度更新 maxDepth，遇到 ')' 就出栈（计数器 -1）；数字和 '+'、'-'、'*'、'/' 一律跳过。

4. 剩余元素含义：题目保证输入是有效括号表达式，所以遍历结束后栈必然是空的（计数器回到 0），没有剩余元素；答案是过程中记录的最大栈高 maxDepth，而不是结束时的栈内容。
