# 2337. 移除指定数字得到的最大结果 · 要素

1. 贪心策略：贪心目标是让删掉一个 digit 后剩下的等长字符串字典序最大：优先删第一个满足 number[i] < number[i+1] 的 digit 位置；如果所有 digit 都不小于其右邻（含末尾），就删最后一个 digit。代码里则直接枚举所有 digit 位置的删除结果取 max 来达到同样效果。

2. 局部最优判据：只看当前这个字符 number[i]==digit 和它右边一位 number[i+1]：如果 number[i] < number[i+1]，删它就能把更大的字符提前到这个高位，立刻变大，不用管后面还有几个 digit。

3. 正确性理由：删一个字符后长度固定为 n-1，所以字符串字典序比较就等于数值大小比较，越高位越大越好；第一个 number[i]<number[i+1] 的位置是删除后能让最高位发生提升的最靠前位置，任何更靠后的删法都改不动这一位，所以它一定不劣；若不存在这种位置，说明每个 digit 都不小于右邻，删除只会让高位变小或不变，那就删最后一个 digit 使受影响的位最靠后，损失最小。
