# 323. 无向图中连通分量的数目 · 复盘

两种方式，==**union find、遍历**==都能做，搜索的逻辑都差不太多，都是每个元素都要遍历，判断是否有新的元素没有遍历过，发现了cnt+=1，这样就能够得到一共有多少个group；==**union find 的逻辑就比较简单**==，找自己这个group的parent，有主体、find、union三个部分的逻辑，==**主体**==就是每个node就是一个连通分量，然后需要去union其他的连通分量，union的过程中，需要==**find的逻辑**==找到自己这个group的parent，并且进行路径压缩，这里是递归的逻辑，自己的parent要用递归来找到，==**union**==的话就是先判断，两个group是不是一个parent，是不需要做什么操作，不是就需要挂一个parent，然后cnt-=1。==**#unionFind**==
