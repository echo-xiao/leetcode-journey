# 112. 路径总和 · 复盘

**有两种方式，一种是累加，一种是递减。**假设累加，我出现的问题主要存在参数的参数传递机制、递归返回值、终止条件的判断。这个里面的semantics 就是，无论是递增还是递减，如果我想知道一颗树里面是否有一个路径能够满足路径和为targetSum，那么我需要判断左子树/右子树里面是否有一个路径能够满足路径和为targetSum’，这个targetSum‘代表着递归/递减之后值。那么这个核心就是左右子树的targetSum参数传递了。两种情况，如果是**递减**的话，参数的传递，其实利用主函数就可以了，但是如果是递增的话，就需要有新的辅助函数。如果是递减的话，主体就是targetSum‘ = targetSum - node.val，然后返回左子树或者右子树；termination case就是如果到叶子节点了，要去判断更新之后的targetSum’是否为0。**累加**的逻辑里面，难的一个点在于**状态隔离失败**。这个里面的知识点在于python中，函数内部的参数，引用的对象类型，可能会影响函数外部/递归函数的调用。**如果函数的参数是不可变类型，比如int、float、str、tuple，那么不能够原地修改，必须要将新的值显示的作为参数传给子调用。如果是可变类型，比如list、dict、set、object，那么可以在原地就下，对参数的修改会影响所有持有该对象引用的地方**。然后这个里面另外一个问题就是辅助函数返回值，**为什么不能够是更新后的累加的值**？因为返回累加值 1. 只能够返回一个路径的累加值，会丢失掉其他的路径 2. 主函数通过递归，只会返回一个最终结果，这个结果就是整个问题的答案。
