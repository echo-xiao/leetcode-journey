# 3627. 到达最后一个房间的最少时间 I · 要素

1. 图的表示：图是隐式的无向网格图，每个格子(r,c)是一个节点，上下左右相邻格子之间有边，不需要显式建图，用moveTime矩阵直接算边权

2. 遍历状态：用dist矩阵记录到每个房间的最短时间（相当于visited+距离记录合一），因为是求最短路不会走回头路成环，所以不需要onPath检环

3. 拓扑排序：本题不涉及拓扑排序，因为图是无向网格且存在环（可以来回走），不是DAG，不能用拓扑排序求解

4. 最短路松弛：dist矩阵初始化为正无穷，起点dist[0][0]=0，松弛时新时间newTime=max(当前时间d, moveTime[nr][nc])+1，如果newTime比dist[nr][nc]小就更新并把新状态压入优先队列，用Dijkstra的贪心方式保证每次弹出的都是当前最短的
