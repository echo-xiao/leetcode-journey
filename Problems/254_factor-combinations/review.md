# 254. 因子的组合 · 复盘

这个题目可以按照标准的回溯模板，但是这样的话就会非常耗时，所以要优化。==**1. 收集结果的位置改变了**==，不是到达叶子节点才收集，而是在循环内部就直接执行了 res.append(path + [ i, target // i ])，path 记录的是之前递归层级已经确定下来的因子，i 是当前层级正在吃尝试的较小因子，target//i 是与 i 配对的剩余部分（较大因子）；举个例子，对于合数12，当你找到因子2的时候，剩下的6自动生成组合[2,6]，不需要等递归到低部，这一对因子本身就是一个解。==**2. for loop 里面候选的范围改变**==，一般是给定数组/固定范围[1,n]或者动态范围[start, n]，但是这个动态范围变成[start, int(target**0.5)]，start 表示不回头看，int(target**0.5) 是利用了数学性质，如果 i 是starget的因子，那么 target//i 肯定也是 target 的因子，所以只要遍历到int(target**0.5)，剩下的大因子 target//i 肯定是作为尾巴直接被添加，或者继续被拆解。==**3. 数学运算是除法，target // i==，同时可以通过target//i 来引入大于根号的那个因子。
