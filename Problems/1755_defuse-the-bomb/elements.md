# 1755. 拆炸弹 · 要素

1. 定长还是变长：定长，窗口大小固定为 |k|（k>0 时是 i 后面的 k 个，k<0 时是 i 前面的 |k| 个），k=0 时窗口为空直接全填 0

2. 进窗口更新：i 每往右走一格窗口就跟着挪一格，k>0 时把新进来的 code[(i+k)%n] 加进和里，k<0 时把新进来的 code[(i-1+n)%n] 加进和里，用取模绕回数组开头

3. 出窗口时机：每次进一个就必须出一个来保持长度 |k|：k>0 时减掉刚滑出右侧窗口左端的 code[i]，k<0 时减掉 code[(i-1-|k|+n)%n]，减完窗口和就是当前位置对应的结果

4. 记结果时机：每完成一次“加新的、减旧的”之后立刻把当前窗口和写进 arr[i]，n 个位置各记一次，最后返回 arr
