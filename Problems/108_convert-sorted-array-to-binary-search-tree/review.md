# 108. 将有序数组转换为二叉搜索树 · 复盘

将有序的数组转换成二叉搜索树，两种方法，一种是是==**物理切分+前序遍历**==，直接利用python的切片功能，找到中间元素，这是新树的根节点；左边递归调用生成左子树，右边递归调用生成右子树，合并、返回的左子树和右子树分别连接到根节点的left和right指针。另外一种方式是==**索引移动+中序模拟**==，不切分数组，而是传递坐标（left，right），同时维护了一个全局指针self.index，先递归构建左子树（占位），中间创建根节点，再递归建右子树。

---

这个题目再数据结构上，其实就是中序遍历的逆向过程，但是从实际写代码的过程，是前序遍历模式。思考sementics，要把一个有序数组变成bst，那么先找root，然后左子树，然后右子树，这个里面找root就应该是在递归给左右子树之前，所以，走前序遍历，最后返回这棵树。不知道为啥，就是很难理解的感觉。
