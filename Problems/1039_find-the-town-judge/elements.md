# 1039. 找到小镇的法官 · 要素

1. 贪心策略：本题不涉及真正的贪心：没有排序也没有每步取最值，做法是把每条 trust[u][v] 记成 v 入度 +1、u 出度 +1，最后一次性挑出 indegree[i]==n-1 且 outdegree[i]==0 的人。

2. 局部最优判据：本题不涉及分步的局部最优；唯一的判定是遍历 1..n 时对单个 i 直接看两个计数是否满足「被所有其他 n-1 人信任且自己谁也不信」，这个判断只依赖已经统计完的全量度数，不是走一步选一步。

3. 正确性理由：正确性来自法官定义本身而非贪心交换论证：满足入度 n-1、出度 0 的人至多只有一个（若有两人，彼此都得信任对方，与出度 0 矛盾），所以一旦找到就是答案，找不到就返回 -1。
