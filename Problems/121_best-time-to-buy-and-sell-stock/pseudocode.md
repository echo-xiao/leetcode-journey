# 121. 买卖股票的最佳时机 · 解题思路与伪代码

## 1. 一句话直击本质

**贪心单调扫描**：遍历价格数组，动态维护"历史最低买入价"，实时计算当前卖出的最大利润差值。

## 2. 综合思路

所有版本本质相同，仅实现形式略有差异：

- **贪心迭代法（版本1/2/3/5/6）**：一次遍历，用两个变量分别追踪"当前遇到的最小价格"和"当前能获得的最大利润"，边扫描边更新，是最标准的AC解法。
- **递归法（版本4）**：将问题转化为"今天卖出的利润" vs "未来某天卖出的利润"取较大值，通过递归传递最小价格状态。本质是贪心思路的递归改写，但存在重复计算风险（未做记忆化，实际因为是线性递归无分支重复，等效于线性遍历）。

两类方法的时间复杂度相同，区别仅在于用循环还是递归实现"自左向右扫描并维护最小值"这一过程。

## 3. 全量伪代码

### （1）贪心迭代版（版本1/2/3/5/6通用逻辑）

```
函数 求最大利润(价格数组):
    最低价 = 正无穷 （或极大值）
    最大利润 = 0 （或 -1，最终不影响结果，因为会被合法差值覆盖）
    
    对于 价格数组中的每个价格 price:
        最低价 = min(最低价, price)          # 更新历史最低点
        当前利润 = price - 最低价             # 假设今天卖出
        最大利润 = max(最大利润, 当前利润)     # 更新全局最优
    
    返回 最大利润
```

### （2）递归版（版本4逻辑）

```
函数 求最大利润(价格数组):
    结果 = 递归求解(价格数组, 0, 正无穷)
    返回 max(0, 结果)

函数 递归求解(价格数组, 当前索引 i, 目前最低价 minPrice):
    如果 i == 数组长度:
        返回 0    # 递归终止，无更多利润可获得
    
    今日利润 = 价格数组[i] - minPrice           # 假设今天卖出
    新的最低价 = min(minPrice, 价格数组[i])
    未来利润 = 递归求解(价格数组, i+1, 新的最低价)  # 假设未来某天卖出
    
    返回 max(今日利润, 未来利润)
```

## 4. 复杂度

| 版本类型 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 贪心迭代法（1/2/3/5/6） | $O(n)$ | $O(1)$ |
| 递归法（版本4） | $O(n)$ | $O(n)$（递归调用栈深度为n，无显式记忆化数组） |

其中 $n$ 为价格数组 `prices` 的长度。

**补充说明**：递归版本虽然逻辑上是"树形"分叉（今日利润 vs 未来利润两条路径），但由于每层只有一次递归调用（无分支重复子问题），实际执行仍是线性时间 $O(n)$，只是多了递归栈的空间开销。
