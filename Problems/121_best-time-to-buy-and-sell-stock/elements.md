# 121. 买卖股票的最佳时机 · 要素

1. 状态：状态是遍历到第i天时，手上是否持有股票（或者简化为：截止到第i天为止出现过的历史最低价格）

2. 选择：第i天要么不操作（继续持有之前的最低价状态），要么用当天价格买入更新最低价，要么用当天价格卖出结算利润

3. dp 定义：dp[i]表示第i天卖出股票能获得的最大利润，等价于minPrice记录前i天（含第i天）出现过的最低价格，maxProfit记录截止第i天为止能获得的最大利润

4. base case：base case是第0天，minPrice初始化为prices[0]（或正无穷），maxProfit初始化为0，表示还没有任何交易发生

5. 遍历顺序：从左到右按天数递增的顺序遍历一次数组，因为每天的最低价和最大利润都依赖于前面所有天的结果
