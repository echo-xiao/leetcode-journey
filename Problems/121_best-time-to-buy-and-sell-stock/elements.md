# 121. 买卖股票的最佳时机 · 要素

1. 状态：走到第 i 天时，前面出现过的最低价 minPrice，以及到目前为止的最大利润 maxProfit。

2. 选择：在第 i 天要么把它当卖出日（赚 prices[i] - minPrice），要么不卖、只把它当新的可能最低买入价继续往后看。

3. dp 定义：maxProfit 表示只在前 i 天里完成一次买卖能拿到的最大利润；递归版 solve(i, minPrice) 表示从第 i 天起、已知历史最低价为 minPrice 时还能赚到的最大利润。

4. base case：minPrice 初始为正无穷、maxProfit 初始为 0（不交易就是 0 利润）；递归里 i 越过数组末尾时返回 0。

5. 遍历顺序：从左到右按天数 i=0 到 n-1 遍历一次，因为第 i 天的利润依赖的是它前面所有天的最低价。
