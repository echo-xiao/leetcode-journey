# 300. 最长递增子序列 · 要素

1. 状态：这道题用的是贪心+二分的变形DP，状态是tail数组当前的内容，代表各个长度递增子序列的最小结尾值，会随着遍历nums不断更新

2. 选择：对每个新元素num，选择是把它接到tail末尾（形成更长的子序列）还是替换tail中第一个大于等于它的位置（保持同长度但结尾更小，为后续留更多可能）

3. dp 定义：tail[i]定义为长度为i+1的递增子序列中，所有可能结尾里最小的那个值

4. base case：base case是tail初始只包含nums[0]一个元素，表示长度为1的子序列结尾是nums[0]

5. 遍历顺序：按nums数组的原始顺序从左到右遍历一遍，每个元素处理时前面的tail状态已经是当前最优的，直接二分查找更新即可
