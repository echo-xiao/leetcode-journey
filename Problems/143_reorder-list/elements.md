# 143. 重排链表 · 要素

1. 要不要 dummy：不需要 dummy——本题是原地重排，头结点始终是原来的 head，反转后半段和交替穿插都是直接改 next 指针，没有新建链表，边界靠「head 为空或只有一个节点直接返回」就够了。

2. 指针关系：fast 每轮走两步、slow 走一步，保持 fast 的步数是 slow 的两倍，这样 fast 到尾时 slow 正好停在前半段的最后一个节点上，slow.next 就是后半段的头，然后 slow.next=None 把两段断开。

3. 停止条件：循环条件是 fast 和 fast.next 都不为空，即 fast 走到最后一个节点（奇数长度）或走到空（偶数长度）就停；之后合并阶段的停止条件是 lst1 或 lst2 有一个为空。
