# 682. 棒球比赛 · 解题思路与伪代码

1. 一句话直击本质：使用栈数据结构逐步处理每个操作符以维护有效分数，并在最后计算总和。

2. 综合思路：
   - 迭代法：使用栈来模拟操作，遍历每个操作符，根据不同的操作符类型（数字、'D'、'C'、'+'）对栈进行相应的操作。
   - 递归法：虽然题目可以用递归实现，但在此代码集中未出现递归版本，通常递归不如迭代在此类问题中直观。

3. 全量伪代码：
   ```
   初始化一个空栈 stack
   对于每个操作符 num 在 operations 中：
       如果 num 是 'D'：
           弹出栈顶元素 prev
           将 prev 放回栈中
           将 prev 的两倍压入栈中
       如果 num 是 'C'：
           弹出栈顶元素
       如果 num 是 '+'：
           弹出栈顶元素 prev1
           弹出栈顶元素 prev2
           将 prev2 放回栈中
           将 prev1 放回栈中
           将 prev1 和 prev2 的和压入栈中
       否则：
           将 num 转换为整数并压入栈中
   返回栈中所有元素的和
   ```

4. 复杂度：
   - 时间复杂度：$O(n)$，其中 $n$ 是操作符的数量，因为每个操作符都需要常数时间进行处理。
   - 空间复杂度：$O(n)$，因为在最坏情况下，栈可能会存储所有的操作符。
