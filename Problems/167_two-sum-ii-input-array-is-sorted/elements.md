# 167. 两数之和 II - 输入有序数组 · 要素

1. 指针类型：用左右指针相向而行，left 从 0 开始、right 从 n-1 开始，靠数组已升序这个性质来收缩区间。

2. slow 含义：本题不涉及，因为这里不是原地覆盖/去重的快慢指针，没有「待写入位置」这回事。

3. 停止条件：当 left >= right（两指针相遇或交错）就停，循环条件写 left < right（写 <= 也行但同一个数不能用两次），中途只要 numbers[left]+numbers[right]==target 就直接返回 [left+1, right+1]，走完循环返回 [-1,-1]。
