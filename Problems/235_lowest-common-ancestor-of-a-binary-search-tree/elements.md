# 235. 二叉搜索树的最近公共祖先 · 要素

1. 函数定义：lowestCommonAncestor(root,p,q)：在以 root 为根的这棵搜索树里找 p、q 的最近公共祖先，返回那个祖先节点。

2. base case：root 为空就返回 None，表示这条路上没找到（题目保证 p、q 都在树里，实际走不到）。

3. 单层主体：拿 p.val、q.val 跟 root.val 比：都比它小就把答案交给左子树，都比它大就交给右子树，一大一小（或有一个等于 root）说明 root 就是分叉点，直接返回 root。

4. 代码位置：前序位置——先比较当前节点的值决定往哪边走，不需要等子树结果回来。
