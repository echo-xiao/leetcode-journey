# 216. 组合总和 III · 要素

1. 路径：path 里存的是已经选好的几个互不相同的数字，比如 [1,2,4]。

2. 选择列表：从 start 到 9 的数字，每层递归 start 变成 num+1 保证只往大的选、不重复；若 path 和加上 num 已超过 n 就直接 break 剪枝。

3. 结束条件：path 长度等于 k 且 path 元素和等于 n 时，把 path 的副本存进 res 并返回；数字用到 9 或和超了自然结束这层。

4. 撤销：递归返回后把刚加进 path 的 num 弹出去（同时若用变量累加和，也要把 num 从和里减掉），恢复到选它之前的状态。
