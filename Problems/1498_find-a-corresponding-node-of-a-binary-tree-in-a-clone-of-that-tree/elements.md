# 1498. 找出克隆二叉树中的相同节点 · 要素

1. 函数定义：dfs(p, q) 同时走原树的 p 和克隆树的 q，两者始终在同一位置，无返回值（也可以让它返回找到的克隆节点），找到时把 q 存进外部变量 res。

2. base case：p 或 q 为空就直接 return，什么都不做；顺带如果 res 已经找到也可以提前返回剪枝。

3. 单层主体：只判断当前的 p 是不是 target（比较引用相等），是就把对应的 q 记下来，然后分别递归 (p.left,q.left) 和 (p.right,q.right)。

4. 代码位置：写在前序位置——先判当前节点再往下递归，这样一命中就能直接返回，不用等子树算完。
