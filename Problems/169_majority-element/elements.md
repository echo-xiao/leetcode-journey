# 169. 多数元素 · 要素

1. 数学结构：多数元素出现次数超过 n/2，所以把它记 +1、其他元素记 -1，总和一定为正——这就是 Boyer-Moore 投票法能成立的依据：任何一次抵消都最多消掉一个多数元素和一个非多数元素，剩下的候选必是答案。

2. 枚举范围：不用枚举候选值，只需从头到尾扫一遍 nums，用 candidate 和 cnt 两个变量边走边更新；分治法则是按下标 mid 不断二分递归。

3. 数值边界：cnt 最大只到 n，n≤5万级别不会溢出、也不用取模；只需注意 cnt 为 0 时必须换候选，以及题目保证多数元素存在，所以不用额外验证 candidate。
