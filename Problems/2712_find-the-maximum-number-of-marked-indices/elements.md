# 2712. 求出最多标记下标 · 要素

1. 贪心策略：排序后，让左半部分最小的数尽量去匹配右半部分中刚好够用（不超过它两倍）的那个最小值，用双指针从左到右扫描配对

2. 局部最优判据：当前左指针指向的数 nums[left] 乘以2如果小于等于右指针指向的数 nums[right]，就立即配对标记两个下标，否则说明右边这个数太小不够用，右指针右移换更大的数再试

3. 正确性理由：因为数组已排序，若某个较大值能满足与当前最小值配对（2*nums[left]<=nums[right]），那它一定也能满足后面更大的左值，所以把最小的可行右值留给当前最小的左值不会浪费资源，反而给后续的左值留出更多更大的右值可选，这样贪心配对能使总配对数最多
