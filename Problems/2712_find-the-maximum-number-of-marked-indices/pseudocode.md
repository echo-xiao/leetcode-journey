# 2712. 求出最多标记下标 · 解题思路与伪代码

## 一、核心逻辑一句话总结

将数组排序后，用双指针贪心匹配"较小的前半部分"与"较大的后半部分"，使得较小值乘2不超过较大值即可配对标记，从而最大化标记的下标数量。

## 二、综合思路

本题所有 AC 解法本质上都基于同一贪心策略：**排序 + 双指针（二分查找辅助验证）**，主要有以下两种实现思路：

**思路一：双指针贪心（滑动窗口）**
- 排序后，将数组分为左半部分 `[0, n/2)` 和右半部分 `[n/2, n)`。
- 左指针从左半部分起始位置开始，右指针从右半部分起始位置开始。
- 若 `2*nums[left] <= nums[right]`，说明可以配对成功，标记数 +2，两指针同时右移。
- 否则右指针右移，寻找更大的数进行匹配。
- 该方法保证左半部分尽量匹配最小可行的右半部分值，从而给后续匹配留出更多空间（贪心性质）。

**思路二：二分答案 + 验证（二分法）**
- 二分枚举“最多能标记的对数” `k`（标记总数为 `2k`）。
- 验证：排序后判断前 `k` 小的数是否可以与后 `k` 大的数一一对应满足 `2*nums[i] <= nums[j]`。
- 找到满足验证条件的最大 `k`，结果为 `2k`。

两种思路本质相同，都利用了排序后局部有序性以及"小数尽量匹配次小可行大数"的贪心原理，双指针法是二分法的线性优化版本。

## 三、全量伪代码

**版本 A：双指针贪心法**

```
函数 求最多标记下标(nums):
    对 nums 进行升序排序
    n = nums长度
    left = 0
    right = n // 2
    ops = 0  // 记录标记的下标总数
    
    当 left < n//2 且 right < n:
        如果 2 * nums[left] <= nums[right]:
            ops += 2          // 成功配对，标记两个下标
            left += 1
            right += 1
        否则:
            right += 1        // 当前右边数不够大，尝试下一个
    
    返回 ops
```

**版本 B：二分答案法（等价逻辑，部分实现采用）**

```
函数 求最多标记下标(nums):
    对 nums 进行升序排序
    n = nums长度
    lo = 0, hi = n // 2
    
    当 lo < hi:
        mid = (lo + hi + 1) // 2
        如果 检查可行(nums, mid, n):
            lo = mid
        否则:
            hi = mid - 1
    
    返回 lo * 2

函数 检查可行(nums, k, n):
    对于 i 从 0 到 k-1:
        如果 2 * nums[i] > nums[n - k + i]:
            返回 False
    返回 True
```

## 四、复杂度分析

**双指针贪心法：**
- 时间复杂度：排序 $O(n \log n)$，双指针遍历 $O(n)$，总体 $O(n \log n)$
- 空间复杂度：$O(\log n)$（排序所需栈空间，视语言实现而定，若原地排序可视为 $O(1)$ 额外空间）

**二分答案法：**
- 时间复杂度：排序 $O(n \log n)$，二分查找 $O(\log n)$ 次，每次验证 $O(n)$，总体 $O(n \log n)$
- 空间复杂度：$O(\log n)$（排序栈空间）

**综合结论：**
$$\text{时间复杂度} = O(n \log n), \quad \text{空间复杂度} = O(\log n)$$
