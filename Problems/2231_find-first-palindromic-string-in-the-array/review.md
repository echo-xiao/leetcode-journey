# 2231. 找出数组中的第一个回文字符串 · 复盘

同样，披着双指针外衣的题目，遍历数组里面每个元素，判断对应的元素是否palindromic。判断是否palindromic这个里面就有tricks了。首先为什么要用这种tricks呢？这个里面只有一个函数，也就是firstPalindrome这个函数用来返回回文的，是没有额外的is_palindrome来判断true or false的。这个其实是一个主函数+辅助函数的套路。就是把问题分解了，那么什么情况下需要把问题分解呢？在这个里面，是需要进行连续判断，如果判断array里面某个元素，假设是回文返回就好，但是如果不是回文，也不能够直接返回false，需要继续下一个，那么是否可以用continue呢？不太行，因为在while的循环里面使用continue，只会跳过内层循环的本次迭代，进入while循环的下一次迭代，而不是跳到外层for循环找下一个元素。所以这个里面需要用布尔标记的方法。所以这个题目里面需要用到布尔标记的最主要原因是为了区分循环的退出方式，让外部代码也就是for loop能够清晰的了解到内部循环的执行结果，区分出来是循环的正常结束还是中途打断。
