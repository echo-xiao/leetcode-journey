# 138. 随机链表的复制 · 要素

1. 要不要 dummy：哈希表法不需要 dummy：新节点在第一次遍历时就按原节点一一建好了，最后直接返回 oldNode[head]，没有「往尾部追加」的边界问题（若改用原地穿插法，倒是可以拿个 dummy 接分离出来的新链表头）。

2. 指针关系：本题不涉及快慢指针的步数差：两次遍历都是一个 curr 单步走，两趟之间的关系靠哈希表 oldNode 把原节点映射到新节点，而不是靠指针间距。

3. 停止条件：两次遍历都是 while curr != null 时走完整条链，遍历中对 curr.next / curr.random 判空后才去哈希表取对应新节点，最后返回 oldNode[head]（head 为空直接返回空）。
