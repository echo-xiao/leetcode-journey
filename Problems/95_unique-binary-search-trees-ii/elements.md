# 95. 不同的二叉搜索树 II · 要素

1. 状态：状态是当前处理的连续数字区间的长度length，以及区间内选谁做根节点j（j从1到length）

2. 选择：每个状态下的选择是：从当前区间里挑一个数字j当根节点，剩下的数字分成左边j-1个、右边length-j个分别构成左右子树

3. dp 定义：dp[length]表示由length个连续数字（1到length，实际用时会整体偏移）能组成的所有不同二叉搜索树的列表

4. base case：base case是dp[0]=[None]，表示0个节点时子树为空

5. 遍历顺序：按照子树长度length从1到n从小到大遍历，因为构建长度为length的树需要用到更短的dp[j-1]和dp[length-j]，必须先算完短的
