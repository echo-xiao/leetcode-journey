# 114. 二叉树展开为链表 · 要素

1. 函数定义：flatten(root)：把以 root 为根的子树原地改成「只有右指针」的前序链表，不返回值，只靠外部变量 prev 记住上一个已处理好的节点（也就是当前链表的头）。

2. base case：root 为空就直接 return，什么都不做，prev 保持不变。

3. 单层主体：假设左右子树都已经被拉成链表了，当前节点只做三件事：root.right = prev、root.left = null、prev = root。

4. 代码位置：写在后序位置，而且递归顺序要反过来先右再左（右→左→处理自己），这样 prev 始终是前序序列里紧跟在 root 后面的那个节点。
