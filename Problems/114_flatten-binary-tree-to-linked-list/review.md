# 114. 二叉树展开为链表 · 复盘

==**version 3: **==有三种流派，==**第一种流派是递归思维**==；==**变形后序遍历（reverse pre order）**==，递归顺序 right→left→root，维护全局prev；==**分治法-找尾巴**==，flatten(left)→ flatten(right)→把左边插到右边→while循环找尾巴接上原来的右边。==**分治法-返回尾巴**==，递归函数不返回void而是返回tail节点；==**第二流派：迭代思维**==，==**标准stack的迭代**==，stack存节点，先压右，再压左，pop出来直接连prev；==**列表缓存 list brute force**==，先遍历一遍list，再for循环连起来；最后一个派别，==**空间极致优化，morris遍历变种（寻找前驱**==），没有stack/recursive，找到左子树最右节点，然后把右子树接过去。以及==**version 2: **==有三种流派，核心都是解决“为了连接上左子树，必须乳钙root.right指针，但是原来的右子树不能丢”的问题。为了解决这个矛盾，衍生出了三种策略，==**1. 空间换时间，存起来，**==用stack/列表把右子树存着，等左边处理完了再弹出来接上，是标准的迭代法、列表法；2. ==**时间换空间，移花接木，**==把右子树嫁接到左子树的右下角，那个位置也就是前序遍历中左子树的最后一个节点，物理上暂时存放在树的底部，也就是morris、找尾巴法；3. 最后一个是==**逆向思维**==，是倒着来的，既然正向走会覆盖有指针，那么就从右往左倒着处理，先把右子树处理完变成链表，即使指针断了也无所谓，因为已经处理完了，也就是变形后续遍历。==**version 1: **==有三种解法，==**第一种是暴力解法**==，前序遍历重组，a. 先存后连，用stack把节点按照顺序一个个存进list，然后遍历list重新连起来，b. 边走边连，用stack存左孩子和右孩子，每次pop出来一个，就直接用prev.right连上去。==**第二种是倒序递归法**==，因为是倒着来的，所以我们总是先处理完链表的尾巴，维护一个prev指针，每次把curr.right指向prev，然后prev往前移。==**第三种是寻找前驱节点的方法**==，不用stack，不用递归，找到左子树最右下角的那个节点（前驱），把根节点的右子树嫁接过去，然后把左子树挪到右边。
