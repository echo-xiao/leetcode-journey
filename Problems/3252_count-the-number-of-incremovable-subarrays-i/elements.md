# 3252. 统计移除递增子数组的数目 I · 要素

1. 指针类型：这里用的是左右指针（i 指向前缀递增末尾 l，j 指向后缀递增起点 r），但不是相向而行去缩小区间，而是各自独立找到最长递增前缀和最长递增后缀的边界，再用双指针（i 从0到l，j 从r开始随i增大而右移）配合统计满足条件的组合数。

2. slow 含义：本题不涉及快慢指针的写入场景，因为不是原地覆盖数组元素，而是找递增前缀/后缀的边界下标（l 和 r），slow 这个含义在此题不适用。

3. 停止条件：停止条件是遍历越界：从左到右遍历直到发现 nums[i]>=nums[i+1] 停止得到 l，从右到左遍历直到发现 nums[j-1]>=nums[j] 停止得到 r，内层指针 j 则在 j<n 且 nums[i]>=nums[j] 时持续右移，直到条件不满足或 j 越界为止。
