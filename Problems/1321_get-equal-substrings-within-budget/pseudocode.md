# 算法分析：尽可能使字符串相等

## 1. 一句话直击本质
**滑动窗口**：维护一个字符差值总和不超过 maxCost 的最长连续子串，通过双指针动态调整窗口边界。

## 2. 综合思路
本题核心是求满足"窗口内代价总和 ≤ maxCost"约束下的最长子数组，属于经典**同向双指针（滑动窗口）**问题。

- **核心思路**：右指针不断扩张窗口、累加代价；当代价超限时，左指针收缩窗口直到满足约束；过程中持续记录最大窗口长度。
- **同类变体思路**（本题AC解法中常见但未在给定代码中出现的）：
  - **前缀和 + 二分查找**：先计算差值数组的前缀和，对每个右端点二分查找满足条件的最左左端点，时间复杂度 $O(n\log n)$。
  - **前缀和 + 双指针**：与滑动窗口思想一致，只是用前缀和数组辅助计算区间和。

给定代码属于**滑动窗口（双指针）**解法，是本题的最优解法。

## 3. 全量伪代码

### 解法一：滑动窗口（双指针）
```
函数 equalSubstring(s, t, maxCost):
    left ← 0
    总代价 ttl ← 0
    最大长度 maxlen ← 0
    
    对 right 从 0 到 s长度-1:
        ttl ← ttl + |s[right] 的ASCII码 - t[right] 的ASCII码|
        
        当 ttl > maxCost 时:
            ttl ← ttl - |s[left] 的ASCII码 - t[left] 的ASCII码|
            left ← left + 1
        
        maxlen ← max(maxlen, right - left + 1)
    
    返回 maxlen
```

### 解法二：前缀和 + 二分查找（常见变体，供参考）
```
函数 equalSubstring(s, t, maxCost):
    计算差值数组 diff[i] = |s[i] - t[i]|
    计算前缀和数组 prefix，其中 prefix[i] = diff[0] + ... + diff[i-1]
    
    maxlen ← 0
    对 right 从 0 到 n:
        目标值 target ← prefix[right] - maxCost
        使用二分查找在 prefix[0..right] 中找到第一个 >= target 的位置 left
        maxlen ← max(maxlen, right - left)
    
    返回 maxlen
```

## 4. 复杂度

### 滑动窗口解法（给定代码）
- 时间复杂度：$O(n)$，左右指针各自最多遍历一次字符串
- 空间复杂度：$O(1)$，只使用常数额外变量

### 前缀和 + 二分查找解法
- 时间复杂度：$O(n \log n)$，对每个右端点进行一次二分查找
- 空间复杂度：$O(n)$，需要额外的前缀和数组

**综合结论**：滑动窗口解法是本题的最优解，时间复杂度为线性 $O(n)$，空间复杂度为常数 $O(1)$，充分利用了"窗口扩张单调递增代价，收缩单调递减代价"的性质，避免了重复计算。
