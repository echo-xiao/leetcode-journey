# 3193. 找出强数对的最大异或值 I · 要素

1. 定长还是变长：本题本质是排序后双指针维护变长窗口，窗口条件是nums[r]<=2*nums[l]，属于变长窗口

2. 进窗口更新：排序后固定右端点r向右扩展（r从0到n-1遍历），每次r增加就把nums[r]纳入考虑范围

3. 出窗口时机：左指针l从0扫到r，只要nums[r]<=2*nums[l]就说明l及其右边的数都满足条件（因为已排序），不满足条件的l被排除出有效窗口，不需要额外维护数据只是筛选范围

4. 记结果时机：每当找到满足nums[r]<=2*nums[l]的数对时，立即计算nums[l]异或nums[r]并与max_res比较更新
