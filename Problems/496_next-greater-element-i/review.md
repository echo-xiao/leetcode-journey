# 496. 下一个更大元素 I · 复盘

这个题目是单调栈最经典的题目，就是让你找每个元素右边第一个最大的元素，其实正着和倒着都可以，但是倒着来更加方便理解，倒着来可以理解成开口向着左边的stack，最底部的是最右边的元素。**这个题目的语义是说，**遍历的每个元素就可以跟stack top 进行pk，如果元素pk top赢了，就说明这个top不行，就要pop掉，然后换后面的试试，如果元素 pk top输了，就说明这个top就是该元素右边第一个最大的元素，需要把这个答案加入到结果表里面。但是我可能在**翻译成伪代码的时候**没有翻译好，可以理解还是不太懂计算机里面状态的转变。涉及到：判断条件-逻辑处理-状态恢复，这三个步骤，先不要去想直接加入到stack里面，先判断pk条件，赢了就存起来，输了就pop出去，然后对应的条件有不同的逻辑处理方式，最后再恢复状态进行append。另外一个问题，优先写失败的逻辑还是成功的逻辑，**while loop 和 for loop 的时候，都需要优先失败的逻辑**，这是清洁状态的动作。
