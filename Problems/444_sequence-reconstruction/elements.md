# 444. 序列重建 · 要素

1. 图的表示：用邻接表 adj 表示有向图，节点是 1~n（nums 里的数字），边是每个 sequences 里相邻元素 (u,v) 的先后关系。

2. 遍历状态：不用 visited/onPath 检环，而是用 indegree 数组记录每个节点入度，靠入度是否变 0 来判断节点能否入队。

3. 拓扑排序：需要，用 Kahn 入度法做 BFS 拓扑排序，且每一步要求队列里只能有一个入度为0的节点（否则说明顺序不唯一），跑完后把结果序列 res 和 nums 逐一比较判断是否唯一重建成功。

4. 最短路松弛：本题不涉及，因为这题只关心拓扑顺序是否唯一确定，不涉及边权和最短路径计算。
