# 19. 删除链表的倒数第 N 个结点 · 复盘

先要知道如何remove正向数起第n个数，然后再做remove后面数起第n个数，所以先做203、remove linked list element。这个题目**首先**明确要用快慢指针来解决，快指针在慢指针前面n个。**其次**，快指针不要太快，快指针如果为none的话，慢指针刚好停在倒数第n个node上面，但是删除的时候，慢指针需要在倒数第n个node前面，然后删除后面这个node。并且，考虑删除的是第一个节点，这种时候，就需要用到dummy head。**以及**，探路指针是fast，要用fast来决定循环什么时候停止，**最后**，删除操作，不是在循环中每次都判断，而是等循环结束之后，slow找到了正确位置，只需要做一次就好了。
