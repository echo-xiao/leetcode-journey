# 3463. 交替组 I · 解题思路与伪代码

1. 一句话直击本质：通过遍历颜色数组的扩展版本，检查每三个连续元素是否构成交替组来计数。

2. 综合思路：
   - 迭代法：通过将原数组扩展前两个元素到末尾，使用迭代遍历检查每三个连续元素是否满足交替条件。

3. 全量伪代码：
   ```
   定义函数 numberOfAlternatingGroups(colors):
       创建新数组 arr 为 colors 的副本并在末尾添加 colors 的前两个元素
       初始化计数器 cnt 为 0
       
       对于 l 从 0 到 arr 的长度减去 2:
           如果 arr[l] 不等于 arr[l+1] 且 arr[l+1] 不等于 arr[l+2]:
               将 cnt 增加 1
       
       返回 cnt
   ```

4. 复杂度：
   - 时间复杂度：$O(n)$，其中 $n$ 是输入数组的长度，因为需要遍历数组一次。
   - 空间复杂度：$O(n)$，因为创建了一个新的数组来存储扩展后的颜色序列。
