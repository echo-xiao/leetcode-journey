# 有效三角形的个数 - 算法分析

## 1. 一句话直击本质
**排序后固定最大边，用双指针在剩余区间内统计满足"两边之和大于第三边"的组合数，实现 $O(n^2)$ 求解。**

## 2. 综合思路

两个版本代码逻辑完全一致，均采用**排序 + 双指针（固定最大值）**的解法：

- **核心思想**：三角形成立的充要条件（在三边非负前提下）只需保证 **较小两边之和 > 最大边**。因此先排序数组，从后往前枚举最大边 `nums[i]`，在 `[0, i-1]` 区间内用左右指针 `left/right` 寻找满足条件的组合。
- **双指针收缩逻辑**：
  - 若 `nums[left] + nums[right] > nums[i]`：说明以 `right` 为右边界、`left` 到 `right-1` 之间的所有元素与 `right` 组合都满足条件（因为数组升序，缩小 `left` 只会让和更大），一次性累加 `(right - left)` 个组合，然后 `right--`。
  - 否则说明和不够大，需要增大 `left` 来增大和，`left++`。
- 该思路避免了纯粹枚举三元组的 $O(n^3)$，通过排序的单调性把内层判断降为线性双指针扫描。

（两个版本无实质差异，仅是相同解法的重复提交。）

## 3. 全量伪代码

```
函数 triangleNumber(nums):
    对 nums 进行升序排序
    n ← nums 长度
    cnt ← 0

    for i from n-1 down to 2:          # 固定最大边为 nums[i]
        left ← 0
        right ← i - 1
        while left < right:
            if nums[left] + nums[right] > nums[i]:
                # 此时 left 到 right-1 与 right 都能构成三角形
                cnt ← cnt + (right - left)
                right ← right - 1
            else:
                left ← left + 1
    return cnt
```

## 4. 复杂度

- **时间复杂度**：排序 $O(n\log n)$，双重循环（外层枚举 + 内层双指针总共线性扫描）为 $O(n^2)$，整体：
$$O(n^2)$$

- **空间复杂度**：仅使用常数额外变量（排序原地进行）：
$$O(1)$$
