# 173. 二叉搜索树迭代器 · 要素

1. 函数定义：这题不用递归函数，核心是辅助方法 _push_left(node)：把从 node 开始一路向左的所有节点压栈，无返回值，栈顶始终是当前未访问的最小节点；next() 返回下一个最小值，hasNext() 返回栈是否非空。

2. base case：_push_left 里 node 为空就停止压栈（while node 循环自然结束）；对应地 hasNext() 在栈空时返回 false，表示遍历完了。

3. 单层主体：next() 里只做三件事：弹出栈顶节点 node，若它有右孩子就对右孩子调 _push_left，然后返回 node.val——左子树已经在之前压栈时处理完了。

4. 代码位置：中序：栈顶弹出即“访问当前节点”，弹出前左边全压完（左），弹出后再展开右子树（右），正好是左-根-右的迭代版。
