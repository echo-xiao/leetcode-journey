# 173. 二叉搜索树迭代器 · 解题思路与伪代码

### 一句话直击本质
使用栈模拟中序遍历，逐步访问二叉搜索树的下一个最小节点。

### 综合思路
在给定的代码集中，只有一种解法，即使用迭代方式和栈数据结构来实现二叉搜索树的中序遍历。具体思路如下：
1. **迭代法**：利用栈来模拟递归中序遍历的过程。初始化时，将所有左子节点压入栈中。每次调用 `next()` 方法时，弹出栈顶节点，并将其右子树的所有左子节点压入栈中。`hasNext()` 方法则检查栈是否为空。

### 全量伪代码
```plaintext
类 BSTIterator:
    方法 初始化(root):
        初始化一个空栈 stack
        调用 _push_left(root)

    方法 _push_left(node):
        当 node 非空时:
            将 node 压入 stack
            node 移动到其左子节点

    方法 next() -> int:
        从 stack 弹出一个节点 node
        如果 node 有右子节点:
            调用 _push_left(node 的右子节点)
        返回 node 的值

    方法 hasNext() -> bool:
        返回 stack 是否非空
```

### 复杂度
- 时间复杂度：$O(1)$ 平均情况下每次调用 `next()` 的时间复杂度为常数，因为每个节点最多被压入和弹出栈一次。
- 空间复杂度：$O(h)$，其中 $h$ 是树的高度，栈的空间复杂度取决于树的高度。
