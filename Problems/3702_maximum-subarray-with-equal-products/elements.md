# 3702. 最长乘积等价子数组 · 要素

1. 定长还是变长：变长窗口，窗口大小随着质因子冲突动态调整，不是固定长度

2. 进窗口更新：right从0遍历到n-1，每加入nums[right]就分解它的质因子，并把这些质因子的出现次数加一（同时记录质因子来源的计数）

3. 出窗口时机：当加入nums[right]导致某个质因子在窗口内出现次数大于1（说明窗口内存在两个数不互质）时，就不断移动left，把nums[left]的质因子计数减一，直到窗口内所有质因子计数都不超过1

4. 记结果时机：每次right移动完成、窗口调整合法后，用right-left+1更新最大长度max_pairwise_coprime_len，最后返回时和2取最大值
