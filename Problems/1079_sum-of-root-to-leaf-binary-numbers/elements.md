# 1079. 从根到叶的二进制数之和 · 要素

1. 函数定义：dfs(node, ttl)：ttl 是从根走到 node 父节点已经拼好的二进制数值，返回值是以 node 为根、这条路径继续走到各叶子所得二进制数的总和（版本1则用外部 res 累加，无返回值）。

2. base case：node 为空时返回 0（版本1直接 return，不累加），因为空节点没有路径也不算叶子。

3. 单层主体：先把当前节点并入路径：ttl = ttl*2 + node.val；若左右孩子都为空说明是叶子，直接返回/累加 ttl；否则把新 ttl 传下去，返回左右子树结果之和。

4. 代码位置：前序位置——必须先用父节点传来的 ttl 更新出当前值，再往下递归；叶子判断和求和顺带在向下的路上完成。
