# 118. 杨辉三角 · 要素

1. 状态：当前在算第几行 i、这行的第几个位置 j，也就是二维坐标 (i, j)。

2. 选择：本题没有真正的“选择”，第 i 行第 j 个数只有一种算法：要么它是行首行尾填 1，要么等于上一行 j-1 和 j 两个数相加。

3. dp 定义：dp[i][j] 就是杨辉三角第 i 行第 j 列的那个数字，整个 dp 二维数组就是最终答案。

4. base case：dp[0] = [1]（第一行只有一个 1），并且每行的首尾 dp[i][0] = dp[i][i] = 1。

5. 遍历顺序：行从上往下 i 从 1 到 numRows-1，每行内 j 从左到右，这样算 dp[i][j] 时上一行 dp[i-1][j-1] 和 dp[i-1][j] 已经算好了。
