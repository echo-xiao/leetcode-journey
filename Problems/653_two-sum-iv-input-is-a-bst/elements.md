# 653. 两数之和 IV - 输入二叉搜索树 · 要素

1. 函数定义：traverse(node, k, res) 表示以node为根的子树中，是否存在一个节点值等于k减去res集合中某个已访问值，返回True/False表示是否找到符合条件的两数之和

2. base case：当node为空时返回False，表示空节点不可能凑出目标和

3. 单层主体：先判断k-node.val是否已经在res集合里，是就直接返回True，否则把node.val加入res集合，再分别递归左右子树看是否找到，最后返回left或right的结果

4. 代码位置：前序位置，因为要先处理当前节点（判断+加入集合）再递归左右子树，保证子树递归时集合里已包含祖先和之前兄弟节点的值
