# 1993. 找出所有子集的异或总和再求和 · 解题思路与伪代码

1. 一句话直击本质：利用回溯法遍历所有子集，计算每个子集的异或和，并累加到结果中。

2. 综合思路：
   - 递归回溯法：通过递归遍历所有可能的子集，分别计算每个子集的异或和，并将结果累加到最终结果中。
   - 递归分支选择：在递归过程中，对于每个元素都有两种选择：要么包含在当前子集中，要么不包含，从而形成所有可能的子集。

3. 全量伪代码：
   ```
   定义函数 subsetXORSum(nums):
       初始化结果 res 为 0
       调用回溯函数 backtrack(索引 0, 当前异或和 0)
       返回结果 res

   定义回溯函数 backtrack(当前索引 idx, 当前异或和 curr):
       将当前异或和 curr 加入到结果 res 中
       对于从当前索引 idx 到数组末尾的每个元素 i:
           递归调用 backtrack(索引 i+1, 当前异或和 curr 异或 nums[i])
   ```

4. 复杂度：
   - 时间复杂度：$O(n \times 2^n)$，因为每个元素都有两种选择（包含或不包含），总共有 $2^n$ 个子集，每个子集的异或和计算需要 $O(n)$ 的时间。
   - 空间复杂度：$O(n)$，递归调用栈的深度最多为 $n$。
