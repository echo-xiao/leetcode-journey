# 验证回文串 算法分析

## 1. 核心逻辑

**过滤非字母数字字符并统一大小写后，使用双指针从两端向中间比较，判断字符序列是否对称。**

## 2. 综合思路

两个版本采用完全相同的算法思路，均分为两个阶段：

- **预处理阶段**：遍历原字符串，利用 `isalnum()` 过滤出字母和数字字符，并统一转换为小写，生成一个只包含有效字符的"干净字符串"。
- **判断阶段**：使用双指针（左指针从头、右指针从尾）向中间靠拢，逐一比较对应位置字符是否相等。

两版本的差异仅在于字符串拼接写法（`+=` vs `+`）和判断分支顺序（先判断不等 vs 先判断相等），核心算法逻辑完全一致，未出现递归、栈等其他解法变体。

## 3. 全量伪代码

```
函数 isPalindrome(s):
    初始化 clean 为空字符串
    
    // 第一阶段：过滤与标准化
    对 s 中的每个字符 c:
        如果 c 是字母或数字:
            将 c 转为小写并追加到 clean

    // 第二阶段：双指针判断回文
    left ← 0
    right ← clean 长度 - 1
    
    当 left < right 时:
        如果 clean[left] 不等于 clean[right]:
            返回 False
        否则:
            left ← left + 1
            right ← right - 1
    
    返回 True
```

## 4. 复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 为字符串长度。过滤阶段遍历一次字符串，双指针比较阶段最多遍历 $n/2$ 次。

- **空间复杂度**：$O(n)$，需要额外的 `clean` 字符串存储过滤后的字符（原地双指针本身仅需 $O(1)$ 辅助空间，但因预处理生成了新字符串，故整体为线性空间）。
