# 1570. 商品折扣后的最终价格 · 要素

1. 单调方向：栈里从栈底到栈顶保持价格严格递增（正序做法），也就是遇到比栈顶小或等于的价格就把栈顶清掉，保证栈内是一串越来越大的待结算价格。

2. 存下标还是值：正序做法存下标，因为弹栈时要回到 answer[i] 上做减法；倒序做法可以只存价格值，因为答案直接写在当前下标上。

3. 弹栈条件：正序：while 栈非空且 prices[栈顶] >= 当前 prices[i] 就弹出，弹出的那个商品的折扣就是 prices[i]；倒序：while 栈非空且栈顶价格 > 当前价格就丢掉（它不可能当折扣）。

4. 遍历方向：两种都行——正序遍历是「我给前面等着的人发折扣」，倒序遍历是「我从后面留下的候选里找折扣」，本题推荐正序，一次减法即可。
