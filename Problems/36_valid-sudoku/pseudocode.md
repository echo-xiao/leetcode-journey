# 36. 有效的数独 · 解题思路与伪代码

## 1. 一句话核心逻辑

用哈希集合（或等价的计数结构）分别记录每行、每列、每个 3×3 宫格中已出现的数字，遍历棋盘时若发现重复则判定无效。

## 2. 综合思路

虽然本题只给出一个版本，但该类题目的 AC 实现通常可归纳为以下几种等价思路：

- **哈希集合法（本版本）**：为每行、每列、每个宫格各建一个 `set()`，遍历过程中检查当前数字是否已存在于对应集合中。
- **二维数组/计数矩阵法**：用 `int[9][9]` 的计数数组代替集合，`rows[r][num]++`，通过计数是否 >1 判断重复，避免哈希开销。
- **位运算（bitmask）法**：用一个整数的 9 位表示 1-9 是否出现，通过位与操作 `(mask >> num) & 1` 判断重复，效率更高、空间更省。
- **一次遍历合并判断法**：将行、列、宫格的标记合并为一个字符串键（如 `f"{val}_row{r}"`），存入同一个 set 中，通过字符串是否重复判断冲突，代码更简洁但性能略低。

这些思路本质相同：**用某种结构记录已出现的数字并检测冲突**，区别仅在于数据结构的选择（set/数组/位运算）。

## 3. 全量伪代码

```
函数 判断数独是否有效(board):
    初始化 9 个行记录结构 rows[0..8]
    初始化 9 个列记录结构 cols[0..8]
    初始化 9 个宫格记录结构 boxes[0..8]

    对每个格子 (r, c) 遍历棋盘:
        val = board[r][c]
        如果 val 是 '.':
            跳过

        计算宫格编号 box = (r // 3) * 3 + (c // 3)

        如果 val 已存在于 rows[r]:
            返回 False
        否则:
            将 val 加入 rows[r]

        如果 val 已存在于 cols[c]:
            返回 False
        否则:
            将 val 加入 cols[c]

        如果 val 已存在于 boxes[box]:
            返回 False
        否则:
            将 val 加入 boxes[box]

    返回 True
```

（若采用计数数组或位运算实现，仅将“集合添加/查询”替换为“计数自增并检查是否>1”或“位运算置位并检查是否已置位”，整体流程一致。）

## 4. 复杂度

设棋盘大小为固定的 $9 \times 9$（更一般地记 $n=9$）：

- **时间复杂度**：$O(n^2)$，需要遍历所有 $81$ 个格子各一次。
- **空间复杂度**：$O(n^2)$，需要维护 $27$ 个大小不超过 $9$ 的集合（或等价的计数/位结构），整体为常数级 $O(1)$（相对于输入规模固定时）。

即：
$$
\text{时间复杂度} = O(n^2), \quad \text{空间复杂度} = O(n^2) \; (\text{固定 9×9 时视为 } O(1))
$$
