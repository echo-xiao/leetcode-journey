# 226. 翻转二叉树 · 复盘

**有四种方式，前序、中序、后序、层序，中序会比较麻烦**，因为会同时调整左右指针。但是这个里面有两种方式，分别是**赋值、和交换指针**：两者都能够反转二叉树，但是他们在逻辑上的意义是不一样的。root.left = rightInvert，root.right = leftInvert ，这是**赋值，我等着我的孩子们处理好，然后我再把他们放在我新的位置上；**另外一种是**交换指针** root.left, root.right = root.right, root.left，**我先把我自己换号位置，然后让我的孩子们去处理他们的新的子树。后序**，先搞定子孙，最后根节点交换。**前序**，先根节点交换，再让子孙去搞。**层序**，用队列，一层层处理，工业界写法，比边递归爆栈。**中序**，容易出错，不推荐。
