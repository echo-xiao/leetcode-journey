# 151. 反转字符串中的单词 · 解题思路与伪代码

# 反转字符串中的单词 - 算法分析

## 1. 核心逻辑（一句话）
将字符串按空白分割成单词序列，去除多余空格后**反转单词顺序**再拼接。

## 2. 综合思路

本题常见 AC 解法可分为以下几类：

- **库函数法**：利用语言内置的 `split()`（按空白自动切分并忽略多余空格）与 `reverse` 操作，再 `join` 拼接，代码最简洁（即本题给出的版本，通过手动扫描实现了类似 split 的效果）。
- **双指针/原地反转法（O(1)额外空间，多用于 C++/Java char[]）**：
  1. 先反转整个字符串；
  2. 再反转每个单词内部字符顺序；
  3. 使用双指针清理多余空格（首尾空格、单词间多个空格压缩为一个）。
- **栈/列表暂存法**（本题版本即属此类）：正向遍历字符串，用临时变量收集非空格字符组成单词，遇到分隔符则将单词压入列表，最终反转列表并用空格连接。

## 3. 全量伪代码

### 类型一：分割-反转-拼接法（本题版本对应逻辑）
```
函数 reverseWords(s):
    在 s 末尾添加一个空格，方便统一处理最后一个单词
    初始化 临时字符串 tmp = ""
    初始化 单词列表 lst = []
    
    遍历 s 中每个字符 c:
        如果 c 不是空格:
            将 c 追加到 tmp
        否则（c 是空格）:
            如果 tmp 非空:
                将 tmp 加入 lst
                重置 tmp = ""
    
    将 lst 反转
    用空格连接 lst 中所有单词
    返回结果字符串
```

### 类型二：原地双指针法（O(1)空间通用思路）
```
函数 reverseWords(s):
    去除首尾空格
    将中间多个连续空格压缩为一个空格
    反转整个字符串
    对每个单词（以空格分隔）反转其内部字符
    返回处理后的字符串
```

### 类型三：内置函数法（多语言通用简洁写法）
```
函数 reverseWords(s):
    words = s.split()   // 自动去除多余空格并分割
    words.reverse()
    返回 " ".join(words)
```

## 4. 复杂度分析

| 解法类型 | 时间复杂度 | 空间复杂度 |
|---------|-----------|-----------|
| 分割-反转-拼接法（本题版本） | $O(n)$ | $O(n)$ |
| 原地双指针法 | $O(n)$ | $O(1)$（不计返回结果） |
| 内置函数法 | $O(n)$ | $O(n)$ |

其中 $n$ 为字符串 `s` 的长度。

- **时间复杂度**：所有方法均需遍历字符串常数次，故为 $O(n)$。
- **空间复杂度**：除原地反转法可做到 $O(1)$ 额外空间外，其余方法均需额外的列表/临时字符串存储单词，空间复杂度为 $O(n)$。
