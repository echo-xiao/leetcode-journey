# 151. 反转字符串中的单词 · 要素

1. 栈还是队列：本题实际用的是列表（lst）模拟单词收集容器，靠反转列表顺序实现单词逆序，并非典型栈或队列的先进后出/先进先出逻辑

2. 存什么：存的是扫描过程中收集到的一个个完整单词（字符串），不是下标也不是配对信息

3. 进出时机：遇到非空格字符时把字符累加到临时变量tmp里，遇到空格且tmp非空时把tmp作为一个单词存入lst并清空tmp，这就是'进'的时机；本题没有'出'的操作，只在最后统一反转lst并拼接

4. 剩余元素含义：循环结束后lst里保存的是原字符串中按顺序切分出的所有单词，最后把这个列表整体反转再拼接就是答案，不存在中间剩余未处理的元素
