# 1468. 检查整数及其两倍数是否存在 · 要素

1. 指针类型：本题不涉及真正的双指针：题目要的是「存在某数是另一数的两倍」，标准解法是一遍哈希集合（边走边查 2*num 和 num/2），双重循环 i、j 只是暴力枚举下标，不是相向或同向推进的双指针。

2. slow 含义：本题不涉及：没有原地覆写或去重的动作，不存在「下一个待写入位置」这种 slow，唯一的下标 i 只是普通遍历游标。

3. 停止条件：停止条件就是普通遍历走完：哈希法 num 遍历完整个 arr 仍没命中就返回 False；暴力法 i、j 都跑到 n-1（且跳过 i==j）后返回 False，中途一旦发现 arr[i]==2*arr[j] 就立刻返回 True。
