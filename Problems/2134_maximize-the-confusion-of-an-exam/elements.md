# 2134. 考试的最大困扰度 · 要素

1. 定长还是变长：变长窗口，窗口大小随着能容忍的翻转次数k动态变化，不是固定长度

2. 进窗口更新：right从0到n-1逐个右移扩大窗口，每次把answerKey[right]加入窗口，如果它等于目标字符c就把cnt加1

3. 出窗口时机：当窗口内目标字符数cnt超过k时（说明非目标字符数太多，超过k次可翻转次数），就移动left缩小窗口，移出answerKey[left]时如果它等于c就把cnt减1，然后left加1

4. 记结果时机：每次right右移完成、窗口收缩到合法状态后，用当前窗口长度right-left+1去更新maxlen
