# 2134. 考试的最大困扰度 · 解题思路与伪代码

## 1. 一句话直击本质
对字符 'T' 和 'F' 分别做**滑动窗口**，求窗口内异字符个数不超过 k 时的最大窗口长度，取两次结果的最大值。

## 2. 综合思路
三个版本本质上是**完全相同的算法思路**，均为：
- **双指针滑动窗口法**：分别以 'T' 为目标字符、'F' 为目标字符跑一遍滑动窗口，计算"最多可以翻转 k 个非目标字符使窗口内全为目标字符"的最大窗口长度。
- 没有出现其他解法分支（如前缀和二分、动态规划等），三版本仅在变量初始化位置、局部变量声明习惯上有细微差异，核心逻辑一致。

**算法原理**：
- 若把所有 'T' 看作可以额外容忍 k 次改变的目标，问题转化为"最长子数组，其中非 T 字符数 ≤ k"；
- 同理对 'F' 做一次同样处理；
- 两次结果取较大值即为答案（因为最优连续段要么以更多的 T 为主要类型，要么以更多的 F 为主要类型）。

## 3. 全量伪代码

```
函数 最大连续段(answerKey, k):
    n ← answerKey 长度
    maxlen ← 0

    对于 目标字符 c 属于 {'T', 'F'}:
        left ← 0
        cnt ← 0   // 窗口内非目标字符(需要翻转)的数量，这里代码里统计的是目标字符数，逻辑等价
        
        对于 right 从 0 到 n-1:
            如果 answerKey[right] == c:
                cnt ← cnt + 1        // 统计窗口内字符为 c 的数量（作为“多数目标”的计数）
            
            当 cnt > k 时:            // 说明窗口中不该被改变的字符数超过阈值
                如果 answerKey[left] == c:
                    cnt ← cnt - 1
                left ← left + 1      // 收缩左边界
            
            maxlen ← max(maxlen, right - left + 1)
    
    返回 maxlen
```

**核心细节说明**：
- 这里的 cnt 统计的是窗口中等于目标字符 c 的数量，但由于窗口总长度固定为 `right-left+1`，非 c 字符数 = 窗口长度 - cnt。当 cnt > k 时收缩窗口，本质是限制"非目标字符数"过多的一种等价写法（另一种更直观写法是统计非目标字符数并与 k 比较，二者逻辑等价，仅统计对象不同）。
- 双指针 `left`、`right` 均单调递增，保证整体 $O(n)$。

## 4. 复杂度

- **时间复杂度**：对两种目标字符分别做一次线性扫描，每次扫描中 left 和 right 指针总移动次数均为 $O(n)$，故总时间复杂度为：
$$
O(n)
$$

- **空间复杂度**：仅使用常数个额外变量（cnt、left、right、maxlen），不依赖输入规模：
$$
O(1)
$$
