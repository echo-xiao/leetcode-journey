# 232. 用栈实现队列 · 要素

1. 栈还是队列：用两个栈（后进先出）拼出先进先出的队列：input 栈接新元素，output 栈负责往外出。

2. 存什么：两个栈里存的都是队列里的元素值本身，只是 output 栈里的顺序被倒过来了，栈顶就是队首。

3. 进出时机：push 时元素直接进 input 栈；pop/peek 时先看 output 是否为空，空了就把 input 里的元素全倒进 output，然后从 output 栈顶取；不空就直接从 output 栈顶取。

4. 剩余元素含义：input 里剩的是较晚入队还没倒过去的元素，output 里剩的是已倒序、排在队列前面等着出队的元素；两个都空才算队列空。
