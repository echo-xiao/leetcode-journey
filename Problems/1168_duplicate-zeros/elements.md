# 1168. 复写零 · 要素

1. 指针类型：用同向的快慢指针，但方向是从后往前：i（读指针）指原数组要保留的最后一个元素，j（写指针）指数组末尾，反向复制避免覆盖没读的元素。

2. slow 含义：这里的写指针 j 指的是结果数组中下一个要填的位置（从 n-1 往前走），遇到 0 就在 j 和 j-1 连填两个零，非零就把 arr[i] 搬到 arr[j]。

3. 停止条件：先用 slot 累加（0 计 2、非零计 1）扫到 slot>=n 停下，确定读指针 i 的边界；之后复制阶段 i 从该位置递减到 0（或 j<0）为止，注意 slot==n+1 的边界要先在 arr[n-1] 单独补一个 0 再开始。
