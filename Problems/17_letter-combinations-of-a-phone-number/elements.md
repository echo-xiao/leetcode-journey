# 17. 电话号码的字母组合 · 要素

1. 路径：path 就是已经为前 index 个数字各挑好的一个字母拼成的串，比如 digits="23" 时走到一半是 "a"。

2. 选择列表：当前第 index 位数字在 mapping 里对应的那几个字母，比如 '2' 就是 a、b、c，'7' 就是 p、q、r、s。

3. 结束条件：index 等于 digits 的长度，说明每个数字都挑完了一个字母，把 path 转成字符串塞进 res 后返回；另外 digits 为空时直接返回空列表。

4. 撤销：递归回来后把刚加进 path 的那个字母 pop 掉，让 path 恢复到选它之前的长度（若用字符串拼接传参则天然无需手动撤销）。
