# 2698. 找出数组的串联值 · 解题思路与伪代码

1. 一句话直击本质：通过双指针从数组两端向中间移动，将每对元素按位拼接成一个新的数并累加，最终得到数组的串联值。

2. 综合思路：
   - 双指针迭代法：使用两个指针分别指向数组的起始和末尾，逐步向中间移动，将每对元素拼接成一个新的数并累加到结果中。
   - 递归法：可以用递归的方式实现类似的逻辑，但在给定的代码集中没有出现这种实现。

3. 全量伪代码：
   ```
   初始化左指针为0，右指针为数组长度减1，结果数值为0
   当左指针小于等于右指针时，重复以下步骤：
       如果左指针等于右指针：
           将结果数值加上nums[左指针]
       否则：
           计算右指针元素的位数
           将左指针元素乘以10的右指针元素位数次方，加上右指针元素，再加上结果数值
       左指针加1
       右指针减1
   返回结果数值
   ```

4. 复杂度：
   - 时间复杂度：$O(n)$，其中 $n$ 是数组的长度，因为每个元素最多被访问一次。
   - 空间复杂度：$O(1)$，因为只使用了常数个额外变量。
