# 671. 二叉树中第二小的节点 · 要素

1. 函数定义：dfs(节点)表示对以该节点为根的子树进行搜索，没有返回值，而是通过更新外部变量second_min来记录比min1大的最小值

2. base case：节点为空直接return，不做任何处理，因为空节点没有值可比较

3. 单层主体：如果当前节点值大于min1，说明找到一个候选的第二小值，更新second_min为它和当前节点值中较小的那个，然后不再往下递归（剪枝）；否则说明当前节点值等于min1，需要继续往左右子树找

4. 代码位置：主体代码写在前序位置，先判断当前节点值再决定要不要继续递归左右子树，这样可以提前剪枝避免不必要的遍历
