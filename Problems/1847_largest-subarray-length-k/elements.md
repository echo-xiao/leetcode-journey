# 1847. 长度为 K 的最大子数组 · 要素

1. 贪心策略：在下标 0 到 len(nums)-k 这段可行起点里，挑首元素 nums[i] 最大的那个起点，直接返回 nums[idx:idx+k]。

2. 局部最优判据：每扫到一个候选起点 i，只看 nums[i] 是否比当前记录的 maxRes 大，大就把 maxRes 和 idx 换成它，完全不用去看它后面 k-1 个数长什么样。

3. 正确性理由：因为子数组按字典序比大小是先比第一个数，而题目里 nums 是 1~n 的排列、元素互不相同，首元素最大的那条一定严格大于其他所有候选，所以首位取最大这个局部选择就直接锁死了全局最优（若允许重复，则首位相同的还得往后逐位比）。
