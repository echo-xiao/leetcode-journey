# 1558. 课程表 IV · 要素

1. 图的表示：有向图，n 门课编号 0~n-1，prerequisites 里 [a,b] 表示 a→b 的边；n 最多 100，所以可以邻接表建图配一个 n×n 的布尔矩阵 isPre[i][j] 存「i 是 j 的先修」，或者直接只用矩阵跑 Floyd。

2. 遍历状态：只需要记录可达性本身：BFS 拓扑法用入度数组 + 每门课的先修集合；DFS 法用 isPre 矩阵兼做记忆化去重，题目保证无环所以不用 onPath 检环。

3. 拓扑排序：可以用 Kahn 入度法：入度为 0 入队，出队时把自己的先修集合并上自己传给后继，后继入度减到 0 再入队，这样保证一门课出队时先修集合已完整；也可以不排序直接 Floyd 传递闭包。

4. 最短路松弛：本题不涉及，只问「能不能到达」的是非题，不需要距离，dist 退化成布尔可达矩阵，松弛变成 f[i][j] |= f[i][k] && f[k][j]。
