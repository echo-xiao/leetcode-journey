# 1065. 子串能表示从 1 到 N 数字的二进制串 · 要素

1. 定长还是变长：本题（按给出的枚举法）不涉及窗口：做法是枚举 1..n 每个数转二进制后用 s.contains 查一遍，没有 left/right 指针；若硬要套，那是对每个长度 L（1 到 11 位）在 s 上开一个定长 L 的窗口去收集所有出现过的定长子串。

2. 进窗口更新：本题不涉及进窗口更新：判断 bin(i) 是否是 s 的子串靠字符串查找完成，没有随 right 右移维护的计数或和；套定长窗口时才会在 right 右移时把新字符并入当前 L 位二进制值（val = val*2 + s[right]-'0'）并记入已见集合。

3. 出窗口时机：本题不涉及出窗口：没有需要收缩的非法条件，n>2000 直接返回 False 也只是提前剪枝；套定长窗口时才是窗口长度超过 L 就把 s[left] 的最高位权重减掉（val -= (s[left]-'0')<<(L-1)）并 left++。

4. 记结果时机：结果不是在某次窗口移动时记的，而是枚举完毕后：只要有一个 bin(i) 不在 s 里立刻返回 False，全部找到才返回 True。
