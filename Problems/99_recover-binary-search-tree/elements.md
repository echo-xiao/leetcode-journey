# 99. 恢复二叉搜索树 · 要素

1. 函数定义：inorder(node)负责对以node为根的子树做中序遍历，没有返回值，靠更新外部的prev、first、second三个变量来记录中序序列中逆序的两个节点

2. base case：node为空直接返回，不做任何处理，也不更新prev

3. 单层主体：先递归处理左子树，然后比较prev和当前node的值，如果prev大于node说明出现逆序，第一次出现就记录first为prev，每次出现都把second更新为node，最后把prev设为当前node，再递归处理右子树

4. 代码位置：主体代码写在中序位置（左子树递归之后、右子树递归之前），因为要利用中序遍历下有序性来判断逆序对
