# 99. 恢复二叉搜索树 · 复盘

这个思路很简单，中序遍历找到不符合条件的两个node，最后进行交换，这个里面只交换值，不交换节点，但是写代码的时候难点在于，1. 处理相邻节点的关系，相邻关系和不相邻关系处理的逻辑不一样，如果错位节点，A的prev指向B，B的prev指向A，但是如果相邻节点，会出现死循环，或者指针指向自己。2. 处理逻辑，如果出现前一个值>当前值，first=prev，每次遇到都要更新second，second=node，因为如果是相邻交换，second就是当前node，如果错位交换，第二次遇到，second会更欣慰心的node 3. 最后更新prev指针。4. prev初始化成 float(’-inf’)，因为要保证第一个节点也能够进行比较。两种方式，递归和迭代都可以，两者都是中序遍历。
