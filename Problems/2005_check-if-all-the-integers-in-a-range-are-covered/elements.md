# 2005. 检查是否区域内所有整数都被覆盖 · 要素

1. 前缀和还是差分：用差分：给的是一堆区间 [start,end]，要把每个区间上的数都「+1」标记覆盖次数，然后扫一遍看 left..right 有没有 0，属于区间批量增减。

2. preSum[0] 定义：本题不涉及经典 preSum[0]，因为最后是把 diff 累加成覆盖次数 cnt 从 1 开始扫（数值范围 1..50），cnt 初始为 0 就相当于第 0 位前缀和为 0，不需要额外特判。

3. 差分下标位置：对每个区间 [start,end] 做 diff[start] += 1、diff[end+1] -= 1；因为 end 最大 50，diff 开到长度 100（或 52）就不会越界。
