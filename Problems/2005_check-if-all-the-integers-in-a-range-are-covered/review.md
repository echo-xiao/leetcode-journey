# 2005. 检查是否区域内所有整数都被覆盖 · 复盘

这个题目跟上一个统计人口的题目有共同点，按时也有差异，共同点在于最基础的问题，在这个时间轴/墙上，有多少个重叠的区间（生命周期/刷漆任务），我需要知道任何一个时间轴/墙的单点状态下，到底有多少个区间覆盖了它（有多少的人口/有几层漆）；那么不同点在于一个是找最大人口数的那一年，不仅仅要知道最大人口数，还要知道对应的哪一年，后者在于不关心油漆多厚，只要检查从left到right这个段落里面，是否有没有被覆盖的，要做一个判断。然后就是这个题目其实因为数据量比较小，可以直接brute force直接计算，brute force的计算里面，难点在于这个布尔值是否覆盖的判断，for loop的逻辑是神恶魔？什么时候断掉循环，什么时候判断可以返回。
