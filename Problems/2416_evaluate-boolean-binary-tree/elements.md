# 2416. 计算布尔二叉树的值 · 要素

1. 函数定义：evaluateTree(root) 传入当前子树的根节点，返回这棵子树算出来的布尔值（true/false）。

2. base case：叶子节点就是 base case：val==1 返回 true，val==0 返回 false；因为题目保证非叶子必有两个孩子，所以不会真的走到空节点。

3. 单层主体：当前节点只负责拿左右子树的结果做运算：val==2 就返回 left||right，val==3 就返回 left&&right。

4. 代码位置：后序位置——必须先递归算完左右子树的布尔值，再用当前节点的 2/3 做运算。
