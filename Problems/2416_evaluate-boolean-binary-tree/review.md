# 2416. 计算布尔二叉树的值 · 复盘

这个题目是要返回这棵树是true还是false，那么就需要我知道我的左子树，知道右子树，然后结合node.val进行处理，并且要深入整棵树，所以这个semantics就是知道整棵树的bool值，要知道左边的bool值，右边的bool值，结合中间的操作符再返回。主体就是遍历左边，遍历右边，结果要返回，然后node进行操作。node的操作就是主体，node的操作就是，左边遍历完了、右边遍历完了，然后就得到了返回值，如果是2就返回or的结果，如果是3就返回and的结果。但是到这里还不对，返回值那里返回的是结果，但是还要termination case，假如到了叶子节点，如果是1就返回true，如果是0就返回false。最后主函数直接返回结果值就可以了。
