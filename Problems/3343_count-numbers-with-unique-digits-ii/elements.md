# 3343. 统计各位数字都不同的数字个数 II · 要素

1. 状态：状态是(index, mask, isTight, isLeadingZero)，即当前处理到第几位、已用数字的位掩码、是否仍贴着上界、是否还处于前导零阶段

2. 选择：每个状态下的选择是当前这一位填哪个数字d，范围是0到upper_bound（受isTight限制），且d不能已经出现在mask里（前导零阶段的0除外）

3. dp 定义：dp[(index, mask)]表示不受上下界约束、不在前导零阶段时，从index位往后、已用数字集合为mask的情况下能构造出的合法数字个数

4. base case：base case是index等于字符串长度L时，说明已经填完所有位，返回1（表示这是一个合法方案）

5. 遍历顺序：按数位从高到低（index从0到L）递归展开，且mask随选择的digit增加，本质是自顶向下的记忆化搜索，子问题在递归返回时被填入memo，无需显式正序/逆序遍历
