# 3343. 统计各位数字都不同的数字个数 II · 题目

**难度**: Easy | **标签**: `Hash Table` `Math` `Dynamic Programming`

## 题目描述

给定两个<strong>正整数</strong> <code>a</code> 和 <code>b</code>，返回 <em>在范围内具有<strong>唯一</strong>数字的数字的数量</em> <code>[a, b]</code> <em>(<strong>包括</strong>).</em>
<p>&nbsp;</p>
<p><strong class="example">示例 1:</strong></p>

<pre>
<strong>输入:</strong> a = 1, b = 20
<strong>输出:</strong> 19
<strong>解释:</strong> 范围 [1, 20] 中的所有数字都具有唯一的数字，除了 11。因此，答案是 19。
</pre>

<p><strong class="example">示例 2:</strong></p>

<pre>
<strong>输入:</strong> a = 9, b = 19
<strong>输出:</strong> 10
<strong>解释:</strong> 范围 [9, 19] 中的所有数字都具有唯一的数字，除了 11。因此，答案是 10。 
</pre>

<p><strong class="example">示例 3:</strong></p>

<pre>
<strong>输入:</strong> a = 80, b = 120
<strong>输出:</strong> 27
<strong>解释:</strong> 范围 [80, 120] 中有 41 个数字，其中 27 个具有唯一的数字。
</pre>

<p>&nbsp;</p>
<p><strong>约束条件:</strong></p>

<ul>
	<li><code>1 &lt;= a &lt;= b &lt;= 1000</code></li>
</ul>
