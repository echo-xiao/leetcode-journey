# 266. 回文排列 · 题目

**难度**: Easy | **标签**: `Hash Table` `String` `Bit Manipulation`

## 题目描述

<p>给定一个字符串 <code>s</code>，如果字符串的一个排列可以形成一个 <em><span data-keyword="palindrome-string"><em><strong>回文</strong></em></span></em>，则返回 <code>true</code>，否则返回 <code>false</code>。</p>

<p>&nbsp;</p>
<p><strong class="example">示例 1:</strong></p>

<pre>
<strong>输入:</strong> s = &quot;code&quot;
<strong>输出:</strong> false
</pre>

<p><strong class="example">示例 2:</strong></p>

<pre>
<strong>输入:</strong> s = &quot;aab&quot;
<strong>输出:</strong> true
</pre>

<p><strong class="example">示例 3:</strong></p>

<pre>
<strong>输入:</strong> s = &quot;carerac&quot;
<strong>输出:</strong> true
</pre>

<p>&nbsp;</p>
<p><strong>约束条件:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 5000</code></li>
	<li><code>s</code> 仅由小写英文字母组成。</li>
</ul>
