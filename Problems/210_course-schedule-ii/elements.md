# 210. 课程表 II · 要素

1. 图的表示：有向图，用邻接表 adj 存，把每个 [cur, pre] 建成 pre → cur 的一条边（先修课指向后修课），课程数 numCourses 就是节点数。

2. 遍历状态：DFS 版要三种状态：未访问、正在访问（在当前递归路径上）、已完成；BFS 版不用 visited，靠 indegree 数组减到 0 来控制每个点只入队一次。

3. 拓扑排序：这题就是拓扑排序：Kahn 法把入度 0 的课入队、逐个出队并给后继减入度，结果长度等于 numCourses 就返回，否则有环返回空数组；DFS 三色法则在完成时把课加入 res，最后整体逆序输出。

4. 最短路松弛：本题不涉及，只要一个合法学习顺序，边没有权重，不求最短路。
