# 718. 最长重复子数组 · 要素

1. 状态：状态是当前比较到的nums1的下标i和nums2的下标j，即以nums1[i-1]和nums2[j-1]结尾这两个位置

2. 选择：每个状态下的选择是nums1[i-1]和nums2[j-1]是否相等：相等则接上前面的公共子数组长度+1，不相等则该位置公共长度归0

3. dp 定义：dp[i][j]表示以nums1的第i个元素和nums2的第j个元素结尾的最长公共子数组的长度

4. base case：base case是dp[0][j]和dp[i][0]都为0，表示某一个数组还没取元素时公共长度为0

5. 遍历顺序：按i从1到n、j从1到m的顺序双重遍历，因为dp[i][j]只依赖dp[i-1][j-1]，从前往后算即可保证子问题已算好
