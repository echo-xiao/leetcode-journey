# 1706. 连接所有点的最小费用 · 要素

1. 函数定义：本题不涉及递归函数定义，这题是最小生成树（Kruskal/Prim），主循环是排序+并查集或堆循环，唯一带递归味的是并查集的 find(x)：传入节点编号，返回它所在集合的根节点。

2. base case：本题不涉及空节点返回值；对应的终止条件是 Kruskal 里已选边数 cnt 达到 n-1 就停，或 find 中 parent[x]==x 时返回 x 自己。

3. 单层主体：本题不涉及树的单层处理；对应的单步是取出当前最小边 (dist,u,v)，若 u、v 不同根就 union 并把 dist 累加进 cost，否则跳过（Prim 则是取出堆顶最小点、标记已访问、累加 dist 并用曼哈顿距离更新其余未访问点）。

4. 代码位置：本题不涉及前中后序，点集没有树结构；顺序上关键是先把所有点对的曼哈顿距离边排好序（或用最小堆保证每次拿到最小边），再依次判断连通性。
