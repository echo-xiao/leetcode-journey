# 867. 新 21 点 · 要素

1. 状态：状态是当前分数i（从0到n之间的某个点数值），表示爱丽丝手上已经累计的点数

2. 选择：在i<k时，选择抽一张1到maxPts之间的牌，等概率地把点数从i变成i+1到i+maxPts中的某个值

3. dp 定义：dp[i]表示爱丽丝在拿到点数i这个状态时最终发生的概率（即从初始状态转移到点数恰好为i的概率）

4. base case：dp[0]=1.0，表示还没抽牌时点数为0的概率是1，另外若k为0或n>=k+maxPts则直接返回1.0（不用真的算dp）

5. 遍历顺序：从i=1正序遍历到n，同时维护一个大小为maxPts的滑动窗口和windowSum，保证计算dp[i]时窗口里存的是i-maxPts到i-1（且<k）这些已经算好的dp值之和
