# 1445. 大小为 K 且平均值大于等于阈值的子数组数目 · 解题思路与伪代码

# 分析：大小为 K 且平均值大于等于阈值的子数组数目

## 1. 一句话直击本质
利用**滑动窗口**维护固定长度K的区间和，通过增量更新（加新元素、减旧元素）避免重复求和，判断窗口和是否达到阈值（阈值×K）来计数。

## 2. 综合思路
本题解法思路较为统一，核心均基于**滑动窗口/双指针**技巧，主要围绕以下要点展开：

- **核心技巧**：将"平均值 ≥ threshold"转化为"区间和 ≥ threshold × k"，避免浮点数除法运算，全程使用整数运算，提升效率与精度。
- **窗口维护方式**：
  - 先计算初始窗口（前K个元素）的和作为基准；
  - 后续窗口通过 `新窗口和 = 旧窗口和 + 新进入元素 - 移出元素` 的方式O(1)更新，而非重新计算区间和。
- **计数方式**：遍历过程中，每次窗口和满足条件即计数器+1。

（本题解法较为固定，其他AC版本大多是该滑动窗口思路的等价实现，可能存在如下细节差异，但整体逻辑一致）：
- 部分实现可能用前缀和数组显式存储，再通过下标相减获取区间和；
- 部分实现可能将阈值判断改为 `平均值 = 区间和 / k` 后与threshold比较（浮点运算，性能稍逊于整数运算）。

## 3. 全量伪代码

```
函数 计算满足条件的子数组数目(数组arr, 窗口大小k, 阈值threshold):
    初始化 目标值 = threshold * k          # 转化为整数比较，避免浮点误差
    初始化 窗口和 = arr[0] 到 arr[k-1] 的和
    初始化 计数器 cnt = 0
    
    如果 窗口和 >= 目标值:
        cnt = cnt + 1
    
    从 i = k 到 数组长度-1 遍历:
        窗口和 = 窗口和 + arr[i] - arr[i - k]   # 滑动窗口更新：加新元素，减最旧元素
        如果 窗口和 >= 目标值:
            cnt = cnt + 1
    
    返回 cnt
```

## 4. 复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 为数组长度。初始窗口求和需要 $O(k)$，后续每次滑动只需 $O(1)$ 更新，共遍历 $n-k$ 次，总体线性。

- **空间复杂度**：$O(1)$，只需常数级别的额外变量（窗口和、计数器等），不使用额外数组存储。
