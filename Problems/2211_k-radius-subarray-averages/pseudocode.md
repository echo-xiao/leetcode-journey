# 2211. 半径为 k 的子数组平均值 · 解题思路与伪代码

## 1. 一句话直击本质
利用**滑动窗口（前缀和增量更新）**，避免每次重新求和，从而在 $O(n)$ 内计算每个下标为中心、半径为 k 的子数组平均值。

## 2. 综合思路
所有 4 个版本采用的算法思路完全一致，均为**滑动窗口法**，没有出现递归、DFS/BFS 或其他数据结构的解法。细节上只有微小差异：

- **版本1、2、3**：先手动计算窗口 `[0, 2k+1)` 的和并赋值给 `res[k]`，然后从 `k+1` 开始遍历，每次通过“加右减左”的方式更新窗口和。
- **版本4**：同样先计算初始窗口和，但将赋值逻辑统一放入循环体内，从 `i=k` 开始遍历，用 `if i>k` 判断是否需要更新窗口和（即将第一次窗口和的复用与后续更新合并处理，逻辑等价但实现方式略有不同）。

两种写法的时间和空间复杂度完全相同，只是代码组织形式不同（是否将首元素处理独立于循环）。

## 3. 全量伪代码

```
函数 getAverages(nums, k):
    n ← nums 长度
    res ← 长度为 n 的数组，初始值全部为 -1
    
    若 2*k + 1 > n:
        直接返回 res   # 窗口大小超过数组长度，无法形成完整窗口
    
    windowSum ← nums[0..2k] 的和   # 初始窗口和
    
    对 i 从 k 到 n-k-1 遍历:
        若 i > k:
            windowSum ← windowSum + nums[i+k] - nums[i-k-1]  # 滑动窗口更新：加入右端新元素，去掉左端旧元素
        res[i] ← windowSum // (2*k + 1)   # 整数除法求平均值
    
    返回 res
```

（版本1-3等价于将 i=k 的赋值单独提出循环之外处理，其余逻辑相同）

## 4. 复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 为数组长度，只需一次遍历并对窗口和进行常数时间更新。
- **空间复杂度**：$O(n)$，用于存储结果数组 `res`（若不计返回结果所需空间，则额外空间为 $O(1)$）。
