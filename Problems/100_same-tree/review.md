# 100. 相同的树 · 复盘

这个题目的第一反应就是分解问题，要判断两个树是否是一样的。semantics其实就是要判断两棵树的左子数是否一样、右子树是否一样、根是否一样；这个里面主体就变成了traverse树里面每个node，判断p树的left是否等于q树的left；这个树里面输入是两棵树，进行比较，比较两个树的left和right，以及每棵树的node，返回是返回这三个条件的判断；termination case就是有两个tree分别是q和q，只要其中有一个为none，就返回false，==**如果都是none，就返回true，因为递归同时到达了两个分支的末端（空指针），这意味着它们的父节点到这个位置，路径傻姑娘所有的结构和值都是匹配的，他们都是空的，所以返回True。**==
