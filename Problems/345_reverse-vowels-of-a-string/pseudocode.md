# 345. 反转字符串中的元音字母 · 解题思路与伪代码

## 1. 一句话直击本质
利用**双指针从两端向中间收缩**（或先收集所有元音位置再首尾配对交换），只交换字符串中的元音字符位置，其余字符保持不动。

## 2. 综合思路

**思路一：双指针夹逼法（版本1-4）**
- 使用集合或列表存储元音字符集合（大小写）
- 设置左右指针 i、j 分别指向字符串首尾
- 循环判断：
  - 若 i、j 均为元音，交换后同时收缩
  - 若仅 i 是元音，则右指针左移（跳过非元音）
  - 若仅 j 是元音，则左指针右移
  - 若都不是元音，左指针右移
- 直至 i >= j 停止

**思路二：两次遍历+索引记录法（版本5）**
- 第一次遍历：记录所有元音字符的索引位置及对应字符值
- 利用记录的字符值列表，从后向前弹出（模拟反转）
- 第二次遍历（按索引顺序）：依次把弹出的字符值赋回对应索引位置，实现元音反转

两种思路本质相同：只对元音字符进行位置反转，非元音字符保持原位，区别在于实现方式（原地双指针 vs 记录+回填）。

## 3. 全量伪代码

**方法一：双指针夹逼**
```
函数 反转元音(s):
    将字符串转为字符列表
    定义元音集合 = {a,e,i,o,u,A,E,I,O,U}
    i = 0, j = 长度-1
    当 i < j 时:
        如果 s[i] 和 s[j] 都是元音:
            交换 s[i] 与 s[j]
            i += 1, j -= 1
        否则如果 s[i] 是元音:
            j -= 1
        否则如果 s[j] 是元音:
            i += 1
        否则:
            i += 1
    返回 拼接后的字符串
```

**方法二：索引记录+回填**
```
函数 反转元音(s):
    索引列表 idx = []
    元音值列表 res = []
    将字符串转为字符列表

    遍历字符串每个字符及其下标 i:
        如果该字符（忽略大小写）属于元音:
            记录下标 i 到 idx
            记录字符值到 res

    遍历 idx 中的每个下标 j:
        从 res 尾部弹出一个值 val
        将 s[j] 赋值为 val

    返回 拼接后的字符串
```

## 4. 复杂度

**方法一（双指针）：**
- 时间复杂度：$O(n)$，每个指针最多遍历一次字符串
- 空间复杂度：$O(n)$，需要将字符串转换为可变列表（若不计入输入转换开销则为 $O(1)$ 额外空间）

**方法二（索引记录）：**
- 时间复杂度：$O(n)$，两次线性遍历
- 空间复杂度：$O(n)$，需要额外存储索引列表和元音值列表

其中 $n$ 为字符串长度。
