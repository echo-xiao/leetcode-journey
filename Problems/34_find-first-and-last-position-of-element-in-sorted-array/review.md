# 34. 在排序数组中查找元素的第一个和最后一个位置 · 复盘

==**version 1. **==1. 等于的时候要判断是往左走还是往右走，所以需要一个有ifFirst的变量来进行判断 2. 需要一个candidate来储存mid的值，因为为了确认是不是第一个/最后一个，需要贪心的移动指针，知道循环结束为止，但是如果找到了，left或者right仍然会移动一步，所以需要一个变量candidate先把过程中遇到的最佳答案存起来。==**version 2.**== 其实很简单的一道题目，就是找这个里面的left bound和right bound，直接套模板，然后打补丁就行，如果理解了模板，就很简单。
