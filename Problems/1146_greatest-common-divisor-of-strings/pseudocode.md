# 1146. 字符串的最大公因子 · 解题思路与伪代码

## 1. 一句话直击本质
两个字符串存在“公共字符串因子”的充要条件是 `str1+str2 == str2+str1`，其最大公因子长度等于两字符串长度的**最大公约数（GCD）**。

## 2. 综合思路

本题 AC 解法主要分为两大类思路：

**思路一：拼接验证法（Concatenation Check）**
- 核心判断：若 `str1 + str2 != str2 + str1`，说明两串没有公共的"基础重复单元"，直接返回空串。
- 若满足交换律等式，则两串的最大公因子长度必为 `gcd(len(str1), len(str2))`，取 `str1` 的前 `gcd` 长度子串即为答案。

**思路二：候选子串验证法（GCD Length + Multiple Check，即本题代码所用方法）**
- 先计算长度的最大公约数 `g = gcd(len1, len2)`。
- 取 `str1` 的前 `g` 个字符作为候选答案 `cand`。
- 验证 `cand` 重复 `len1/g` 次是否等于 `str1`，且重复 `len2/g` 次是否等于 `str2`。
- 若两者都成立，`cand` 即为答案；否则返回空字符串（说明两串本质上不是同一个"基串"的倍数）。

两种思路本质等价（拼接判断等价于双向重复验证），区别在于**判等方式**：一种通过整体拼接比较，一种通过分别重复构造比较。

## 3. 全量伪代码

```
函数 gcdOfStrings(str1, str2):
    l1 ← str1 长度
    l2 ← str2 长度
    g ← gcd(l1, l2)          // 辗转相除法求最大公约数
    cand ← str1 的前 g 个字符

    // 验证 cand 是否能通过重复构造出 str1 和 str2
    如果 cand 重复 (l1 / g) 次 等于 str1 
       且 cand 重复 (l2 / g) 次 等于 str2:
        返回 cand
    否则:
        返回 ""

函数 gcd(a, b):
    当 b 不为 0:
        a, b ← b, a mod b
    返回 a
```

（另一常见等价版本的核心判断替换为）：
```
如果 str1 + str2 ≠ str2 + str1:
    返回 ""
否则:
    g ← gcd(len(str1), len(str2))
    返回 str1 的前 g 个字符
```

## 4. 复杂度

设 $m = |str1|$，$n = |str2|$。

- **时间复杂度**：
  - 求 GCD：$O(\log(\min(m,n)))$
  - 字符串重复构造与比较（或拼接比较）：$O(m+n)$
  - 总体：$O(m+n)$

- **空间复杂度**：
  - 构造临时字符串（重复串或拼接串）需要额外空间：$O(m+n)$

$$
\text{Time: } O(m+n), \quad \text{Space: } O(m+n)
$$
