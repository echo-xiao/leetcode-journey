# 98. 验证二叉搜索树 · 要素

1. 函数定义：validate(节点, 下界, 上界) 表示以该节点为根的子树是否所有节点值都落在(下界,上界)这个开区间内，返回真/假；isValidBST是入口，调用validate(根, -∞, +∞)

2. base case：节点为空时说明这条路径验证完毕，没有违反规则，返回真

3. 单层主体：检查当前节点值是否大于下界且小于上界，不满足直接返回假；满足则往左子树传入(下界,当前值)，往右子树传入(当前值,上界)继续验证，两边都为真才算对

4. 代码位置：前序位置：先判断当前节点值是否越界（不满足直接返回假），再递归左右子树；中序遍历法则是把比较逻辑放在中序位置（左子树递归完之后、递归右子树之前，比较prev和当前值）
