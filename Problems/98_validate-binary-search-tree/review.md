# 98. 验证二叉搜索树 · 复盘

树有两种方式一般，递归+迭代， 这道题目有两种方式实现，中序遍历+区间比较，所以有四种解法，迭代的话用布尔值的框架比较合适。==**中序遍历**==的话需要跟前驱节点prev进行比较，中序遍历牛逼在于把空间问题转化成了时间线上的大小比较，BST要求的是严格递增，所以中序遍历之需要判断prev和node.val的大小就好了，难点在于，要知道什么时候用self.prev什么时候把参数直接丢辅助函数里面，如果prev作为参数，进入左子树和右子树的prev是一样的，但是如果是全局参数，进入左子树和进入右子树，参数会更新。==**区间比较**==需要继承min和max，min是左子树的最大值，max是右子树的最小值，难点在于如何理解这个递归公式是怎么来的，当前node做的一个判断，是否在min和max之间，不符合就return，最终返回的是left and right，这个地方感觉很难理解。
