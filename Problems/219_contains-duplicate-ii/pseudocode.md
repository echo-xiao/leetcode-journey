# 219. 存在重复元素 II · 解题思路与伪代码

# 219. 存在重复元素 II 分析

## 1. 一句话直击本质
**维护一个大小为 k 的滑动窗口（哈希集合），检查窗口内是否存在重复元素。**

## 2. 综合思路

所有 AC 版本本质上都是**滑动窗口 + 哈希集合**的思路，仅在实现细节上有细微差异，可归纳为两类：

- **思路 A（合并循环，动态维护窗口）**：用一个 `for` 循环遍历数组，每次判断当前元素是否已在集合 `seen` 中；若在则返回 `True`，否则加入集合；当集合大小超过 `k` 时，移除窗口最左侧（即 `nums[i-k]`）的元素，保证集合始终维护最近 `k` 个元素。（版本 1、2、3、4、6、7、8 均属此类，仅 `remove`/`discard` 用法略有不同）

- **思路 B（拆分为两阶段处理）**：先处理前 `k` 个元素建立初始窗口，再从第 `k` 个位置开始，每次先判断重复、再插入新元素同时移除窗口最旧的元素。（版本 5）

两种思路时间和空间复杂度完全一致，只是代码组织形式不同，本质都是滑动窗口法。

## 3. 全量伪代码

```
函数 containsNearbyDuplicate(nums, k):
    初始化空哈希集合 seen

    情况一（合并循环写法）：
        对 i 从 0 到 len(nums)-1:
            如果 nums[i] 已存在于 seen 中:
                返回 True
            将 nums[i] 加入 seen
            如果 seen 的大小超过 k:
                从 seen 中移除 nums[i-k]  # 移除滑出窗口的元素
        返回 False

    情况二（分阶段写法）：
        对 i 从 0 到 min(k, len(nums))-1:
            如果 nums[i] 已存在于 seen 中:
                返回 True
            将 nums[i] 加入 seen

        对 r 从 k 到 len(nums)-1:
            如果 nums[r] 已存在于 seen 中:
                返回 True
            将 nums[r] 加入 seen
            从 seen 中移除 nums[r-k]  # 保持窗口大小为 k

        返回 False
```

**核心思想统一说明**：
- 哈希集合 `seen` 始终只保存最近遍历过的、窗口大小不超过 `k` 的元素。
- 一旦发现当前元素已在集合中，说明存在下标差不超过 `k` 的重复元素，直接返回 `True`。
- 遍历结束仍未发现重复，返回 `False`。

## 4. 复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 为数组长度，每个元素最多被插入和删除一次。
- **空间复杂度**：$O(\min(n, k))$，哈希集合最多保存 $k$ 个元素（或数组长度，取较小值）。
