# 219. 存在重复元素 II · 复盘

这个里面有一个典型的问题 abs(i-j)≤ k的问题，定义了一个固定大小的领域或者窗口，一般来说可以分成三种情况：找特定的值是否存在、找相邻元素、找窗口内最大/最小值，这个是找特定的值是否存在，所以直接用哈希就好了。
为什么这个里面无法第一眼看出来是滑动窗口；因为读懂题不等于知道怎么下手，通常是因为这个是一步直接跳到了最优解，最优解是想出来的，不是看出来的；首先写暴力解
for j in 0..n-1:
    for i in 0..j-1:
        if nums[i] == nums[j] and j - i <= k:
            return True
return False
然后换掉内循环，把条件 j - i <= k 挪一下变成 i >= j - k，那内层就是：在 [j-k, j-1] 这段里，有没有一个位置的值等于 nums[j]
然后这个循环里面的状态不会写（不变量是什么）；状态里面的顺序也不会写；（修、查、加）
