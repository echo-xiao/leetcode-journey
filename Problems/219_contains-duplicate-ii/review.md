# 219. 存在重复元素 II · 复盘

1. 这个里面有一个典型的问题 abs(i-j)≤ k的问题，定义了一个固定大小的领域或者窗口，一般来说可以分成三种情况：找特定的值是否存在、找相邻元素、找窗口内最大/最小值，这个是找特定的值是否存在，所以直接用哈希就好了。
2. 为什么这个里面无法第一眼看出来是滑动窗口；因为读懂题不等于知道怎么下手，通常是因为这个是一步直接跳到了最优解，最优解是想出来的，不是看出来的；首先写暴力解
3. 然后换掉内循环，把条件 j - i <= k 挪一下变成 i >= j - k，那内层就是：在 [j-k, j-1] 这段里，有没有一个位置的值等于 nums[j]
4. 然后这个循环里面的状态不会写（不变量是什么）；不变量其实是说，走到j的时候，我手边应该有什么东西才能够立刻回答问题？装的是j前面的最近k个，不变量就是包理解内层循环扫的那段东西，只不过换成方便查看的形式；内层扫什么，拿这个范围干什么；
5. 状态里面的顺序也不会写；循环体里面的固定顺序，永远是修、查、加，不变量是啥->把过期状态踢出去、让不变量成立->用状态回答问题->把nums[j]并进去，给下一轮用。
