# 1901. 通过最少操作次数使数组的和相等 · 解题思路与伪代码

# 算法分析：通过最少操作次数使数组的和相等

## 1. 一句话直击本质
**贪心策略**：每次操作优先选择"能带来最大差值变化"的元素进行修改（大数组中的大元素变小，或小数组中的小元素变大），从而用最少次数消除两数组和的差异。

## 2. 综合思路

两个版本采用完全一致的**贪心算法**思路，仅在变量命名和交换方向上有细微差异：

- **核心思路**：设两数组和分别为 s1、s2，差值为 diff = |s1 - s2|。
- 每次操作可将数组中某元素变为 [1,6] 中的任意值，因此：
  - 对于和较大的数组中的元素 x，最大能贡献的"减少量"为 (x - 1)（变成1）
  - 对于和较小的数组中的元素 y，最大能贡献的"增加量"为 (6 - y)（变成6）
- 将所有元素的"最大贡献值"汇总到一个 gains 列表中，**降序排序**，贪心地每次选择贡献最大的操作，直到 diff 被消耗完或变为负数。
- 若所有元素贡献之和仍小于 diff，则无法通过操作使两数组和相等，返回 -1（对应极端情况，如一个数组全是1，另一个全是6且差距过大）。

两个版本本质相同，无递归/迭代等实质性差异，均为**一次遍历+排序贪心**的实现。

## 3. 全量伪代码

```
函数 minOperations(nums1, nums2):
    计算 s1 = sum(nums1), s2 = sum(nums2)
    
    若 s1 < s2，交换 nums1 和 nums2，同时交换 s1 和 s2
    （保证 nums1 对应和较大的数组）
    
    diff = s1 - s2
    若 diff == 0，返回 0
    
    初始化空列表 gains
    
    对 nums1 中每个元素 i：
        gains.append(i - 1)   # 变为1时的最大减少量
    对 nums2 中每个元素 j：
        gains.append(6 - j)   # 变为6时的最大增加量
    
    将 gains 降序排序
    
    ops = 0
    对 gains 中每个值 g（按降序遍历）：
        diff -= g
        ops += 1
        若 diff <= 0：
            返回 ops
    
    返回 -1   # 无法消除差值
```

## 4. 复杂度

设 n = len(nums1) + len(nums2)（两数组总长度）：

- **时间复杂度**：$O(n \log n)$
  （主要开销来自对 gains 列表的排序操作）

- **空间复杂度**：$O(n)$
  （用于存储 gains 列表，其长度为两数组元素总数）
