# 501. 二叉搜索树中的众数 · 复盘

semantics是要找到整棵树的mode，那就traverse整个树，然后记录见过的次数最多的node.val，这个见过的次数最多，其实就是traverse的时候记录最大值，由于这个题目是binary search tree，所以用中序遍历，这个顺序可以一遍遍历进行比较。首先我要知道上一个值prev是多少，然后上个值prev跟现在的值node.val进行比较，如果对得上，cnt+=1，对不上cnt重置为1，这个是频率的更新，更新了频率之后，要判断频率是否是最大的，如果是最大的，更新最大的频率，并且把这个录入到结果，如果是一致的，那么直接append到结果。然后最后一步漏掉了，我要更新prev，下一个步骤的prev就是现在的node.val。把这个逻辑搞清楚了就很简单。
