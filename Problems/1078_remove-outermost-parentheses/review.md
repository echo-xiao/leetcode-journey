# 1078. 删除最外层的括号 · 复盘

==**方法一，用计数器来跟踪，**==状态更新时机错误，把“判断当前状态“和”更新到下一个状态“的顺序搞错了。类似于“差一错误”和“前置/后置操作”的逻辑错误。判断一个元素是否应该被处理，必须基于它被遇到“那一刻”的状态，而不是在状态更新“之后”。先更新再判断 vs 先判断再更新。==**方法二，用stack来做**==，但是有两个知识点没有掌握 1. 关注点分离，一个变量/函数应该只负责做好一件事情，所以需要一个变量 res 来储存结果，另外一个独立的变量 stack / cnt 来管理状态，不能够用 res 的长度来判断深度，因为 res 的大小是你正在构建的结果，而不是依赖的条件。同时 2. 算法的状态变量，在解决算法问题时，必须清楚的定义，需要跟踪哪些信息才能够做出决策，需要当前嵌套的深度 cnt / len(stack) 来做，构建的目标是最终的结果字符串 res，不能把这两者搞混淆。
