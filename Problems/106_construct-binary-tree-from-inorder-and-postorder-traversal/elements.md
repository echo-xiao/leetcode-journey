# 106. 从中序与后序遍历序列构造二叉树 · 要素

1. 函数定义：buildTree(inorder, postorder)：传入某棵子树的中序序列和后序序列，返回这棵子树建好的根节点。

2. base case：中序（或后序）序列为空时返回 None，表示这段范围里没有节点。

3. 单层主体：取后序最后一个元素当根值建根节点，在中序里找到它的下标 i，用 i 把中序切成左右两段、并按左子树长度 i 把后序切成左段和右段（去掉最后那个根），分别递归接到 root.left 和 root.right。

4. 代码位置：前序位置——先根据后序末尾建出根节点并切分区间，再去递归左右子树，最后返回 root。
