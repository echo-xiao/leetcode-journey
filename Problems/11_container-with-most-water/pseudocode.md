# 11. 盛最多水的容器 · 解题思路与伪代码

# 盛最多水的容器 - 算法分析

## 1. 一句话直击本质
**双指针从两端向中间收缩，每次移动较矮的一侧，因为容器容量受限于较短边，移动较长边不可能获得更优解。**

## 2. 综合思路

给定的 AC 版本采用**双指针（对撞指针）贪心法**，这是本题的标准最优解法。其核心思想：

- 初始时指针分别指向数组首尾，此时宽度最大
- 每一步计算当前面积（`min(左高, 右高) * 宽度`），并更新最大值
- **贪心策略**：移动较矮的指针。因为宽度必然减小，若想面积变大，只能寄希望于新的高度更大；而若移动较高的一侧，新的最小高度不可能超过原来的矮边，面积必然不会变大（或更小），所以移动较高边毫无意义，只有移动较矮边才有可能"翻盘"。

（本题理论上还存在暴力双重循环解法 $O(n^2)$，但给出的 AC 代码仅涉及双指针解法，故不再展开。）

## 3. 全量伪代码

```
函数 maxArea(height):
    n = height 数组长度
    left = 0
    right = n - 1
    maxVol = 0
    
    当 left < right 时循环:
        当前宽度 = right - left
        当前高度 = min(height[left], height[right])
        当前面积 = 当前高度 * 当前宽度
        
        如果 当前面积 > maxVol:
            maxVol = 当前面积
        
        如果 height[left] > height[right]:
            right = right - 1   // 右边高，移动左指针无意义，移动右指针
        否则:
            left = left + 1     // 左边较矮或相等，移动左指针
    
    返回 maxVol
```

## 4. 复杂度

- **时间复杂度**：$O(n)$，双指针各自最多遍历数组一次，指针移动总次数不超过 $n$。
- **空间复杂度**：$O(1)$，仅使用常数个额外变量（left、right、maxvol），不依赖输入规模。
