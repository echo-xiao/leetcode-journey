# 11. 盛最多水的容器 - 分析

## 1. 一句话直击本质
**双指针从两端向中间收缩，每次移动较矮的一边，因为移动较高的一边不可能得到更大的面积。**

## 2. 综合思路
两个版本均采用**双指针（对撞指针）贪心**解法，逻辑完全一致：
- 初始化左右指针分别指向数组首尾；
- 每次计算当前面积（宽 × 两者较小高度），更新最大值；
- 移动较矮的指针（因为容器容量由较短的板决定，移动较高的一侧不会增大面积，只可能减小或不变，而移动较矮的一侧才有可能遇到更高的板从而增大面积）；
- 直到左右指针相遇。

两版本仅在**指针移动条件的写法**上略有差异（`<` 与 `<=` 的处理），但本质相同，均为一次遍历的贪心双指针法。

## 3. 全量伪代码

```
函数 maxArea(height):
    left = 0
    right = height.length - 1
    maxvol = 0

    当 left < right 时循环:
        当前宽度 = right - left
        当前高度 = min(height[left], height[right])
        当前面积 = 当前宽度 * 当前高度
        maxvol = max(maxvol, 当前面积)

        如果 height[left] < height[right]:
            left = left + 1
        否则:
            right = right - 1

    返回 maxvol
```

## 4. 复杂度

- 时间复杂度：$O(n)$，其中 $n$ 为数组长度，双指针各遍历一次。
- 空间复杂度：$O(1)$，只使用常数额外空间。
