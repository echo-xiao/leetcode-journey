# 775. N 叉树的前序遍历 · 要素

1. 函数定义：traverse(node, res) 表示以 node 为根遍历并把节点值按前序顺序追加进 res，没有返回值，靠修改 res 传递结果；preorder(root) 返回整棵树前序遍历得到的值列表。

2. base case：当 node 为空时直接 return，不做任何处理，因为空节点没有值可记录也没有子节点可遍历。

3. 单层主体：单层主体是先把当前 node 的值加入 res，然后依次对 node 的每个子节点调用 traverse（每个子树的遍历结果已经算作正确完成）。

4. 代码位置：主体代码写在前序位置，即先处理当前节点值再递归处理子节点，这正是前序遍历要求的“根在前”。
