# 110. 平衡二叉树 · 要素

1. 函数定义：calcHeight(node) 传入当前子树根节点，返回这棵子树的高度；如果这棵子树里有地方不平衡，就返回 -1 当作「坏了」的标记。

2. base case：node 为空返回 0（空树高度为 0，天然平衡）；外层 isBalanced 里 root 为空直接返回 true。

3. 单层主体：拿到左右子树高度后，先看有没有 -1，再看 abs(left-right) 是否大于 1，任一成立就返回 -1，否则返回 max(left,right)+1。

4. 代码位置：后序位置，必须先把左右子树高度都算出来才能判断当前节点是否平衡。
