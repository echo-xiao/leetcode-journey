# 1020. 最长湍流子数组 · 要素

1. 定长还是变长：变长窗口，窗口就是当前这段大小关系交替的湍流子数组，长度随交替是否被打断而伸缩。

2. 进窗口更新：每轮都无条件把 right 右移一位，加入新元素时算出 curr = arr[right] 与 arr[right-1] 的比较结果（1/-1/0），并跟前一对的 prev 比较，判断交替是否还成立。

3. 出窗口时机：不是逐步收缩，而是一旦发现断裂就直接跳左边界：若 curr==0（两数相等）则 left=right，若 curr==prev（同向）则 left=right-1，然后把 isBroken 重置为 False。

4. 记结果时机：每次 right 前进并处理完左边界后都更新一次 maxLen = max(maxLen, right-left+1)，最后返回 maxLen（数组长度小于 2 时直接返回其长度）。
