# 206. 反转链表 · 要素

1. 要不要 dummy：不用 dummy，反转是原地改指针不是新建链表，用 left=None 当初始前驱就够了，它本身就起到了尾部指向 None 的作用。

2. 指针关系：不是快慢指针，是相邻的前后两个指针：left 是已反转部分的头（初始 None），right 是当前待处理节点，两者始终差一步，每轮把 right.next 掉头指向 left 后一起后移。

3. 停止条件：伪代码里循环到 right.next 为空停（此时 right 是最后一个节点，循环外单独把它接上 left 并当作新头）；更常见的写法是 while right != None，循环结束后直接返回 left。
