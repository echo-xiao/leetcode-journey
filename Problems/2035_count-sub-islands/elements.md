# 2035. 统计子岛屿 · 要素

1. 节点与邻居：节点是 grid2 里的每个格子 (r,c)，邻居是上下左右四个相邻且 grid2 值为 1 的格子。

2. 起点与终点：起点是外层扫描到的每个 grid2[r][c]==1 且还没被标记过的格子；没有终点，队列/栈空掉表示这个岛屿走完，此时看 isSub 是否仍为 true 来决定 cnt 是否加一。

3. visited 时机：入队（入栈）的同时就把 grid2[nr][nc] 直接改成 0 当作已访问，起点在入栈时也立刻置 0，避免同一格重复入队。

4. 是否分层：不用分层，只要把整个岛屿的格子全遍历一遍并检查 grid1 对应位置是否都是 1，不关心步数。
