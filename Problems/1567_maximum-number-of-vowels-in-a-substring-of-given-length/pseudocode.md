# 1567. 定长子串中元音的最大数目 · 解题思路与伪代码

## 1. 一句话直击本质
**固定长度滑动窗口**：维护一个大小为 k 的窗口，通过"进一个字符、出一个字符"的方式动态更新窗口内元音数量，取过程中的最大值。

## 2. 综合思路
两个版本本质上是**同一种解法**——定长滑动窗口，仅在窗口滑动的下标表示方式上略有差异：

- **版本 1**：以窗口的"右边界"为循环变量 `left`（其实是窗口末尺）。窗口范围理解为 `[left-k, left]`，每次判断新进入的字符 `s[left]` 和被移出的字符 `s[left-k]`。
- **版本 2**：以窗口的"左边界"为循环变量 `left`。窗口范围为 `[left, left+k-1]`，每次判断新进入的字符 `s[left+k-1]` 和被移出的字符 `s[left-1]`。

两者都是：
1. 先计算初始窗口（前 k 个字符）中的元音数；
2. 滑动窗口，每次加入右侧新字符、移出左侧旧字符，动态维护计数；
3. 用一个变量记录历史最大值。

没有出现递归、DFS/BFS 等其他解法，所有 AC 版本均为**同一思路的滑动窗口迭代实现**。

## 3. 全量伪代码

```
函数 maxVowels(s, k):
    定义元音集合 vowels = {a, e, i, o, u}
    
    # 步骤一：计算初始窗口元音数
    cnt = 0
    对 s 的前 k 个字符进行遍历:
        若字符属于 vowels:
            cnt += 1
    maxCnt = cnt
    
    # 步骤二：滑动窗口，逐步更新
    对窗口进行从左到右滑动（共滑动 len(s)-k 次）:
        新进入窗口的字符 = 当前窗口右端对应字符
        被移出窗口的字符 = 当前窗口左端对应字符（滑动前的左端）
        
        若 新进入字符 属于 vowels:
            cnt += 1
        若 被移出字符 属于 vowels:
            cnt -= 1
        
        maxCnt = max(maxCnt, cnt)
    
    返回 maxCnt
```

（版本1、2的区别仅是索引运算方式不同，逻辑完全一致）

## 4. 复杂度

- 时间复杂度：$O(n)$，其中 $n$ 为字符串 $s$ 的长度，只需一次遍历。
- 空间复杂度：$O(1)$（若不计元音集合的常数空间，也可认为是 $O(|\Sigma|)$，$\Sigma$ 为字符集，此处为常数 5）。
