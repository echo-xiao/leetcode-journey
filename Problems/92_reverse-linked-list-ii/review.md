# 92. 反转链表 II · 复盘

两种方法，我用的是==**剪下来再反转再拼接**==的方式，但是我出现了几个问题 a. 只考虑边界节点，而漏掉了中间，我的判断条件是是否等于left或者right，这个其实是边界条件，而不是中间的过程。b. 我在处理的时候，直接把curr置空了。c. 要记得移动curr和tail指针。d. 在切断当前节点之前，必须先把下一个节点保存起来。另外一种是==**直接三个指针符合条件**==就做反转，分成三段来做，移动+反转+移动，分成几个开头到left，left到right，right到end，每个段落来进行处理。另外一种方法是==**头插法**==，通过头插法来把left到right的链条反转过来，然后是反转left-right次数，这个里面会有一个核心是 prev → curr → nxt → k 要变成 prev → nxt → curr → k。
