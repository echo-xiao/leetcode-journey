# 《滑动窗口最大值》算法分析

## 1. 一句话直击本质
利用**单调递减双端队列**维护窗口内可能成为最大值的候选下标，实现窗口滑动时最大值的 $O(1)$ 均摊获取。

## 2. 综合思路

本题的主流 AC 解法可归纳为以下几类：

- **单调队列（Deque）解法**（本题给出的版本）：
  维护一个存储**下标**的双端队列，保证队列中下标对应的值从队头到队尾单调递减。队头始终是当前窗口的最大值下标。

- **优先队列（大顶堆）解法**：
  将 `(数值, 下标)` 存入大顶堆，每次取窗口最大值时，弹出堆顶中已经滑出窗口范围的元素（懒删除），直到堆顶下标合法为止。

- **分块预处理（Sparse Table / ST表）解法**：
  预处理出每个区间的最大值（类似 RMQ 问题），空间换时间，适合多次查询场景，但滑动窗口场景中较少使用，且实现较重。

- **暴力法（会超时，非最优但逻辑简单）**：
  每次窗口滑动都遍历窗口内所有元素找最大值，时间复杂度较高，一般不作为最终 AC 方案，仅作对比。

其中**单调队列解法**是本题最经典、最优、最常见的 AC 版本，也是给定代码实现的核心逻辑。

## 3. 全量伪代码

### （1）单调队列解法（如给定版本）
```
初始化空双端队列 q（存下标）
初始化结果列表 res

对 i 从 0 到 n-1:
    // 维护单调递减性质：队尾值 <= 当前值则弹出
    当 q 不为空 且 nums[q队尾] <= nums[i]:
        队尾出队
    i 入队尾

    // 移除已滑出窗口的队头下标
    如果 q队头 <= i - k:
        队头出队

    // 窗口形成后记录答案
    如果 i >= k - 1:
        res.append(nums[q队头])

返回 res
```

### （2）大顶堆（优先队列）解法
```
初始化最大堆 heap，存 (-nums[i], i)（模拟大顶堆）
初始化结果列表 res

对 i 从 0 到 n-1:
    heap 中压入 (-nums[i], i)

    // 懒删除：堆顶下标不在窗口范围内则弹出
    当 heap不为空 且 heap堆顶下标 <= i - k:
        弹出堆顶

    如果 i >= k - 1:
        res.append(-heap堆顶的值)

返回 res
```

### （3）暴力法（仅作对比，非最优）
```
初始化结果列表 res

对 i 从 0 到 n-k:
    在 nums[i..i+k-1] 中找最大值
    res.append(该最大值)

返回 res
```

## 4. 复杂度

### 单调队列解法（最优，推荐）
- 时间复杂度：每个元素最多入队、出队一次，均摊 $O(1)$，总体为 $O(n)$
- 空间复杂度：队列最多存储 $k$ 个下标，为 $O(k)$

$$
\text{时间复杂度} = O(n), \quad \text{空间复杂度} = O(k)
$$

### 大顶堆解法
- 时间复杂度：每次堆操作为 $O(\log n)$，共 $n$ 次操作
- 空间复杂度：堆中最多存储 $n$ 个元素

$$
\text{时间复杂度} = O(n \log n), \quad \text{空间复杂度} = O(n)
$$

### 暴力法
- 时间复杂度：外层 $O(n)$ 次窗口，内层遍历窗口 $O(k)$，共 $O(n \times k)$
- 空间复杂度：仅需常数额外空间（不计结果数组）

$$
\text{时间复杂度} = O(n \times k), \quad \text{空间复杂度} = O(1)
$$
