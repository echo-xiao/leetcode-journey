# 1609. 寻找所有的独生节点 · 要素

1. 函数定义：dfs(cur, parent)：cur 是当前访问的节点，parent 是它的父节点（根节点传 None），函数本身不返回值，只负责把找到的独生节点值塞进外部的 res 列表。

2. base case：cur 为空就直接 return，什么都不做也不记录。

3. 单层主体：看 parent 是否存在且 parent 的左右子节点里只有一个不为空（parent.left 和 parent.right 一个是 None 一个不是），是就把 cur.val 加入 res，然后分别递归左右孩子。

4. 代码位置：写在前序位置：先判断并记录当前节点，再往下递归左右子树；因为判断只依赖父子关系，跟子树结果无关，放哪都行但前序最自然。
