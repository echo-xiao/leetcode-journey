# 1528. 拥有最多糖果的孩子 · 解题思路与伪代码

## 1. 一句话核心逻辑
先求出糖果数组的最大值，再判断每个孩子加上额外糖果后是否不小于该最大值。

## 2. 综合思路
两个版本本质相同，均为**遍历+比较法**，无递归、DFS/BFS等其他解法分支：

- **版本1（预计算最大值）**：先调用一次 `max(candies)` 缓存最大值，再遍历数组比较，避免重复计算，效率更优。
- **版本2（重复计算最大值）**：在遍历过程中每次都调用 `max(candies)`，逻辑等价但存在重复计算，效率较低。

两者核心判断逻辑一致：`candies[i] + extraCandies >= max(candies)`。

## 3. 全量伪代码

```
函数 拥有最多糖果的孩子(candies, extraCandies):
    result = []                      # 结果列表
    maxCandy = 求candies中的最大值      # (版本1: 循环外计算一次; 版本2: 循环内每次计算)
    
    对于 candies 中的每个 candy:
        如果 candy + extraCandies >= maxCandy:
            result.append(True)
        否则:
            result.append(False)
    
    返回 result
```

## 4. 复杂度分析

**版本1（最优实现）**
- 时间复杂度：$O(n)$，其中一次求最大值 $O(n)$，一次遍历 $O(n)$
- 空间复杂度：$O(n)$，用于存储结果数组（不计入返回值可视为 $O(1)$ 额外空间）

**版本2（重复计算版本）**
- 时间复杂度：$O(n^2)$，因为循环内部每次都重新计算 `max(candies)`，导致 $n$ 次调用、每次 $O(n)$
- 空间复杂度：$O(n)$，同上
