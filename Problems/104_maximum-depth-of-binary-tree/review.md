# 104. 二叉树的最大深度 · 复盘

**有三种方式来做，一种是自下而上的后序遍历post order，参数的传递不需要传递给孩子节点，**一棵树的最大深度，semantics就是取左子树和右子树的最大深度，然后加上root这个节点，就是最终的深度，这个是递归。主体就是递归左子树，递归右子树，然后中间的节点没有什么要做的。termination case就是到了叶子节点末端就直接返回，如果node节点为空，直接返回。**另一种是自上而下，带着参数下命令的前序遍历pre order，**把深度信息作为参数往下传递，先处理跟再处理子树，维护的是全剧最大值，带着“当前是多少层”的信息往下走。可以看灵神的视频讲解：https://www.bilibili.com/video/BV1UD4y1Y769?vd_source=c359bd7a1bfb0747446033f5053d3ff4&spm_id_from=333.788.videopod.sections。 **最后就是常规的迭代法了。**
