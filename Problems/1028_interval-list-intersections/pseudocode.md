# 1028. 区间列表的交集 · 解题思路与伪代码

# 区间列表的交集 - 算法分析

## 1. 一句话直击本质
利用双指针遍历两个**有序**区间列表，通过取左端点最大值和右端点最小值判断交集，再依据右端点较小者的区间已耗尽来推进对应指针。

## 2. 综合思路
本题只有一种主流高效解法——**双指针（Two Pointers）**，因为两个列表本身有序且不重叠，无需排序或复杂数据结构：

- **双指针法**（题解中的唯一实现）：
  - 用两个指针分别指向两个列表当前待比较的区间。
  - 每次计算两区间交集（若存在则记录）。
  - 比较两区间的右端点，右端点较小的区间已经"用尽"，其所在列表指针后移。
  - 直到某个列表遍历完毕。

（理论上也可用归并/优先队列思路模拟，但由于输入本身有序且不相交，双指针是最简且最优解，本题目AC版本均基于此思路。）

## 3. 全量伪代码

```
函数 区间交集(firstList, secondList):
    初始化 left = 0, right = 0
    初始化结果集 res = []
    
    当 left < firstList长度 且 right < secondList长度:
        取 A = firstList[left]
        取 B = secondList[right]
        
        low = max(A的起点, B的起点)
        high = min(A的终点, B的终点)
        
        如果 low <= high:
            res 加入 [low, high]   // 存在有效交集
        
        // 谁的右端点小，谁就先耗尽，指针后移
        如果 A的终点 > B的终点:
            right += 1
        否则:
            left += 1
    
    返回 res
```

## 4. 复杂度

设 firstList 长度为 $m$，secondList 长度为 $n$：

- **时间复杂度**：$O(m + n)$，两个指针各自最多遍历一次对应列表。
- **空间复杂度**：$O(1)$（不计结果集存储空间），仅使用常数额外变量；若计入输出结果，最坏为 $O(m+n)$。
