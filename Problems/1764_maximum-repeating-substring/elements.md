# 1764. 最大重复子字符串 · 要素

1. 状态：状态就是下标 i，表示以 sequence 的第 i 个字符结尾这个位置，看它往前 m 个字符能不能接上 word。

2. 选择：每个位置只有两种情况：sequence[i-m+1..i] 正好等于 word，就在前面 i-m 结尾的答案上加 1；不等于就断掉，记 0。

3. dp 定义：dp[i]（即 recursion(i)）= 以下标 i 结尾时，word 连续重复拼接能匹配的最大次数。

4. base case：i < m-1 时返回 0，因为前面字符数不够一个 word；另外子串不等于 word 时也直接是 0。

5. 遍历顺序：i 从小到大（0 到 n-1），因为 dp[i] 依赖更靠前的 dp[i-m]，最后对所有 dp[i] 取最大值。
