# 1618. 删除链表 M 个节点之后的 N 个节点 · 要素

1. 要不要 dummy：可以用 dummy 但不是必需：因为 M≥1 保证头结点一定保留，删除只发生在中间；伪代码里加 dummy 只是为了让 curr 从一个统一起点出发、每轮循环写法一致，最后返回 dummy.next（或直接返回原 head）。

2. 指针关系：不是同时跑的快慢指针，而是交替走：每一轮 slow 从当前段起点往前走 M 步停在这段保留部分的最后一个节点，fast 从 slow.next 出发再往前走 N 步跳过要删的节点，两者之间恰好隔着 N 个待删节点，然后 slow.next = fast，再把 slow 当作下一轮的起点。

3. 停止条件：两处都要判空即停：走 M 步时 slow 变成 null 就说明链表已走完，直接结束外层循环；走 N 步时 fast 变成 null 就说明尾部不足 N 个，此时 slow.next = null 把尾巴全删掉；外层循环以 slow/curr 为 null 作为整体终止。
