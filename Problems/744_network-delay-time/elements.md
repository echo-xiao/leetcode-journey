# 744. 网络延迟时间 · 要素

1. 图的表示：这题是有向带权图，n个节点，用邻接表（或邻接矩阵存Floyd）存每条边(u,v,w)表示u到v的传输时间

2. 遍历状态：不需要visited去重那种遍历，而是维护一个dist数组记录起点k到各节点当前已知最短时间，Dijkstra里再加一个visited/处理标记数组防止重复松弛

3. 拓扑排序：本题不涉及拓扑排序，因为图里可能有环（网络延迟场景边权为正但图不是DAG），求的是最短路而不是依赖顺序

4. 最短路松弛：dist数组初始化为无穷大，起点k的dist设为0，然后按选中的算法（Dijkstra每次取未访问中最小的节点松弛邻居，或Floyd三重循环用中转点k更新dist[i][j]=min(dist[i][j], dist[i][k]+dist[k][j])）不断更新，最后取dist数组里的最大值作为答案，若有节点不可达则返回-1
