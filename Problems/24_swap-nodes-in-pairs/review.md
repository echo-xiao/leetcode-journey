# 24. 两两交换链表中的节点 · 复盘

这个题目最难的点在于思考如何调整指针。**首先**要知道需要哪些指针，一共需要四个指针；**其次**三个箭头要修改，prev -> first 变成 prev -> second，first -> second 变成 second -> first，second -> nxt 变成 first -> nxt；**再者**，这四个指针如何交换；**以及**，这几个指针如何复原，loop里面没有条件，所以只需要思考while条件写的逻辑，以及如何复原就好了；**后面**就是如何检查none，因为这个里面需要起码2个指针，不然就会要罢工，然后while条件里面考虑的是second这个指针，所以其实不需要second next，**最后**，如果里面有遇到只有一个node留下的情况，需要分情况讨论。
