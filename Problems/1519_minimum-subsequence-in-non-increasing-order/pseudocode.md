# 1519. 非递增顺序的最小子序列 · 解题思路与伪代码

1. **一句话直击本质**：通过对数组进行降序排序后，逐步累加前缀和，直到前缀和大于剩余元素和时返回当前前缀。

2. **综合思路**：
   - **排序与前缀和**：首先对数组进行降序排序，然后计算前缀和，找到第一个前缀和大于剩余元素和的位置，返回该前缀。
   - 该题目主要采用了排序和前缀和的思路，没有涉及到递归、DFS、BFS等其他复杂算法。

3. **全量伪代码**：
   ```plaintext
   定义函数 minSubsequence(nums):
       将 nums 按降序排序
       计算 nums 的总和 ttl
       初始化前缀和数组 arr，长度为 len(nums) + 1，初始值为 0
       
       对于 i 从 1 到 len(nums)（包含）:
           计算当前前缀和 arr[i] = nums[i-1] + arr[i-1]
           如果 arr[i] 大于 ttl - arr[i]:
               返回 nums 的前 i 个元素作为结果
   ```

4. **复杂度**：
   - 时间复杂度：排序的时间复杂度为 $O(n \log n)$，计算前缀和的时间复杂度为 $O(n)$，因此总时间复杂度为 $O(n \log n)$。
   - 空间复杂度：使用了一个额外的前缀和数组，空间复杂度为 $O(n)$。
