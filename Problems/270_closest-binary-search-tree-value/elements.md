# 270. 最接近的二叉搜索树值 · 要素

1. 函数定义：closestValue(root, target) 表示在以root为根的BST中找到最接近target的节点值，返回这个最接近的值

2. base case：root为空时返回正无穷（表示这条路径无效，不会被选中）

3. 单层主体：比较target和root.val的大小，决定往左子树还是右子树递归，拿到子树返回的closest后，跟root.val比谁离target更近，返回更近的那个

4. 代码位置：前序位置：先判断走左还是走右并递归，拿到结果后在当前节点（回溯时）做比较，所以准确说是后序位置——先处理子树递归调用，再用结果和当前节点比较后返回
