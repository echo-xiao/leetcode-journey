# 2582. 两个城市间路径的最小分数 · 要素

1. 图的表示：无向带权图，用邻接表存，adj[u] 里放 (邻居v, 边权w)，每条 roads[i]=[u,v,w] 双向各加一次；n 最多 10^5，用矩阵会爆内存。

2. 遍历状态：只需要一个 visited 数组给城市去重，另外一个全局 res 记一路上见过的最小边权；不用 onPath，因为无向图里允许反复走边、环不影响答案。

3. 拓扑排序：本题不涉及，图是无向的且不要求任何先后顺序，只要判断哪些城市和城市1连通。

4. 最短路松弛：本题不涉及最短路松弛，答案是路径上边权的最小值而不是和，且能无限往返，所以只要在城市1所在连通块里对所有边权取 min，初始 res=正无穷。
