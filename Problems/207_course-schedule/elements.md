# 207. 课程表 · 要素

1. 图的表示：有向图，用邻接表存：把 prerequisites 里的 [cur, pre] 建成 pre→cur 的边（BFS 法），或 cur→pre（DFS 法），课程编号 0..numCourses-1 直接当下标，边稀疏所以不用矩阵。

2. 遍历状态：BFS 法只需一个 indegree 数组加一个计数器；DFS 法需要 flags 三态数组，0 未访问、1 表示当前这条递归路径上（相当于 onPath，再遇到就是有环）、2 表示已确认无环可跳过。

3. 拓扑排序：需要，本题就是拿拓扑排序判环：Kahn 法把入度 0 的入队、出队时把邻居入度减 1，最后看出队数是否等于 numCourses；或者 DFS 三色标记，任一节点 dfs 返回 False 就说明有环。

4. 最短路松弛：本题不涉及，只要判断能不能修完所有课（有没有环），不求任何路径长度，边也没有权重。
