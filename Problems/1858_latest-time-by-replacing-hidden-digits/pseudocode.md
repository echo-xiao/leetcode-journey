# 1858. 替换隐藏数字得到的最晚时间 · 解题思路与伪代码

1. 一句话直击本质：通过逐个替换时间字符串中的问号，以确保每个位置的数字最大化，从而得到可能的最晚时间。

2. 综合思路：在这两个版本中，采用了相同的思路，即通过条件判断和替换操作来处理时间字符串中的问号。没有使用递归、迭代、DFS、BFS或其他数据结构的不同解法。

3. 全量伪代码：
   - 将时间字符串分为小时和分钟部分。
   - 对于小时部分：
     - 如果两个字符都是问号，替换为 "23"。
     - 如果第一个字符是问号，根据第二个字符的值替换为 "2" 或 "1"。
     - 如果第二个字符是问号，根据第一个字符的值替换为 "9" 或 "3"。
   - 对于分钟部分：
     - 如果第一个字符是问号，替换为 "5"。
     - 如果第二个字符是问号，替换为 "9"。
   - 将处理后的小时和分钟部分重新组合成时间字符串并返回。

4. 复杂度：
   - 时间复杂度：$O(1)$，因为算法只对固定长度的字符串进行有限次的字符替换和判断。
   - 空间复杂度：$O(1)$，因为只使用了常数个额外的空间来存储中间结果。
