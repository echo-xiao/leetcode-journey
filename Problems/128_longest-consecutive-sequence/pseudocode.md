# 128. 最长连续序列 · 解题思路与伪代码

## 1. 一句话直击本质

将数组去重后判断每个数是否为某段连续序列的"起点"（即其前驱不存在），再向后扩展统计长度，从而在保证整体线性时间的前提下求出最长连续序列长度。

## 2. 综合思路

题目的 AC 解法可归纳为两大类：

**思路一：哈希集合（Set）+ 边界判断（版本1、3）**
- 将 `nums` 存入哈希集合，实现 $O(1)$ 查询。
- 遍历集合中每个数字，只有当它是一个连续序列的**起点**（即 `num-1` 不在集合中）时，才向后扩展查找 `num+1, num+2, ...` 是否存在，统计长度。
- 这样保证每个数字最多被访问两次（一次作为遍历元素，一次作为扩展元素），从而达到 $O(n)$ 总时间复杂度。

**思路二：排序 + 线性扫描（版本2、4）**
- 先对数组排序。
- 遍历排序后的数组，比较相邻元素：
  - 若相等，跳过（去重）。
  - 若相差 1，长度 `length += 1`。
  - 否则（不连续），重置 `length = 1`。
- 用 `maxlen` 记录过程中的最大长度。
- 该方法实现简单，但因排序，时间复杂度为 $O(n \log n)$。

两种思路本质相同：都是找到连续段并统计长度，区别在于查找相邻数字的方式（哈希 O(1) vs 排序有序遍历）。

## 3. 全量伪代码

### 解法一：哈希集合法
```
函数 最长连续序列(nums):
    若 nums 为空: 返回 0
    将 nums 转为集合 seen  // 自动去重，支持O(1)查找
    maxlen ← 0
    对 seen 中每个数字 num:
        如果 (num - 1) 不在 seen 中:   // 确保是序列起点
            length ← 1
            cur ← num
            当 (cur + 1) 在 seen 中:
                length ← length + 1
                cur ← cur + 1
            maxlen ← max(maxlen, length)
    返回 maxlen
```

### 解法二：排序扫描法
```
函数 最长连续序列(nums):
    若 nums 为空: 返回 0
    对 nums 进行排序
    length ← 1
    maxlen ← 1
    对 i 从 1 到 len(nums)-1:
        如果 nums[i] == nums[i-1]:
            继续（跳过重复元素）
        否则如果 nums[i] == nums[i-1] + 1:
            length ← length + 1
        否则:
            length ← 1
        maxlen ← max(maxlen, length)
    返回 maxlen
```

## 4. 复杂度

**解法一（哈希集合法，版本1、3）：**
- 时间复杂度：$O(n)$（每个元素最多被访问常数次）
- 空间复杂度：$O(n)$（额外的哈希集合存储）

**解法二（排序扫描法，版本2、4）：**
- 时间复杂度：$O(n \log n)$（排序主导）
- 空间复杂度：$O(\log n)$ 或 $O(n)$（取决于排序算法实现，如快排递归栈或 Timsort 辅助空间；若不计排序内部开销，则额外空间为 $O(1)$）
