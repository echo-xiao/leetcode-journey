# 2602. 最多可以摧毁的敌人城堡数目 · 复盘

不是一个经典的算法问题，但是可以归类为”带状态的单词遍历“或者一个极简的”状态机”（state machine）的问题，解决在线性数据比如数组/字符串中寻找两个“特定点”之间满足某种条件的片段的最大值/最小值。状态机的想法给我的第一反应就是布尔标记，但是其实布尔标记没有办法解决这么复杂的问题，但是回归到本质，布尔标记其实就是一个简单tag，那么如果需要储存更多的信息，就会需要更牛逼的状态标记。这个里面的逻辑就是线性扫描一下这个那个数组，然后找到一个由1和一个-1所包裹的最长的0序列。对我来说，难点更多在于loop里面的条件怎么写，这个里面是一个逻辑检查的问题，写成 if elif else 的情况比较合适。
