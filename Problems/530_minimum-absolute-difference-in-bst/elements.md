# 530. 二叉搜索树的最小绝对差 · 要素

1. 函数定义：traverse(node) 表示对以node为根的子树做中序遍历，没有返回值，靠更新外部变量pre（前驱节点值）和minDiff（最小差值）来记录结果

2. base case：节点为空直接return，不做任何比较，因为空节点没有值可以参与差值计算

3. 单层主体：用当前节点值减去pre（上一个中序遍历到的节点值），如果这个差比minDiff小就更新minDiff，然后把pre更新成当前节点值

4. 代码位置：写在中序位置，即先递归左子树，再执行比较更新的代码，最后递归右子树，这样保证遍历顺序是从小到大，相邻比较才有意义
