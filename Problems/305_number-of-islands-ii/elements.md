# 305. 岛屿数量 II · 要素

1. 节点与邻居：本题不是真正的BFS题，而是并查集题：节点是网格中的每个格子(r*n+c)，邻居是上下左右四个相邻格子，只有当邻居也是陆地时才算相连

2. 起点与终点：本题不涉及单一起点终点，每次在positions中新加一个陆地点后就检查它和四周陆地的连通情况，目标是统计当前岛屿总数而不是找路径

3. visited 时机：用isLand数组标记某格是否已变成陆地，在处理positions[i]时先标记当前格为陆地，再去看四周是否已标记过陆地从而决定是否合并，防止把同一个格子重复计数或重复合并

4. 是否分层：本题不需要分层遍历，因为不是逐层扩散求最短路径，而是用并查集一次性判断连通块个数
