# 2552. 长度为 K 子数组中的最大和 · 解题思路与伪代码

# 分析：长度为 K 子数组中的最大和

## 1. 一句话直击本质
**滑动窗口 + 哈希计数**：维护一个大小为 K 的滑动窗口，用哈希表记录窗口内元素出现次数以判断"元素是否互不相同"，同时用前缀和思想动态维护窗口和，仅当窗口内元素全不相同时才更新最大值。

## 2. 综合思路
两个版本本质完全相同，均采用**定长滑动窗口**解法：

- **窗口和的维护**：不重新计算窗口和，而是通过"加入右端新元素、减去左端滑出元素"的增量方式动态更新（类似前缀和差分），保证每次窗口移动是 $O(1)$。
- **元素去重判断**：使用哈希表（`defaultdict(int)`）记录窗口内每个数字出现的次数。当某个数字的计数归零时从哈希表中删除该键，这样 **哈希表的 key 数量（`len(counter)`）就等于窗口内不同元素的个数**。若该数量等于 `k`，说明窗口内元素互不相同，此时才尝试更新最大和。
- 两版本没有用其他数据结构（如排序、堆）的实现，均为该单一滑动窗口+哈希计数解法，属于同一类逻辑的等价实现。

## 3. 全量伪代码

```
函数 求最大子数组和(nums, k):
    初始化 计数器 counter 为空哈希表（默认值为0）
    初始化 当前窗口和 sum = 0
    初始化 最大和 maxSum = 0

    # 第一步：构建初始窗口 [0, k-1]
    对 i 从 0 到 k-1:
        sum += nums[i]
        counter[nums[i]] += 1

    若 counter中不同key的个数 == k:
        maxSum = sum

    # 第二步：滑动窗口，从 k 到 len(nums)-1
    对 i 从 k 到 len(nums)-1:
        sum += nums[i]        # 加入新元素
        sum -= nums[i-k]      # 移除旧元素

        counter[nums[i]] += 1
        counter[nums[i-k]] -= 1

        若 counter[nums[i-k]] == 0:
            从 counter 中删除该 key   # 保证key数即为不同元素个数

        若 counter中不同key的个数 == k:
            maxSum = max(maxSum, sum)

    返回 maxSum
```

## 4. 复杂度

- **时间复杂度**：$O(n)$，其中 $n$ 为数组长度，每个元素仅被加入/移除窗口各一次，哈希表操作均为均摊 $O(1)$。
- **空间复杂度**：$O(k)$，哈希表最多存储窗口内 $k$ 个不同元素。
