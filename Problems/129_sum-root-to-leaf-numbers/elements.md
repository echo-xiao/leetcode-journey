# 129. 求根节点到叶节点数字之和 · 要素

1. 函数定义：dfs(node, currSum)：node 是当前节点，currSum 是从根走到 node 父节点时累积出来的数字，返回值是以 node 为根的这棵子树里所有根到叶路径数字之和。

2. base case：node 为空就返回 0，表示这条不存在的分支不贡献任何数字。

3. 单层主体：先把 currSum 更新成 currSum*10+node.val，若左右子节点都为空说明是叶子直接返回这个数，否则把左右子树的返回值加起来返回。

4. 代码位置：累积数字和叶子判断写在前序位置（进入节点、递归子树之前），左右结果相加算在后序位置。
