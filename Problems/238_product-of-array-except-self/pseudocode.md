# 238. 除了自身以外数组的乘积 - 算法解析

## 1. 一句话直击本质

对每个位置 i，其结果等于该位置**左侧所有元素乘积**与**右侧所有元素乘积**的乘积，通过两次遍历分别累积左右乘积即可避免除法运算。

## 2. 综合思路

三份代码本质上是**同一种解法**：前缀积 × 后缀积。仅在空间使用上有细微差异：

- **思路一（版本1）**：使用两个独立数组 `left` 和 `right` 分别存储每个位置的前缀积和后缀积，最后遍历相乘得到结果。空间复杂度为 $O(n)$（额外数组）。

- **思路二（版本2、3）**：使用两个滚动变量 `left` 和 `right`（而非数组）在遍历过程中动态累积左右乘积，直接在结果数组 `res` 上原地更新。相比版本1节省了额外数组空间，只用两个标量变量。

两种思路都规避了"如果允许用除法，先求总乘积再除以自身"的方案（该方案在遇到 0 时会出错），符合题目"不使用除法"的要求。

## 3. 全量伪代码

### 逻辑一：双数组法（前缀数组 + 后缀数组）

```
函数 productExceptSelf(nums):
    n = nums 长度
    初始化 left 数组，全部为 1，长度为 n
    初始化 right 数组，全部为 1，长度为 n
    
    # 计算前缀积：left[i] 表示 i 左侧所有元素的乘积
    对于 i 从 1 到 n-1:
        left[i] = left[i-1] * nums[i-1]
    
    # 计算后缀积：right[j] 表示 j 右侧所有元素的乘积
    对于 j 从 n-2 到 0（倒序）:
        right[j] = right[j+1] * nums[j+1]
    
    初始化 res 数组，长度为 n
    对于 i 从 0 到 n-1:
        res[i] = left[i] * right[i]
    
    返回 res
```

### 逻辑二：滚动变量法（原地更新 + 双变量）

```
函数 productExceptSelf(nums):
    n = nums 长度
    初始化 res 数组，全部为 1，长度为 n
    初始化 left = 1, right = 1
    
    # 第一次遍历：计算前缀积，直接存入 res
    对于 i 从 1 到 n-1:
        left = left * nums[i-1]
        res[i] = left
    
    # 第二次遍历：计算后缀积，并与已有的前缀积相乘
    对于 j 从 n-2 到 0（倒序）:
        right = right * nums[j+1]
        res[j] = res[j] * right
    
    返回 res
```

## 4. 复杂度分析

### 版本1（双数组法）
- 时间复杂度：$O(n)$，需要三次线性遍历（计算前缀、计算后缀、合并结果）
- 空间复杂度：$O(n)$，需要额外的 `left` 和 `right` 数组（不计输出数组）

### 版本2、版本3（滚动变量法）
- 时间复杂度：$O(n)$，需要两次线性遍历
- 空间复杂度：$O(1)$，仅使用常数个额外变量（不计输出数组 `res`，这是题目允许的返回值）

**总结**：所有版本时间复杂度均为 $O(n)$；空间复杂度上，版本1为 $O(n)$（额外数组），版本2、3为 $O(1)$（仅额外常数空间，更优）。
