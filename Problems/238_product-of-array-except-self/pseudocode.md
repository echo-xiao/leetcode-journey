# 除了自身以外数组的乘积 - AC实现分析

## 1. 一句话直击本质
利用**左侧前缀积**与**右侧后缀积**的乘积等于除自身外所有元素的乘积，通过两次遍历避免除法运算。

## 2. 综合思路

所提供的两个版本（版本1与版本2）逻辑完全一致，均属于**前缀积+后缀积（双向遍历）**解法，具体思路如下：

- **核心思想**：对于结果数组 `res[i]`，其值等于 `nums[i]` 左边所有元素的乘积 × `nums[i]` 右边所有元素的乘积。
- **实现方式**：
  1. 第一次从左到右遍历，计算每个位置**左侧**所有元素的乘积，存入 `res[i]`。
  2. 第二次从右到左遍历，用一个变量动态维护**右侧**累乘积，将其乘到 `res[i]` 上。
- **优势**：只用了两个额外变量（`left`, `right`）作为累乘器，未使用额外数组存储前缀/后缀积，空间复杂度为 $O(1)$（不计输出数组）。
- **未出现的其他解法**（补充说明，代码集中未体现）：
  - 使用两个独立数组分别存储前缀积和后缀积，再逐位相乘，空间复杂度为 $O(n)$。
  - 暴力法：对每个位置计算除自身外所有元素乘积，时间复杂度为 $O(n^2)$（本题不允许除法时的备选方案）。

两版本本质相同，仅变量声明顺序略有差异，不影响算法逻辑。

## 3. 全量伪代码

```
函数 除自身以外数组的乘积(nums):
    n = nums的长度
    初始化结果数组 res，所有元素为 1
    初始化 left = 1，right = 1

    // 第一次遍历：计算左侧乘积
    对于 i 从 1 到 n-1:
        left = left * nums[i-1]
        res[i] = left

    // 第二次遍历：计算右侧乘积并累乘到结果中
    对于 j 从 n-2 到 0（递减）:
        right = right * nums[j+1]
        res[j] = res[j] * right

    返回 res
```

## 4. 复杂度分析

- **时间复杂度**：两次线性遍历数组，故为 $O(n)$
- **空间复杂度**：除返回的结果数组外，只使用了常数个额外变量（`left`, `right`），故为 $O(1)$（若计入输出数组则为 $O(n)$）
