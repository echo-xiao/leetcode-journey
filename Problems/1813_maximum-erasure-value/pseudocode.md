# 删除子数组的最大得分 - 算法分析

## 1. 一句话直击本质
使用**滑动窗口（双指针）**维护一个不含重复元素的连续子数组，动态调整窗口边界并实时更新窗口内元素和的最大值。

## 2. 综合思路
本题的核心解法是**滑动窗口 + 哈希计数**，具体逻辑为：
- **右指针扩张**：不断将新元素加入窗口，累加窗口和。
- **左指针收缩**：当窗口内出现重复元素时，从左侧不断移除元素（同时减少哈希计数和窗口和），直到窗口内不再有重复元素。
- **维护最大值**：每次右指针移动后，更新历史最大窗口和。

该方法本质上是**同向双指针**思想，时间复杂度为线性，是本题的标准最优解法（未见有效性相近的DFS/BFS等其他解法，因为本题不涉及树或图结构，天然适合滑动窗口）。

## 3. 全量伪代码

```
函数 求最大子数组得分(数组nums):
    初始化 左指针 = 0
    初始化 当前窗口和 = 0, 历史最大得分 = 0
    初始化 哈希表 counter（记录窗口内每个元素出现次数）

    对于 右指针 从 0 到 数组长度-1:
        将 nums[右指针] 计数加1
        当前窗口和 += nums[右指针]
        
        当 nums[右指针] 的计数 > 1 时:  // 出现重复，需要收缩左边界
            将 nums[左指针] 计数减1
            如果 nums[左指针] 计数变为0:
                从哈希表中删除该元素
            当前窗口和 -= nums[左指针]
            左指针 += 1
        
        历史最大得分 = max(当前窗口和, 历史最大得分)
    
    返回 历史最大得分
```

## 4. 复杂度分析

**时间复杂度**: $O(n)$
- 左右指针各自最多遍历数组一次，虽然是嵌套循环结构，但左指针的移动次数总和不超过 $n$，属于均摊线性时间复杂度。

**空间复杂度**: $O(n)$
- 需要额外的哈希表 `counter` 存储窗口内元素及其出现次数，最坏情况下需要存储所有不同元素，空间开销与数组长度线性相关。
