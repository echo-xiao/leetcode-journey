# 1430. 找到一个数字的 K 美丽值 · 要素

1. 定长还是变长：定长：窗口就是 num 转成字符串后长度恰好为 k 的一段数位，从头滑到尾。

2. 进窗口更新：right 每次右移一位把新数位吃进来；若维护数值就是 cur = cur*10 + 新数位（这里直接切 k 位子串转 int 也一样）。

3. 出窗口时机：窗口凑满 k 位后每次右移就同步把 left 那位吐掉，维护数值时减去 最高位数字 * 10^(k-1)，然后 left++。

4. 记结果时机：每次窗口正好为 k 位时判一次：子串值不为 0 且 num % 子串值 == 0 就 cnt++，全部滑完返回 cnt。
