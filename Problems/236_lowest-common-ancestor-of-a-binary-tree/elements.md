# 236. 二叉树的最近公共祖先 · 要素

1. 函数定义：lowestCommonAncestor(root,p,q)：在以 root 为根的子树里找 p 和 q，返回值是「这棵子树里 p、q 的最近公共祖先」，如果只找到一个就返回那一个，都没找到返回空。

2. base case：root 为空返回 null；root 正好是 p 或 q 时直接返回 root，不再往下找。

3. 单层主体：拿到左右子树的返回值 left、right：左右都非空说明 p、q 分居两侧，当前 root 就是答案；只有一边非空就把那一边的结果往上传；两边都空返回 null。

4. 代码位置：后序位置——必须先递归拿到 left 和 right 的结果，才能判断当前节点是不是分叉点。
