# 160. 相交链表 · 要素

1. 要不要 dummy：不用 dummy，本题只是找两条已有链表的相交结点，不新建也不修改链表，没有头结点被删改的边界问题。

2. 指针关系：两指针同速走，靠「走完自己再走对方」来抵消长度差：ptr1 走 A 再走 B、ptr2 走 B 再走 A，走到相交点时两者总步数相同，所以是路径长度相等的关系，不是快慢步差。

3. 停止条件：停止条件是 ptr1 == ptr2：要么在相交结点相遇返回该结点，要么两者同时走完 a+b 步都变成 None 返回 None（注意判空时是先切换到另一条链表头，切换只允许各做一次，靠 None 本身参与比较来保证不死循环）。
