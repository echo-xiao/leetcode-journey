# 567. 字符串的排列 · 解题思路与伪代码

## 1. 一句话直击本质
用**定长滑动窗口**维护窗口内字符计数，与目标串 s1 的字符计数做比较，只要某窗口计数与 s1 完全相同即存在排列。

## 2. 综合思路
所有版本本质相同，均为**滑动窗口 + 哈希表计数**，差异仅在实现细节：

- **版本1/2/3**：先统计 s1 的字符频次到 `seen`；遍历 s2，用字典 `win` 维护窗口计数，窗口大小固定为 `len(s1)`，超出窗口左边界时移除最左字符（计数为0则删除该键），每步比较 `win == seen`。
- **版本4**：使用 `defaultdict(int)` 简化计数操作；先处理长度小于 s1 的特判（`k>n` 直接返回 False）；初始化窗口为前 k 个字符并先比较一次，然后再进行滑动窗口的增删比较，逻辑等价但结构略有不同（先判断初始窗口，再循环右移）。
- **版本5**：采用显式双指针（`left`, `right`）来控制窗口，通过 `while right - left > len(s1)` 收缩窗口，逻辑上等价于固定窗口滑动，但写法更贴近标准双指针模板。

综上，所有版本都属于**同一种算法思路（滑动窗口计数比较）**，没有本质分支（如DFS/BFS/排列组合等），仅代码风格、窗口维护方式、字典操作细节不同。

## 3. 全量伪代码

```
函数 checkInclusion(s1, s2):
    若 len(s1) > len(s2): 返回 False

    seen ← 空字典       # 统计 s1 中每个字符出现次数
    对 s1 中每个字符 c:
        seen[c] += 1

    win ← 空字典         # 滑动窗口内字符计数
    k ← len(s1)

    对 i 从 0 到 len(s2)-1:
        c ← s2[i]
        win[c] += 1                      # 扩大窗口，加入右边字符

        若 窗口长度 > k:                  # 收缩窗口，保持长度为 k
            left_char ← s2[i - k]         # 或使用双指针 left
            win[left_char] -= 1
            若 win[left_char] == 0:
                从 win 中删除 left_char

        若 win == seen:                  # 比较窗口计数与目标计数
            返回 True

    返回 False
```

（版本4额外在窗口首次填满后立即比较一次，再进入循环滑动；版本5用 while 循环模拟窗口收缩，逻辑等价。）

## 4. 复杂度

- 时间复杂度：$O(n \times \Sigma)$，其中 $n = |s_2|$，$\Sigma$ 为字符集大小（因字典比较 `win == seen` 最坏情况下需要 $O(\Sigma)$）。若视字符集大小为常数（如26个小写字母），可视为 $O(n)$。

- 空间复杂度：$O(\Sigma)$，用于存储两个计数字典，通常视为 $O(1)$（字符集大小固定）。

$$
\text{时间复杂度：} O(n \cdot \Sigma) \approx O(n), \quad \text{空间复杂度：} O(\Sigma) \approx O(1)
$$
