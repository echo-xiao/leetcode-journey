# 76. 最小覆盖子串 · 解题思路与伪代码

## 1. 一句话本质
**双指针滑动窗口**：右指针扩张窗口直到完全覆盖 `t` 中所有字符，左指针在满足覆盖条件时收缩窗口以寻找最小长度，全程用哈希表统计窗口内字符频次。

## 2. 综合思路
三个版本（含重复代码）实现思路完全一致，属于同一种解法，无分支差异：

- **数据结构**：使用两个哈希表（`dict`）——`need` 记录 `t` 中每个字符所需数量，`win` 记录当前窗口中各字符的实际数量。
- **算法范式**：经典的**同向双指针（滑动窗口）**法，非递归、非DFS/BFS。
- **覆盖判断**：通过一个独立的辅助函数 `covered(win, need)`，每次窗口更新后**遍历 `need` 的所有键**检查 `win` 中对应字符数量是否都不小于 `need`，以此判断窗口是否合法覆盖 `t`。
- **收缩策略**：只要覆盖条件满足，就不断左移左指针尝试缩小窗口并更新最优解，直到窗口不再满足覆盖条件为止（保证得到以当前右端点为右边界的最小窗口）。

三版本区别仅在变量命名（`basei` vs `besti`），逻辑与实现细节完全相同，属于同一 AC 方案的重复提交。

## 3. 全量伪代码

```
函数 minWindow(s, t):
    统计 need：t 中每个字符出现次数
    初始化 win 为空哈希表
    初始化左指针 i = 0，最小长度 minres = 无穷大，最优起点 besti = 0
    
    for j from 0 to len(s)-1:
        c = s[j]
        win[c] += 1   # 扩大窗口，纳入右端点字符
        
        while covered(win, need) 为真:   # 当前窗口已覆盖t中所有字符
            当前窗口长度 = j - i + 1
            if 当前窗口长度 < minres:
                更新 minres 和 besti = i
            
            # 尝试收缩左边界
            left = s[i]
            win[left] -= 1
            if win[left] == 0:
                从 win 中删除 left
            i += 1
    
    if minres 仍为无穷大:
        返回 ""
    否则返回 s[besti : besti + minres]

函数 covered(win, need):
    for 每个字符 x in need:
        if x 不在 win 中 或 win[x] < need[x]:
            返回 False
    返回 True
```

## 4. 复杂度分析

设 $s$ 的长度为 $n$，$t$ 的长度为 $m$，$t$ 中不同字符数为 $k$（$k \le m$）。

- **时间复杂度**：
  - 外层 for 循环遍历 $j$ 共 $O(n)$ 次；
  - 内层 while 循环总共（跨越所有 $j$）左指针最多移动 $O(n)$ 次；
  - 但每次调用 `covered` 函数需要遍历 `need` 的所有键，耗时 $O(k)$；
  - 该 `covered` 检查在每次窗口扩张和每次收缩时都会被调用，导致整体复杂度为：
  
  $$O(n \cdot k)$$
  
  （相比使用一个 `valid` 计数变量的 $O(n)$ 优化写法，此实现因重复扫描 `need` 而多了一个 $k$ 因子。）

- **空间复杂度**：
  哈希表 `need` 和 `win` 至多存储字符集大小的键值对，为
  
  $$O(k + |\Sigma|)$$
  
  其中 $|\Sigma|$ 为字符集大小（通常视为常数），因此整体可视为 $O(k)$（或近似 $O(1)$，若字符集固定，如 ASCII）。
