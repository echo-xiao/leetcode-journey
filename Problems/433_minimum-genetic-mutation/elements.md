# 433. 最小基因变化 · 要素

1. 图的表示：图是隐式的无向图，节点是基因串（限定在bank里），两个基因串之间若只差一个字符就算有边，不用邻接表或矩阵，而是在BFS时对每个位置尝试换成ACGT四种字符来现场生成邻居

2. 遍历状态：用visited集合记录已经访问过的基因串防止重复入队，因为是BFS求最短路不存在环回绕问题，所以不需要onPath检环

3. 拓扑排序：本题不涉及拓扑排序，因为图里没有依赖顺序关系，只是求两个基因串之间的最短变化路径

4. 最短路松弛：不用单独的distTo数组，而是队列里每个元素带上(基因串, step)，step就是从startGene走到当前基因串的步数，出队时若等于endGene就直接返回step，相当于按BFS层数天然实现了最短路
