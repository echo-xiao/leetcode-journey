# 49. 字母异位词分组 · 解题思路与伪代码

## 1. 一句话直击本质
**将每个字符串转换为"排序后字符串"或"字符计数签名"作为哈希表的键，把互为字母异位词的字符串聚合到同一个桶中。**

## 2. 综合思路

字母异位词分组的核心是找到一种**规范化表示（canonical form）**，使得互为异位词的字符串映射到同一个键。常见的两种思路：

- **思路一：排序法（本题所用）**
  对每个字符串的字符进行排序，排序后的字符串完全相同即互为异位词。用排序结果作为哈希表的 key，将原字符串归入对应的 value 列表。

- **思路二：计数法（未在本代码中出现，但为常见 AC 解法）**
  统计每个字符串中 26 个小写字母的出现次数，将计数元组（或拼接成字符串）作为 key。此法避免排序开销，适合字符集较小的场景。

两种思路本质相同：都是"求规范形式 + 哈希分组"，区别仅在于规范化方式（排序 vs 计数）。

## 3. 全量伪代码

```
函数 groupAnagrams(strs):
    初始化空哈希表 count  // key: 规范化字符串, value: 原字符串列表

    对 strs 中每个字符串 s:
        // 方式一：排序法
        key = 将 s 的字符排序后拼接成新字符串

        // 方式二（可选变体）：计数法
        // key = 统计 s 中每个字母出现次数，组成长度为26的计数数组或元组

        如果 key 不在 count 中:
            count[key] = [s]      // 新建列表
        否则:
            count[key].append(s)  // 加入已有列表

    返回 count 中所有 value 组成的列表
```

## 4. 复杂度

设字符串数组长度为 $n$，字符串平均长度为 $k$。

**排序法：**
- 时间复杂度：$O(n \cdot k \log k)$（每个字符串排序耗时 $O(k\log k)$）
- 空间复杂度：$O(n \cdot k)$（哈希表存储所有字符串及键）

**计数法：**
- 时间复杂度：$O(n \cdot k)$（统计字符次数为线性）
- 空间复杂度：$O(n \cdot k)$
