# 572. 另一棵树的子树 · 要素

1. 函数定义：两个递归函数：isSubtree(主树节点, 目标子树节点)返回从这个主树节点开始能不能在其子树中找到和目标子树一样的结构；isSame(p, q)返回p和q这两棵树是不是完全长得一样（结构和值都一样）。

2. base case：isSubtree里主树节点为空直接返回False（没得比了）；isSame里p和q都为空返回True（都空说明一样），只有一个为空或值不同返回False。

3. 单层主体：isSubtree的单层主体是：先判断当前节点和目标子树是否isSame相同，如果相同就返回True，否则去左右子节点里继续递归找（当左右子树的查找结果已经算对，只需or起来）；isSame的单层主体是先比较p和q当前节点的值是否相等，再看左子树和右子树的比较结果（已经算对）是否都为True。

4. 代码位置：isSubtree属于前序位置写法，先处理当前节点（判断isSame）再递归左右子节点；isSame也是前序，先比较当前节点值再递归比较左右子树。
