# 131. 分割回文串 · 复盘

是一个切割（子集）的问题，核心在于在哪里放挡板， **切割问题可以被看成是特殊的组合问题，因为组合问题是n个里面选择k个，切割问题可以是n-1个潜在切割位置选择几个位置放挡板。**这个里面i+1其实就是下一个新的位置的起点。**start是这层逻辑的总起点，i是当前层尝试到的具体位置，然后后面i+1就变成下一层位置的起点**。那么什么时候要**用到size作为参数呢？当题目有明确数量限制的时候**。场景1，固定个数的组合，比如从n个里面选择k个，用start来避免重复，用k来记录还剩下几个没有选择，当k==0的时候，递归终止；场景2，93、restore ip address，将字符串切成4段，需要记录start，同时还要记录rem，也就是剩余段数，一直切到rem==0的时候才合法。
