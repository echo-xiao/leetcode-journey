# 563. 二叉树的坡度 · 复盘

这是一个自下而上的遍历，左右根的后续遍历，semantics是我要知道最终这个树的tilt（1. 计算每个node的左右子树和 2. 计算当前node的tilt，就是左右子节点差的绝对值 3. 把当前的坡度计算到全局变量里面去）。遍历每个node，递归函数同时要做两件事情：1. 向上级汇报“子树节点总和“，==**返回 leftSum+rightSum+node.val，其实就是计算当前子树的总和，返回给上级，让上级也能够进行同样的计算。 **==2. 计算并且更新tilt值，用self.res这个全局变量来累加所有节点的tilt值。这个里面一个核心的问题就是，为什么会需要返回值，以及返回的递归公式如何设计。原则就是父节点需要的这个信息，是子节点就知道的简单属性，还是需要子节点深入它整个子孙后代调查出来的一番结论。这个里面说的是左右子树之和，所以肯定不是简单属性，那么递归公式可以理解为：我有了左子树的信息，右子树的信息，当前节点的信息，我如何获取整棵树的信息。
