# 237. 删除链表中的节点 · 解题思路与伪代码

1. 一句话直击本质：通过将待删除节点的值替换为其后继节点的值，并调整指针以跳过后继节点，从而实现节点的删除。

2. 综合思路：
   - 直接替换法：由于无法访问链表的前驱节点，直接将待删除节点的值替换为其后继节点的值，然后跳过后继节点。这种方法不需要遍历链表，只需对节点进行局部操作。

3. 全量伪代码：
   ```plaintext
   定义函数 deleteNode(node):
       令 nxt 为 node 的下一个节点
       将 node 的值替换为 nxt 的值
       如果 nxt 不是最后一个节点:
           将 node 的下一个节点指向 nxt 的下一个节点
       否则:
           将 node 的下一个节点设为 None
   ```

4. 复杂度：
   - 时间复杂度：由于只涉及对常数个节点的操作，时间复杂度为 $O(1)$。
   - 空间复杂度：不需要额外的数据结构，空间复杂度为 $O(1)$。
