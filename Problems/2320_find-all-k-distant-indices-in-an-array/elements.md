# 2320. 找出数组中的所有 K 近邻下标 · 要素

1. 指针类型：同向而行的快慢指针：外层 i 从左到右扫每个下标当快指针，另一个指针 j 在 key 的下标列表 ind 上跟着往前走，因为 i 变大时能匹配的 key 下标也只会往后，不需要相向而行。

2. slow 含义：本题的慢指针 j 不是「下一个待写入位置」，它指向 ind 里当前还可能满足 |i-ind[j]|<=k 的最靠前的 key 下标；结果是往 res 里 append，不做原地覆盖，所以没有写入位置这层含义。

3. 停止条件：外层 i 走到 nums 末尾（i == n）就结束；内层 j 要么越过 ind 末尾（说明这个 i 不合格），要么一旦 |i-ind[j]|<=k 就把 i 加入 res 并 break，不是相遇型停止。
