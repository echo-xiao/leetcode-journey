# 190. 颠倒二进制位 · 要素

1. 数学结构：就是二进制位对称交换：n 的第 i 位要放到结果的第 31-i 位，靠「res 左移一位 + 取 n&1 填进去 + n 右移一位」这个固定套路完成，等价于 res = res*2 + n%2 循环 32 次。

2. 枚举范围：枚举范围固定就是 32 次循环（对应 32 个二进制位），不需要缩到 sqrt 也不看质因数，因为题目明确是 32 位无符号整数，位数写死。

3. 数值边界：输入输出都当 32 位无符号数看，不用取模；在 Java/C++ 里要注意右移用无符号右移（>>>）避免符号位填充，Python 里则要在最后与 0xFFFFFFFF 相与，别让结果超出 32 位。
