# 1486. 两个数组间的距离值 · 要素

1. 指针类型：这题真要用双指针的话是同向而行：先把 arr2 排序，i 扫 arr1（也排好序），j 只往右走找 arr2 中第一个 ≥ arr1[i]-d 的位置，两个指针都单向前进不回退。

2. slow 含义：本题不涉及原地写入，所以没有「下一个待写入位置」的 slow；这里的 j 只是 arr2 里的扫描位置，表示当前候选的最小可能落在 [arr1[i]-d, arr1[i]+d] 内的元素下标。

3. 停止条件：j 在 arr2[j] < arr1[i]-d 时继续右移，一旦 j 越界（j == arr2.length）或 arr2[j] >= arr1[i]-d 就停；此时若 j 越界或 arr2[j] > arr1[i]+d，说明这个 arr1[i] 距离合格，计数加一；外层 i 走完 arr1 结束。
