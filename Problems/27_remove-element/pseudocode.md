# 27. 移除元素 · 解题思路与伪代码

### 一句话直击本质

使用双指针法遍历数组，将不等于目标值的元素移动到数组前部。

### 综合思路

1. **双指针法**：使用两个指针，一个用于遍历数组（快指针），另一个用于记录新数组的末尾位置（慢指针）。当快指针遇到不等于目标值的元素时，将其赋值到慢指针位置，并移动慢指针。
   
   - **迭代实现**：通过循环遍历数组，使用条件判断和指针操作来完成元素的移除。

### 全量伪代码

```plaintext
函数 removeElement(数组 nums, 整数 val):
    初始化慢指针 slow 为 0
    对于 fast 从 0 到 数组长度 - 1 进行迭代:
        如果 nums[fast] 不等于 val:
            将 nums[fast] 的值赋给 nums[slow]
            增加慢指针 slow
    返回 slow 作为新数组的长度
```

### 复杂度

- 时间复杂度：$O(n)$，其中 $n$ 是数组的长度，因为每个元素最多被处理一次。
- 空间复杂度：$O(1)$，因为只使用了常数级别的额外空间。
