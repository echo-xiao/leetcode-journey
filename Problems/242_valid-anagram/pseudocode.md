# 242. 有效的字母异位词 · 解题思路与伪代码

# 《有效的字母异位词》AC版本分析

## 1. 一句话直击本质
判断两字符串是否为字母异位词，本质是比较两字符串中**字符种类及出现次数是否完全相同**。

## 2. 综合思路

- **思路一：排序法**（版本1）
  将两字符串分别排序后转为有序序列，若两字符串是异位词，排序后必然完全相等。

- **思路二：哈希计数法**（版本2）
  用哈希表（字典）分别统计两字符串中每个字符出现的次数，最后比较两个哈希表是否相等。

## 3. 全量伪代码

### 排序法
```
函数 isAnagram(s, t):
    将 s 转为字符列表并排序
    将 t 转为字符列表并排序
    返回 排序后的s == 排序后的t
```

### 哈希计数法
```
函数 isAnagram(s, t):
    初始化空字典 seen1, seen2
    
    遍历字符串 s 中每个字符 i:
        若 i 不在 seen1 中:
            seen1[i] = 1
        否则:
            seen1[i] += 1
    
    遍历字符串 t 中每个字符 j:
        若 j 不在 seen2 中:
            seen2[j] = 1
        否则:
            seen2[j] += 1
    
    返回 seen1 == seen2
```

## 4. 复杂度

### 排序法
- 时间复杂度：$O(n \log n)$（排序的复杂度）
- 空间复杂度：$O(n)$（排序需要额外空间存储）

### 哈希计数法
- 时间复杂度：$O(n)$（遍历两字符串各一次）
- 空间复杂度：$O(k)$，其中 $k$ 为字符集大小（如仅小写字母时 $k=26$，可视为 $O(1)$）
