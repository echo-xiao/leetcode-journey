# 119. 杨辉三角 II · 要素

1. 状态：状态就是当前算到第几行（rowIndex），以及这一行的所有数字组成的列表。

2. 选择：没有真正的“选择”，第 i 行第 j 个位置的值只能由上一行相邻两个数相加得到（两端固定为 1）。

3. dp 定义：getRow(i) 返回杨辉三角第 i 行（从 0 开始）的完整数组，转移是 row[i][j] = row[i-1][j-1] + row[i-1][j]。

4. base case：rowIndex 为 0 时返回 [1]，为 1 时返回 [1,1]。

5. 遍历顺序：从第 0 行往下逐行推到第 rowIndex 行（递归解法是先递归到底再回溯着往上拼），算第 i 行时第 i-1 行必须已经算好；若用一维数组原地更新，行内要从右往左倒着写。
