## 解题思路与复盘

1. **一句话直击本质：** 利用二叉搜索树的性质，通过比较节点值递归或迭代地向下查找，直到找到分叉点即为最近公共祖先。

2. **综合思路：**
   - **递归解法：** 通过递归调用函数，根据二叉搜索树的性质（左子树节点值小于根节点值，右子树节点值大于根节点值），判断 `p` 和 `q` 的值相对于当前节点的位置，决定向左子树或右子树递归，直到找到分叉点。
   - **迭代解法：** 使用循环代替递归，通过相同的逻辑在树中向下遍历，直到找到分叉点。

3. **全量伪代码：**

   **递归解法伪代码：**
   ```
   函数 lowestCommonAncestor(根节点, 节点p, 节点q):
       如果 根节点 为空:
           返回 None
       
       如果 p的值 小于 根节点的值 且 q的值 小于 根节点的值:
           返回 lowestCommonAncestor(根节点的左子节点, p, q)
       否则如果 p的值 大于 根节点的值 且 q的值 大于 根节点的值:
           返回 lowestCommonAncestor(根节点的右子节点, p, q)
       否则:
           返回 根节点
   ```

   **迭代解法伪代码：**
   ```
   函数 lowestCommonAncestor(根节点, 节点p, 节点q):
       当前节点 = 根节点
       当 当前节点 不为空:
           如果 p的值 小于 当前节点的值 且 q的值 小于 当前节点的值:
               当前节点 = 当前节点的左子节点
           否则如果 p的值 大于 当前节点的值 且 q的值 大于 当前节点的值:
               当前节点 = 当前节点的右子节点
           否则:
               返回 当前节点
       返回 None
   ```

4. **复杂度：**
   - 时间复杂度：$O(h)$，其中 $h$ 是树的高度。在最坏情况下（例如，树退化为链表），$h$ 等于 $n$，即节点总数。
   - 空间复杂度：递归解法为 $O(h)$（递归栈的深度），迭代解法为 $O(1)$。
