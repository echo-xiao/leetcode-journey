# 3. 无重复字符的最长子串 · 要素

1. 定长还是变长：变长窗口：窗口大小随重复字符出现而动态伸缩，不是固定长度

2. 进窗口更新：right指针每轮循环都右移一位扩大窗口，把s[right]加入窗口容器（集合加入该字符，或计数字典对应字符计数+1）

3. 出窗口时机：当窗口内出现字符s[right]的重复（集合中已存在，或计数字典该字符计数>1）时就要移动left收缩窗口，移出s[left]时要把它从集合中删除，或计数字典对应计数-1（并可选清理为0的key），直到窗口内不再重复

4. 记结果时机：每次right移动、窗口调整完毕后，用当前窗口长度right-left+1去更新maxres，即每轮循环末尾都要记一次结果
