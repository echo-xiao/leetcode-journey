# 3. 无重复字符的最长子串 · 解题思路与伪代码

# 3. 无重复字符的最长子串 —— AC版本分析

## 1. 一句话直击本质
**滑动窗口**：维护一个不含重复字符的窗口，右指针不断扩张，遇到重复字符时收缩左指针，直至窗口内无重复，过程中记录窗口最大长度。

## 2. 综合思路
所有版本本质相同，均为**双指针滑动窗口**，区别仅在于用何种数据结构记录窗口内字符状态：

- **思路A（Set记录存在性）**：用集合存储窗口内字符，出现重复时不断移除左端字符直到重复字符被移出（版本1、4）。
- **思路B（字典/Counter记录计数）**：用哈希表记录字符出现次数，当前字符计数>1时收缩左边界（版本2、3）。
- **思路C（defaultdict计数+删除清理）**：用 defaultdict 计数，当右指针字符已在计数器中时收缩左指针，并在计数归零时删除该key，保持字典“干净”（版本5、6、7）。
- **思路D（List+Set暴力比较）**：用列表模拟窗口，每次追加新字符后用 `len(list) != len(set(list))` 判断是否有重复，若重复则从左边删除，效率相对较低但等价（版本8）。

四种思路时间复杂度一致，均为线性双指针，只是判重方式不同（集合查找 vs 计数字典 vs 列表转集合比较）。

## 3. 全量伪代码

```
函数 lengthOfLongestSubstring(s):
    初始化 左指针 i = 0
    初始化 窗口状态容器 win （集合 或 计数字典）
    初始化 maxres = 0

    对 右指针 j 从 0 到 len(s)-1:
        c = s[j]

        情况一（集合版）:
            当 c 在 win 中:
                从 win 中移除 s[i]
                i += 1
            将 c 加入 win

        情况二（计数字典版）:
            win[c] 计数加一
            当 win[c] > 1:
                win[s[i]] 计数减一
                i += 1

        情况三（defaultdict + 清理版）:
            当 s[j] 在 win 中:
                win[s[i]] 减一
                若 win[s[i]] == 0: 删除该key
                i += 1
            win[s[j]] 加一

        情况四（列表+集合比较版）:
            将 c 加入列表 res
            当 len(res) != len(set(res)):
                删除 res 的第一个元素
                i += 1

        计算当前窗口长度 = j - i + 1
        更新 maxres = max(maxres, 当前窗口长度)

    返回 maxres
```

## 4. 复杂度

- **时间复杂度**：
  - 思路A/B/C：每个字符最多被左右指针各访问一次，均为 $O(n)$。
  - 思路D：由于每次内层循环需要 `set(res)` 转换（$O(k)$，k为窗口大小），最坏情况下退化为 $O(n^2)$。

- **空间复杂度**：
  所有版本均使用额外的哈希结构（集合/字典/列表）存储窗口内字符，最坏情况下窗口包含所有不同字符，故为 $O(\min(n, |\Sigma|))$，其中 $|\Sigma|$ 为字符集大小。
