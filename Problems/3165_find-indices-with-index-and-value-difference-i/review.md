# 3165. 找出满足差值条件的下标 I · 复盘

一看到相减，就想到是否存在的问题，但是这个题目的难点在于abs、以及范围满足要求。问题变成，对于每一个a，存在哪些b，使得他们的差值满足要求。妥妥的搜索和存在性问题，那么是否存在这种问题，一般可以用高效的数据结构和方法来回答，而不是真的进行遍历。这个问题不是滑动窗口的问题，但是比较类似，更准确的来说是扩展前缀窗口 expanding prefix window 的问题，但是其实都是需要维护窗口。然后这个里面差值满足要求，有一个思维上的转换，需要从“检查所有的历史i点”到“只需要检查历史中最好和最坏的i点”就行了，所以满足要求就转换成了更加简单的问题。想这种问题，不要直接想数学，尝试想想场景。
