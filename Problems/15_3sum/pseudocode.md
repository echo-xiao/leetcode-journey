# 15. 三数之和 · 解题思路与伪代码

# 三数之和算法分析

## 1. 核心本质

**排序后固定一数，双指针夹逼查找另外两数，通过跳过重复元素实现去重。**

## 2. 综合思路

本题解集中仅有一种主流高效解法：**排序 + 双指针（Two Pointers）**。

其核心思想是：
- 先对数组排序，将无序问题转化为有序问题，为双指针扫描和去重提供基础。
- 外层遍历固定第一个数 `nums[i]`，将三数之和问题转化为在剩余区间内寻找**两数之和等于 `-nums[i]`** 的问题。
- 内层使用左右指针 `left`、`right` 从两端向中间夹逼，根据和与目标值的大小关系移动指针。
- 在外层和内层分别做**跳过重复元素**处理，避免结果集中出现重复的三元组。

（注：也存在哈希表解法作为该题的常见思路，但本题给出的 AC 版本只体现了双指针解法，故不再展开列举未出现的方法。）

## 3. 全量伪代码

```
算法：三数之和（排序 + 双指针）

输入：整数数组 nums
输出：所有和为0且不重复的三元组列表

1. 将 nums 按升序排序
2. 初始化结果列表 res = []
3. 令 n = nums 的长度
4. 遍历 i 从 0 到 n-1：
      target = -nums[i]          // 需要 left+right 凑出的目标值
      
      // 第一层去重：跳过与前一个相同的固定数
      如果 i > 0 且 nums[i] == nums[i-1]：
          continue（跳过本次循环）
      
      left = i + 1
      right = n - 1
      
      当 left < right 时循环：
          若 nums[left] + nums[right] == target：
              将 [nums[i], nums[left], nums[right]] 加入 res
              
              // 第二层去重：跳过左指针的重复值
              当 left < right 且 nums[left] == nums[left+1]：
                  left += 1
              // 第三层去重：跳过右指针的重复值
              当 left < right 且 nums[right] == nums[right-1]：
                  right -= 1
              
              left += 1
              right -= 1
          
          否则若 nums[left] + nums[right] > target：
              right -= 1     // 和过大，右指针左移减小和
          
          否则：
              left += 1      // 和过小，左指针右移增大和

5. 返回 res
```

## 4. 复杂度分析

**时间复杂度**：

- 排序耗时 $O(n \log n)$
- 外层循环 $O(n)$，内层双指针扫描均摊 $O(n)$，故双重循环总体为 $O(n^2)$
- 整体时间复杂度为：

$$O(n^2)$$

**空间复杂度**：

- 排序本身所需的辅助空间（视具体排序算法实现，Python 的 Timsort 通常为 $O(\log n)$ 到 $O(n)$）
- 不考虑返回结果 `res` 所占空间（题目输出必需），额外空间复杂度为：

$$O(\log n) \text{ 或 } O(1)$$（排序算法的栈开销，视具体实现而定）

若计入结果存储空间，最坏情况下空间复杂度为：

$$O(n^2)$$（当存在大量满足条件的三元组时）
