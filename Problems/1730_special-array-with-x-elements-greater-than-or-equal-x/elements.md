# 1730. 特殊数组的特征值 · 要素

1. 指针类型：本题不用快慢指针，只有二分版用得上「相向而行」的 left/right 在候选值 0~n 上夹逼（left=0、right=n），线性扫描版就一个下标 i 从头到尾走，本质不是双指针题。

2. slow 含义：本题不涉及：没有原地删除/覆盖元素的动作，不存在「下一个待写入位置」，降序排序后的下标 i 只表示「前面已有 i+1 个元素≥nums[i]」这个计数含义。

3. 停止条件：二分版在 left > right 时结束并返回 -1（每轮用 cnt 与 guess 比较来收缩区间）；线性扫描版在 i 走到 n（越界）时结束返回 -1，中途一旦 nums[i]>=i+1 且下一个元素小于 i+1 就直接返回 i+1。
