# 294. 翻转游戏 II · 要素

1. 状态：状态是当前的字符串局面s（由+和-组成的字符串），因为每次翻转都会改变这个字符串本身

2. 选择：在s中任意一个满足s[i:i+2]=="++"的位置i，把这两个+翻转成--，生成新状态nxt

3. dp 定义：solve(s)表示当前轮到的玩家面对局面s时，是否存在必胜策略（即能否找到一种翻转让对手必输）

4. base case：当s中不存在任何"++"子串（无法进行任何翻转）时，当前玩家必败，返回False

5. 遍历顺序：按状态转移的方向，从s翻转生成的nxt（局面复杂度更低，剩余++更少）先递归求解，再回溯得到s的结果，本质是自顶向下的记忆化递归，不需要显式规定遍历顺序
