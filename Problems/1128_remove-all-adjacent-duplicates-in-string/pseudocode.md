# 1128. 删除字符串中的所有相邻重复项 · 解题思路与伪代码

1. 一句话直击本质：利用栈数据结构逐步消除相邻重复字符，最终返回处理后的字符串。

2. 综合思路：
   - **迭代法（使用栈）**：遍历字符串中的每个字符，使用栈来存储字符，当遇到与栈顶相同的字符时，弹出栈顶元素以消除重复项，否则将字符压入栈中。
   - 该问题主要采用栈结构进行迭代处理，未见其他如递归、DFS、BFS等方法的实现。

3. 全量伪代码：
   ```plaintext
   初始化一个空栈 stack
   对于字符串 s 中的每个字符 char：
       如果栈不为空且栈顶元素等于当前字符 char：
           弹出栈顶元素（消除重复）
       否则：
           将当前字符 char 压入栈中
   将栈中的字符连接成字符串并返回
   ```

4. 复杂度：
   - 时间复杂度：$O(n)$，其中 $n$ 是字符串的长度，因为每个字符最多被压入和弹出栈一次。
   - 空间复杂度：$O(n)$，在最坏情况下（如没有重复字符），栈需要存储所有字符。
