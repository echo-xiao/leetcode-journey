# 2210. 找出数组排序后的目标下标 · 要素

1. 指针类型：这题没有真正的快慢指针，用的是二分里的 left/right 相向收缩去找 target 的第一个位置，收缩完再用一个单指针往后线性扫；如果直接线性扫，就只有一个指针 i

2. slow 含义：本题不涉及，因为没有原地覆盖写入的动作，结果是往 res 里 append 下标，不需要一个「下一个写入位置」的指针

3. 停止条件：二分部分在 left > right 时停（此时 left 就是第一个 >= target 的下标）；收集部分在 left 越出数组长度或 nums[left] != target（排序后即出现比 target 大的值）时停
