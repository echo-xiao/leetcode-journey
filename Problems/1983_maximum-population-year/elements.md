# 1983. 人口最多的年份 · 要素

1. 前缀和还是差分：用差分，因为每条 log 都是给 [birth, death-1] 这段年份整体加 1，属于反复对区间做增减，最后只需扫一遍求人口。

2. preSum[0] 定义：这里的差分数组 delta 全部初始化为 0，累加变量 curr 从 0 开始，扫到 1950 那格直接加上 delta[0] 就是当年人口，不用对第一年做特判。

3. 差分下标位置：活着的区间是 [birth, death-1]，所以 delta[birth-1950] += 1、delta[death-1950] -= 1（即 (death-1)+1 那格减 1）。
