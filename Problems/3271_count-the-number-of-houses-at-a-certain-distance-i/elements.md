# 3271. 按距离统计房屋对数目 I · 要素

1. 图的表示：这是个无向图，n个房子按1..n-1相邻连成链，再加一条x-y的额外边，用邻接表adj存每个点的邻居即可（Floyd版用n+1×n+1的距离矩阵）。

2. 遍历状态：BFS版本只需要一个visited集合防止重复访问，因为是无向无权图不存在环回问题，不需要onPath检环。

3. 拓扑排序：本题不涉及拓扑排序，因为图里有环（链+额外边构成环），不是DAG，也不需要求任何顺序关系。

4. 最短路松弛：距离数组dist初始化为全部无穷大（自己到自己为0），BFS版本每次从一个点出发，按层扩展时新距离=当前距离+1直接赋值（无权图不需要松弛比较）；Floyd版本用dist[i][k]+dist[k][j]和dist[i][j]比较取小来更新，作为标准三重循环松弛。
