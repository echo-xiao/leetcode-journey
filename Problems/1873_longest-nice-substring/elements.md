# 1873. 最长的美好子字符串 · 要素

1. 定长还是变长：变长，但要枚举字母种类数 k 从 1 到 26，每轮固定「窗口内最多 k 种字母（忽略大小写）」，在这个约束下窗口长度仍是变的。

2. 进窗口更新：right 每一步都往右走一格，把当前字符按小写字母归类记进 seen（分别记大写出现次数和小写出现次数），如果这个字母大小写计数都从原来缺一边变成都>0，matched 加一。

3. 出窗口时机：当 seen 里字母种类数超过 k 时收缩：把 s[left] 对应的大小写计数减一，若它原来大小写齐全现在缺了一边就 matched 减一，若大小写计数都为 0 就把这个字母从 seen 删掉，然后 left++。

4. 记结果时机：每次收缩完后，若 seen 的种类数正好等于 k 且 matched 也等于 k（说明这 k 种字母全都大小写齐全），就用 s[left..right] 和 max_res 比长度，更长则替换。
