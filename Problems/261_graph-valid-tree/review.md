# 261. 以图判树 · 复盘

==**这个题目主要是要判断连通性和环。连通性就是node的个数是否是n**==，可以通过==**visited的个数**==来进行判断，如果用set就判断==**set的长度是否等于n**==，如果用false/true的list来判断是否还有false。整体就是一个遍历然后判断的逻辑。然后如果==**判断是否有环，就是边的条数是否等于n-1**==，这个在通过edges的长度就能够判断出来。然后由于仅仅是遍历+判断的逻辑，所以其实用stack和queue的逻辑是一样的。这个题目也可以==**用并查集来看**==，union find的做饭，但是到时候再说吧。==**#connectedComponents #tree&cycles**==
