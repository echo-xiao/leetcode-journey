# 747. 使用最小花费爬楼梯 · 解题思路与伪代码

1. 一句话直击本质：该算法的核心逻辑是通过动态规划递归地计算每一步的最小花费，并使用记忆化存储中间结果以避免重复计算。

2. 综合思路：
   - 递归与记忆化：通过递归函数计算从某一步到达顶部的最小花费，并使用一个数组存储已经计算过的结果以减少重复计算。
   - 迭代动态规划：可以通过迭代的方式从底部向上计算每一步的最小花费，避免递归的栈开销。

3. 全量伪代码：
   - 递归与记忆化版本：
     ```
     定义函数 minCostClimbingStairs(cost):
         初始化 n 为 cost 的长度
         初始化 dp 数组为长度 n+1，元素为 -1
         返回 min(递归(n-1), 递归(n-2))

     定义递归函数 recursion(n):
         如果 n 等于 0:
             返回 cost[0]
         如果 n 等于 1:
             返回 cost[1]
         如果 dp[n] 不等于 -1:
             返回 dp[n]
         dp[n] = min(递归(n-1), 递归(n-2)) + cost[n]
         返回 dp[n]
     ```

4. 复杂度：
   - 时间复杂度：$O(n)$，因为每个台阶的最小花费只计算一次。
   - 空间复杂度：$O(n)$，因为需要一个数组来存储每个台阶的最小花费。
