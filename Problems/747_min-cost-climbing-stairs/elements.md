# 747. 使用最小花费爬楼梯 · 要素

1. 状态：状态是当前站在第几个台阶（下标i），表示走到这一阶为止已产生的最小花费情况

2. 选择：每个台阶i可以选择从i-1再迈一步过来，也可以从i-2跨一步过来，取两者花费较小的

3. dp 定义：dp[i] 表示到达第i个台阶（不一定是终点，可能是走出楼梯的位置）所需要花费的最小体力值

4. base case：base case是dp[0]=cost[0]，dp[1]=cost[1]，即起始的两个台阶花费就是它们自身的cost

5. 遍历顺序：从下标2开始一直遍历到n（楼梯顶部，即数组外一格），保证计算dp[i]时dp[i-1]和dp[i-2]都已经算出来
