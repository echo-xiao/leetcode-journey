# 1476. 统计有序矩阵中的负数 · 要素

1. 指针类型：用左右两个方向相向而行的指针：row 从最后一行往上走、col 从第 0 列往右走，从矩阵左下角出发，两个指针各只朝一个方向移动不回头。

2. slow 含义：本题不涉及快慢指针，没有原地写入或删除元素的需求；这里的 row/col 只是行列游标，row 表示当前正在检查的行，col 表示当前列位置，col 右边的元素在这一行都还没被判定为负。

3. 停止条件：当 row < 0（往上越出矩阵）或 col >= n（往右越出矩阵）时停止；遇到 grid[row][col] < 0 就一次加上 n - col 个负数并上移一行，否则右移一列。二分写法则是 left > right 时停，答案取 len(lst) - left。
