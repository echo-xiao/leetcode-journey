# 774. N 叉树的最大深度 · 要素

1. 函数定义：maxDepth(root) 表示以 root 为根的 N 叉树的最大深度，参数是当前节点，返回值是这个节点为根的子树的最大深度（整数）

2. base case：root 为空时返回 0，表示空节点深度为 0（root 没有子节点时可直接返回 1 作为额外优化，但不是必须）

3. 单层主体：对 root 的每个子节点 child 递归求 maxDepth(child)，取所有子节点结果中的最大值，再加 1 作为当前节点的深度

4. 代码位置：属于后序位置，因为必须先递归算出所有子节点的深度，才能在当前节点汇总取最大值再加一
