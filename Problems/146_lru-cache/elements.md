# 146. LRU 缓存 · 要素

1. 栈还是队列：本质是队列思路——按使用先后排队，最久没用的排在尾部先淘汰，但用双向链表加哨兵头尾节点实现，可以从中间任意位置抽出节点，普通栈或队列做不到。

2. 存什么：链表节点里存 key 和 value 两样（key 是为了淘汰尾节点时能顺手把哈希表里的这条也删掉），哈希表存 key 到节点指针的映射。

3. 进出时机：get 命中或 put 更新旧键时：先 remove 该节点再 add 到头部；put 新键：新节点直接插头部并登记哈希表；只有当哈希表大小超过 capacity 时才从 tail 前一个节点出队并同步删哈希表条目。

4. 剩余元素含义：本题不涉及——这是常驻的数据结构，没有「循环结束」，链表任何时刻从头到尾就是从最近使用到最久未使用的排序。
