# 2220. 从给定原材料中找到所有可以做出的菜 · 要素

1. 图的表示：用哈希表存邻接表，key 是原料名、value 是需要它的菜名列表（有向边：原料→菜），另外用 indegree 记每道菜还缺几种原料；因为名字是字符串所以不用矩阵。

2. 遍历状态：BFS 版靠 indegree 归零来天然去重，每道菜只入队一次；DFS 版用 status 字典标 0未访问/1正在处理/2可做/3不可做，既缓存结果又防止配方互相依赖成环时无限递归。

3. 拓扑排序：需要，主推 Kahn 入度法：把 supplies 全部入队当起点，出队时若是菜就加进答案，再把它作为原料去减下游菜的入度，减到 0 就入队；DFS 版就是三色标记的记忆化写法。

4. 最短路松弛：本题不涉及，只问菜能不能做出来（可达性），没有边权也不求最少步数。
