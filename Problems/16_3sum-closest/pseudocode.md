# 16. 最接近的三数之和 · 解题思路与伪代码

# 最接近的三数之和 - AC版本分析

## 1. 一句话直击本质
**排序 + 固定一数 + 双指针夹逼**，通过排序后固定最外层数字、内层用左右双指针逼近目标值，同时动态维护最小差值的和。

## 2. 综合思路

所提供的两个版本本质上是**同一种算法思路**：排序 + 双指针（Two Pointers），无实质性差异，仅代码书写顺序略有不同（判断大小的分支顺序互换、变量初始化位置略异），核心逻辑完全一致。

**核心思路**：
- 先对数组排序，为双指针移动提供单调性基础。
- 外层遍历固定一个数 `nums[i]`。
- 内层用左右指针 `left, right` 在剩余区间中寻找最接近 `target - nums[i]` 的两数之和。
- 根据当前三数之和与目标值的比较，收缩指针：
  - 若和大于目标，右指针左移（减小和）；
  - 若和小于目标，左指针右移（增大和）；
  - 若和等于目标，直接返回（最优解）。
- 全程用 `closest` 记录历史最优（最接近target）的三数之和。

无递归/DFS等其他解法，均为迭代双指针实现。

## 3. 全量伪代码

```
函数 threeSumClosest(nums, target):
    对 nums 进行升序排序
    n = nums 长度
    closest = nums[0] + nums[1] + nums[2]   # 初始化最接近值

    for i from 0 to n-1:
        left = i + 1
        right = n - 1
        
        while left < right:
            当前和 ttl = nums[i] + nums[left] + nums[right]
            
            如果 |ttl - target| < |closest - target|:
                closest = ttl    # 更新最接近的和
            
            如果 ttl > target:
                right -= 1       # 和过大，右指针左移，减小和
            否则如果 ttl < target:
                left += 1        # 和过小，左指针右移，增大和
            否则:
                return ttl        # 恰好等于target，直接返回最优解
    
    return closest
```

## 4. 复杂度

**时间复杂度**：
- 排序：$O(n \log n)$
- 双重循环（外层 $O(n)$，内层双指针最多移动 $O(n)$）：$O(n^2)$
- 总体：$O(n^2)$

**空间复杂度**：
- 忽略排序算法本身占用的额外空间（原地排序），仅使用常数个变量：
$$O(1)$$
（若考虑排序算法内部递归栈开销，某些语言实现可能为 $O(\log n)$）
