# 347. 前 K 个高频元素 · 解题思路与伪代码

# 前 K 个高频元素 - 算法分析

## 1. 一句话本质
统计元素出现频率后，通过**排序**或**桶排序**筛选出频率最高的 K 个元素。

## 2. 综合思路

本题解法可归纳为两大类：

**思路一：桶排序（版本1、版本2）**
- 利用哈希表统计每个元素的出现频率。
- 创建大小为 `n+1` 的桶数组，下标代表频率值，将元素放入对应频率的桶中。
- 由于频率范围为 `[0, n]`，桶排序可将时间复杂度优化至线性级别，无需比较排序。
- 从高频率桶向低频率桶遍历，依次收集元素直到达到 K 个。

**思路二：直接排序（版本3）**
- 利用哈希表统计频率后，将 `(频率, 元素)` 组成的元组放入列表。
- 对列表整体进行排序（降序），直接取排序后的前 K 个元素。
- 实现简单，但时间复杂度为 $O(n \log n)$，劣于桶排序。

## 3. 全量伪代码

### 通用第一步：频率统计
```
函数 topKFrequent(nums, k):
    初始化空哈希表 count
    对 nums 中每个元素 i:
        若 i 不在 count 中: count[i] = 1
        否则: count[i] += 1
```

### 方法A：桶排序法（版本1、2）
```
    创建长度为 n+1 的桶数组 arr（每个元素为空列表），下标为频率值

    对 count 中每个元素 i:
        freq = count[i]
        将 i 加入 arr[freq]

    res = []
    从高到低遍历频率 i (从 n 到 0):
        遍历 arr[i] 中的每个元素 j:
            将 j 加入 res
            若 res 长度 == k:
                返回 res
    返回 res
```

### 方法B：排序法（版本3）
```
    构建列表 items，包含 (频率, 元素) 元组
    对 items 按频率降序排序

    res = []
    取 items 中前 k 个元组的元素部分，加入 res
    返回 res
```

## 4. 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 桶排序法（版本1、2） | $O(n)$ | $O(n)$ |
| 排序法（版本3） | $O(n \log n)$ | $O(n)$ |

**说明**：
- $n$ 为数组 `nums` 的长度。
- 桶排序法通过空间换时间，利用频率有界（最大为 $n$）的特性，将排序转化为线性遍历，是本题的最优解法。
- 排序法逻辑简单直观，但因排序操作导致时间复杂度上升为 $O(n \log n)$。
- 两种方法的空间复杂度均为 $O(n)$，主要来自哈希表和辅助数组/列表的存储开销。
