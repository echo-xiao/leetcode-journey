# 109. 有序链表转换二叉搜索树 · 复盘

两种做法，都要用到迭代。**一种是找到root来进行递归**，前序遍历分治法，先遍历链表找中点，切断链表，再进行递归。但是我也没有写出来。**另外一种做法是，中序模拟，先算出树的结构，**然后按照链表顺序一个一个的填入数值，一边挖坑一边填坑，找到的是start和end，然后来进行递归。本质是流式处理streaming，树的结构通过递归计算出来，树的内容通过链表指针一步步单向填充进去。**这额题目属于bst里面“构建类+中序模拟”的方式，建议108→897 都用中序遍历来构建树**
