# 1646. 第 k 个缺失的正整数 · 复盘

这个题目核心的一个点在于，理想的数组里面，位于索引i的位置的元素应该是i+1，那么现在在这个地方的元素arr[i]-(i+1)就应该等于缺失的元素。这个里面i+1，用binary search找出来其实就是left的这个位置。这个里面三个关键的代码：cnt = arr[mid] - (mid+1)，告诉我们缺失了多少个元素，if cnt >= k 这个是用来判断，往左走还是往右走，最后这个是终点计算 return k + res。此外，还有一个更加简单的写法，其实就是用元素本身num和k值来进行比较，<的话就+1，说明num元素占据了本身缺失的一个位置，把目标往后挤了一位，所以要直接+1，感觉这个是brute force的解法，但是不知道为什么比较难理解，是一种补偿和挤占的思想。
