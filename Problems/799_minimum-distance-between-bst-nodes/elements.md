# 799. 二叉搜索树节点最小距离 · 要素

1. 函数定义：traverse(node) 表示对以node为根的子树做中序遍历，不直接返回值，而是通过更新外部变量prev（上一个访问节点的值）和min_diff（当前最小差值）来记录结果

2. base case：当node为空时直接return，不做任何处理，因为空节点没有值可比较

3. 单层主体：利用BST中序遍历值递增的性质，先递归左子树，再比较当前节点值和prev的差值来更新min_diff，最后把prev更新为当前节点值，再递归右子树

4. 代码位置：主体代码写在中序位置，即先处理左子树、再处理当前节点（比较并更新prev和min_diff）、最后处理右子树
