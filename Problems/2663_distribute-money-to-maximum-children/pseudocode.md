# 2663. 将钱分给最多的儿童 · 解题思路与伪代码

### 一句话直击本质

通过贪心策略，优先满足每个孩子至少得到1美元，然后尽可能多地将剩余的钱分配给孩子，使得最多的孩子得到8美元。

### 综合思路

1. **贪心策略**：首先给每个孩子分配1美元，然后用剩余的钱尽可能多地将孩子的1美元“升级”到8美元。需要处理一些特殊情况：
   - 如果总钱数少于孩子数，无法满足每个孩子至少1美元的需求，返回-1。
   - 如果总钱数足够给每个孩子8美元以上，则最多只有`children - 1`个孩子能得到8美元。
   - 如果总钱数正好是`8 * children - 4`，则需要调整策略，最多只能有`children - 2`个孩子得到8美元。

### 全量伪代码

```plaintext
函数 distMoney(钱数, 孩子数):
    如果 钱数 < 孩子数:
        返回 -1  # 钱不够每个孩子至少1美元

    如果 钱数 > 8 * 孩子数:
        返回 孩子数 - 1  # 钱太多，最多只有孩子数-1个孩子能得到8美元

    如果 钱数 == 8 * 孩子数 - 4:
        返回 孩子数 - 2  # 特殊情况，避免最后一个孩子拿到4美元

    # 正常情况，使用贪心策略
    返回 (钱数 - 孩子数) // 7  # 剩余的钱用于“升级”1美元到8美元
```

### 复杂度

- 时间复杂度：$O(1)$，因为算法只涉及常数次的计算和条件判断。
- 空间复杂度：$O(1)$，因为只使用了固定数量的额外空间。
