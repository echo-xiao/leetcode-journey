# 94. 二叉树的中序遍历 · 复盘

树的中序遍历，我大概知道这个逻辑，先处理left，处理到底，然后再处理当前节点，再处理右边。但是代码逻辑是错的，我在==**用线性思维去解决一个递归的问题。**==1. 我只说了一直循环一路向左，但是出发了之后，不知道如何回归到这个loo里面来。2. stack在这个里面其实没有用上，只是充当了一个待办清单，而不是容器的作用。3. 缺少总控循环，while curr is not none 只是一个辅助循环，唯一的工作就是左子树全部push进去，但是干完了，其他的东西都没有搞定。正确的总控循环应该是只要还有路走，或者还有待办事项，就不能够停。==**这个里面只要往右走，就会触发一轮新的往左走的路程。这个就是状态机的循环。**==假设有一个tree，2是root，1是left，3是right，while curr is not none 的时候，走到底了，stack里面有2和1，top是1，要开始处理1，pop出来之后，进行处理，append到res，然后这个时候开始处理1的right，但是1的right是none，所以这个循环就是，跳过while curr is not none，直接处理stack里面的2，然后2的right就是3，curr就不是none，所以要开始一轮新的循环。

---

这个题目就是一个典型的遍历求解的问题，里面==**四个知识点**==，一个是中序遍历里面，==**node 的 visit 和 action 两个的运行机制**==，visit就是递归函数调用自己，将控制权交给子节点的过程，；另外一个是==**参数的传递**==，新建一个traverse辅助函数，两种方式，要么传递一个参数，要么定义一个外部变量，同时这个函数没有返回值，因为结果是迭代的副产物；最后一个是==**递归终止的情况**==，inorderTraversal里面就没有if not root的情况，但是traverse里面就有if not node的情况，这个的区别是if not node是递归终止case，是base case，表示函数什么时候要停下，当遍历到一个叶子节点的子节点的时候，比如node.left，这个子节点就是none，对辅助函数的调用就会出发这个条件，调用栈开始弹出，如果没有这个终止条件，函数就会无限递归，然后直到崩溃。但是主函数里面没有if not root就不一样了，主函数是递归的启动函数/入口，这个里面，如果一开始传入的root就是none的话，代码会执行self.traverser(None,res)，在traverse的内部，if not node，条件立刻满足，函数直接return res，返回[]，所以这个检查在这里面可以省略，但是为了代码更加清晰、健壮，这个检查很好。最后一个点，了解下==**迭代法**==是如何解决这个问题的，以及对应的前序、后序遍历是如何做的。
