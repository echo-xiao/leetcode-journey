# 267. 回文排列 II · 要素

1. 路径：path 是当前已排好的半个回文的字符序列，比如 half 是 ['a','a','b'] 时 path 可能是 ['a','b']。

2. 选择列表：排序后的 half 数组里所有还没被 used 标记的字符，且遇到 nums[i]==nums[i-1] 且 used[i-1] 为 False 时跳过，避免同层重复排列。

3. 结束条件：path 长度等于 half 长度时，把 left+mid+left 反转 拼成完整回文塞进 res 后返回；另外开头奇数频次字符超过 1 个就直接返回空列表，根本不进 DFS。

4. 撤销：递归回来后把 path 末尾刚加的字符弹掉，并把 used[i] 重新置回 False。
